数据库目录总结
AI24X网站对应的数据库目录结构如下：

1. 主数据库目录
C:\AI24X\OpenClaw\web\ai24x-website\data\
2. 数据库文件列表
文件	用途
share-links.json	分享链接数据库
share-clicks.json	分享点击记录
share-conversions.json	分享转化记录
fission-rewards.json	裂变奖励记录
invitation-codes.json	邀请码数据库
referral-relations.json	推荐关系数据库
user-levels.json	用户等级数据
user-rewards.json	用户奖励数据
3. 用户数据库
C:\AI24X\OpenClaw\web\ai24x-website\users.json
存储用户基本信息
目前为空数组（等待用户注册）
4. 数据库管理模块
api/share-db.js - 分享系统数据库操作
api/fission-db.js - 裂变系统数据库操作
5. 数据库设计特点
JSON文件存储：使用简单的JSON文件作为数据库
模块化设计：每个功能模块有独立的数据文件
自动初始化：数据库文件不存在时会自动创建
数据持久化：所有操作都会实时写入文件
6. 数据备份目录
C:\AI24X\OpenClaw\web\ai24x-website\backups\
包含历史备份数据
7. 数据库访问路径
// 在代码中访问数据库的示例
const DB_DIR = path.join(__dirname, '../data');
const shareLinks = require('../data/share-links.json');
总结： AI24X网站使用基于JSON文件的轻量级数据库系统，所有数据都存储在 data/ 目录下，用户数据存储在根目录的 users.json 文件中。这种设计简单易用，适合小型网站项目。
