## 一、双线架构

| 线 | 项目 | 参与 | 目标客户 |
|---|---|---|---|
| 🌍 国际流 | Token 平台（www/api.your-domain.com） | 主脑 + 01 + 04 | 国外开发者（AI API 用户） |
| 📈 A1 流 | AI 行情官（a.your-domain.com） | 主脑 + 02 + 03 | 股民/量化/行情爱好者 |

**执行约束：**
- 01 和主脑不能访问外网 → 外网调研/发布由 04 执行（国际流）
- 03 是 A1 生产环境 → 提供数据素材与验证（A1 流）
- 02 是 A1 市场运营 → 内容生产与渠道渗透
- **两条流水勿混**：国际 Token（01+04）≠ 行情官（02+03），词表独立

## 三、SEO 关键词打法（01 主责）

### 主攻簇（顺序）
1. **A 名模 + 性价比**（主攻）
2. **B 跨境痛点**（PayPal / outside China）
3. **C 接入案例**（OpenClaw / OpenAI compatible）
4. D 排错 FAQ · E 品牌收口

**不做主攻：** `best AI API`、`200+ models`、国内「免费 GPT」灰产词

### 名模词表（轮换，勿只写 DeepSeek）

| 优先 | 英文检索示例 |
|------|-------------|
| Kimi / Moonshot | Kimi API, Kimi 3, cheap Kimi API |
| 小米 MiMo | Xiaomi MiMo, MiMo API |
| MiniMax | MiniMax M2, cheap MiniMax API |
| 智谱 GLM | Zhipu GLM, GLM API |
| DeepSeek / Qwen | DeepSeek Flash, Qwen API |

**组词公式：** `{Model} API pricing` · `cheap {Model} API` · `{Model} API PayPal` · `{Model} OpenClaw` · `{Model} vs GPT cost`（数据诚实）

**节奏：** 每周至少 1 个名模主词专题/长文草稿（轮换：Kimi → MiMo → MiniMax → GLM → DeepSeek/Qwen）

## 四、技术 SEO 基建（04 配合 · 主脑定模板）

| 项 | 口径 |
|----|------|
| Google Search Console | 创建+验证+提交 sitemap（需老板 Google 账号） |
| your-domain.com → www 301 | 裸域重定向防重复内容 |
| canonical + og:image | 首页补丁（科设） |
| 完整 sitemap | 持续维护 |
| 国际页英文默认 + hreflang | 上线后验收 |
| title/description 一页一意图 | 主脑改模板；01 提词 |
| HTTPS / 站速 / 无死链 | 04 |
| 故障状态页 | 04；故障期减投放 |
| Bing Webmaster | 收录快，建议提交 |

**⚠️ 安全红线（最高优先）：本机 IP = 生产 IP，被搜索引擎封禁 = 超级麻烦！**
- ❌ 禁止高频直接爬 Google 搜索页（反爬会封 IP）
- ✅ 收录/索引查询一律走正规渠道：GSC / Bing Webmaster / 官方 API
- ✅ 低频、低量、间隔随机；遇验证码/429 立即停
- ✅ 宁可慢，不可封 IP
