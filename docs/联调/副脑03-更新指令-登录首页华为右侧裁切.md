# 副脑03 · 更新指令（登录首页华为右侧裁切）

> 发令：2026-08-04  
> **站点**：`a.ai24x.com`（行情官）  
> **进程**：静态为主；NSSM `AI24X-a1-web` 可选重启  
> 禁止整文件覆盖 `.env`

## 现象

部分华为浏览器打开登录首页：页面偏宽，「注册」与右侧「我的 / VIP」等按钮看不全。

## 本包

| 文件 | 说明 |
|------|------|
| `p/a1/web/index.html` | 加强视口校正；`(pointer: coarse)` 强制单列；按钮栅格可收缩 |
| `p/a1/web/css/base.css` | 默认关掉 `scrollbar-gutter: stable`；`overflow-x: hidden` |
| `p/a1/web/css/tool.css` | 粗指针下取消 input `min-width:180px` |
| `p/a1/web/sw.js` | 静态缓存 **v42** |

## 执行

```powershell
Set-Location C:\ai24x01
git checkout master
git pull origin master
git log -1 --oneline

Get-Service AI24X-a1-api, AI24X-a1-web | Format-Table Name, Status
# 静态为主；可选：
Restart-Service AI24X-a1-web
```

## 验收

1. 华为手机浏览器打开 https://a.ai24x.com/ （**强刷 / 清缓存**）  
2. 「登录 / 注册」两卡完整可见  
3. 「进入行情 / 我的 / 邀请 / VIP」四钮完整可见，无需左右滑  
4. 回报：`git log -1`、机型、是否通过  

## 回滚

```powershell
git checkout <上一稳定> -- p/a1/web/index.html p/a1/web/css/base.css p/a1/web/css/tool.css p/a1/web/sw.js
Restart-Service AI24X-a1-web
```
