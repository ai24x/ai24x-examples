## 背景（为何必须改）

- 运行时有 JS/i18n 时站点大体英文可用，但 **Google 广告快照 / 无 JS** 会读静态 HTML。
- 当前 `pricing.html` 仍含 **`http://127.0.0.1:18001/...`** 与中文默认文案 → 快照质量差，直接影响投放。
- 投流门禁：**下列 P0 未合并上线前，04 不开花。**

## P0（本周必须、挡开投）

### P0-1 清除国际落地页本地链接

**文件：** `web/pricing.html`（已核对仍存在）

| 现状 | 要求 |
|------|------|
| 「本地开通」→ `http://127.0.0.1:18001/account.html#vip`（至少 2 处） | **删除**本地按钮，或整块行情官专区对国际默认隐藏且快照不可见 |
| 「去体验」→ `http://127.0.0.1:18001/demo.html` | 同上 |
| 同区已有 `https://a.ai24x.com/...` | 若保留行情官区块：仅保留 **线上 a 站** 链接；文案英文或 `data-i18n-zh-only` 且确保 **默认英文快照不渲染该中文块** |

**验收：**

1. 源码检索 `pricing.html` **零匹配** `127.0.0.1` / `localhost`  
2. 浏览器禁用 JS 打开 `/pricing.html`：看不到本地地址、不以中文行情官区作为首屏主体  
3. 国际默认语言下，Token 套餐 + PayPal 说明仍清晰

**建议（二选一，优先 A）：**

- **A（推荐）**：国际站 `pricing.html` **整段移除**「AI 行情官｜灯塔版」卡片区（该区本就 `data-i18n-zh-only`，对投流无价值，易污染快照）  
- **B**：保留区块但去掉所有 localhost，只留 `https://a.ai24x.com/...`，且默认 `lang=en` 时不输出中文标题/按钮

### P0-2 广告相关页静态默认改为英文

**文件（优先）：** `pricing.html` · `register.html` · `login.html` · `console.html` · `models/**` 中面向广告用户的页

| 要求 | 说明 |
|------|------|
| `<title>` / 可见 fallback 文案 | 默认英文（与 `locales.js` en 一致） |
| `data-i18n` 节点的 HTML 默认文本 | 改为英文，避免无 JS 显示中文 |
| `<html lang>` | 默认 `en`（若已是则保持） |

**验收：** 禁用 JS 打开 pricing / register：标题与主标题为英文；无大段中文套餐说明作为唯一内容。

### P0-3（投流相关）控制台 API 占位符

**文件：** `web/console.html`

| 现状 | 要求 |
|------|------|
| `#api-base` placeholder `http://127.0.0.1:8000` | 改为生产友好占位，例如 `https://api.ai24x.com` 或留空 + 英文 hint「Production API host」 |

（逻辑上本机仍可由 `api.js` 自动指本地；仅改**用户可见 placeholder/文案**。）
