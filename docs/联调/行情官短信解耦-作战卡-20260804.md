03 上保留的早期主站备份（短信曾通）**有价值，要参考**，用法如下：

| 备份文档里有的 | 今日怎么用 |

| 曾通的 106 账号填法 | ✅ **恢复 A1 `sms_106_*` 主通道**时对照；现网若 101 先修账密 |

| 行情官发码走哪 | ✅ 03 本地 **`local`=106**；不经过 04 总开关 |
