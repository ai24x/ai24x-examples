# 副脑03 ·「登录已失效」其它原因排查（闭环验签）

> 前端已确认公网 `index.html` 含新修复、`sw=v23`。  
> 文案 **「登录已失效，请重新登录。」** 只在 `/api/me` 返回 **401/403** 时出现（`Invalid token` / `Missing token`）。  
> 邀请码、短信密钥 `iamlei` **都不会**直接写出这句。

## 可能原因（按概率）

| # | 原因 | 说明 |
|---|------|------|
| 1 | **签发密钥 ≠ 验签密钥** | 登录由 identity（core `SECRET_KEY`）签发 JWT；`/api/me` 用 a1 `AI24X_JWT_SECRET` 验签 |
| 2 | **改了 .env 但进程没吃到** | 必须 `pm2 restart <名> --update-env`；只 restart 或只改文件无效 |
| 3 | **identity 指到另一套 API** | `AI24X_IDENTITY_API_BASE`（或管理后台覆盖）指向的进程，其 `SECRET_KEY` 与 a1 验签密钥不是同一把 |
| 4 | **对错了 .env 文件 / 多份目录** | 仓库外还有拷贝；或 core 实际 cwd 不是你改的那个 `api\.env` |
| 5 | **密钥带引号/空格/省略号** | 一边是 `abc`，一边是 `"abc"` 或尾部空格；或曾被写成 `…` |
| 6 | **多实例 / 反代打到旧进程** | `pm2 list` 多个 a1-api，Nginx 指到未更新的那个 |
| 7 | （较低）浏览器旧 token | 无痕窗口可排除；公网 Authorization 能到上游（缺头是 Missing，坏签是 Invalid） |

主脑侧已测：无 Authorization → `Missing token`；乱 token → `Invalid token`。用户真实登录后仍失效 → **几乎总是验签失败（1–5）**。

## 闭环脚本（在副脑03打，把输出贴回主脑；不要贴密钥原文）

```powershell

from pathlib import Path

def load(path, name):
    text = Path(path).read_text(encoding="utf-8", errors="replace")
    for line in text.splitlines():
        s = line.strip()
        if not s or s.startswith("#"):
            continue
        if s.startswith(name + "="):
            v = s.split("=", 1)[1].strip()
            if (v.startswith('"') and v.endswith('"')) or (v.startswith("'") and v.endswith("'")):

    return ""

core_env = r""" + $coreEnv.Replace('\','\\') + """
```

### 如何读结果

- `FILE_MATCH=False` 或 `JOSE_CROSS_DECODE=FAIL` → 两把密钥仍不一致（含引号问题）  
- `FILE_MATCH=True` 且 `JOSE_CROSS_DECODE=OK` 但 `LOCAL_ME` 仍 401 → **进程内存里的密钥不是这份文件**（未 `--update-env` / cwd 错 / Nginx 打到别的实例）  
- `LOCAL_ME=200` 本机环回已通，公网仍失效 → 查 Nginx 是否把 `/api` 指到别的 upstream；用无痕再试

## 修复动作（对症）

1. 以 **identity 实际指向的那套 core** 的 `SECRET_KEY` 为准，把 a1 `AI24X_JWT_SECRET` 改成完全相同（记事本行级）。  
2.  
```powershell
pm2 restart <core名> --update-env
pm2 restart <a1-api名> --update-env
```  
3. 再跑闭环脚本，直到 `FILE_MATCH=True`、`JOSE_CROSS_DECODE=OK`、`LOCAL_ME` 非 401。  
4. 无痕打开 `https://a.ai24x.com/index.html` 登录验收。

## 回报主脑（可复制）

- `FILE_MATCH` / `JOSE_CROSS_DECODE` / `LOCAL_ME` 状态码  
- 两边 `len/tail/sha12`  
- `IDENTITY_API_BASE`  
- `pm2` 里 core / a1 的 **name + exec cwd + 端口**  
- 是否已两次 `--update-env`
