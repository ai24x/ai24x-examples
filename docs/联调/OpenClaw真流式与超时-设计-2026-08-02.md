# OpenClaw 可长期默认 AI24X · 真流式 + 超时 + 上下文（设计）

> 日期：2026-08-02  
> 状态：P1-A 实现中；P1-B（tools）二期  
> 目标：OpenClaw `baseUrl=…/v1` + `flash/pro` 多轮中等上下文不再 nginx 60s 504

---

## 1. 调用链现状（假流式）

```
OpenClaw → POST /v1/chat/completions?stream=true
  → main.chat_completions
  → ChatService.process_chat_request   # 整段等完上游
  → model_router.run_routed_chat → _call_openai_compatible (非 stream)
  → openai_compat.iter_sse_from_completion  # 把完整文本切片伪装 SSE
```

痛点：

| 点 | 现象 |
|----|------|
| 假流式 | 首包要等整段生成完，长上下文易超 nginx ~60s → 504 |
| 超时 | `TOKEN_LLM_TIMEOUT_S` 默认 **15s**，上游读超时过短 |
| 上下文 | `messages_to_prompt` **1 万字硬截**；上游只收「拼成一段的 user」，多轮被砍残 |
| baseUrl | OpenClaw 部分版本拼 `/chat/completions`（无 v1）→ 405；须 `…/v1` |

---

## 2. P1-A 目标架构（真流式）

```
stream=true
  → 鉴权 + 钱包预检（assert_can_spend / shared 日帽）同现网
  → run_routed_chat_stream：按现链选取上游，httpx stream=true 透传 SSE
  → 边收边写 OpenAI chunk（role / content delta / finish / [DONE]）
  → 流结束：按 usage.total_tokens（或估算）× billing_mult → consume_tokens / record_shared
```

改动面：

| 模块 | 改什么 |
|------|--------|
| `model_router._call_openai_compatible` | 支持 `messages=`；非流保持 |
| `model_router._call_openai_compatible_stream` | **新增** 上游 SSE 迭代 |
| `model_router.run_routed_chat_stream` | **新增** 同链 failover（仅「首包前」可换上游） |
| `ChatService.stream_chat_request` | **新增** 流末扣费 |
| `openai_compat` / `main.chat_completions` | stream=true 走真流式；放宽截断与 max_tokens |
| `/v1/chat/run` | **不改**（无回归） |

扣费时机：**流正常结束**后扣一次；客户端中断则尽量按已产出估算扣（防白嫖），失败未产出不扣。

Failover：已向客户端写出 content 后不再换上游（避免拼接错乱）。

## 3. 超时与反代（副脑04）

应用侧：

- `TOKEN_LLM_STREAM_TIMEOUT_S` 默认 **300**（读超时）
- 响应头：`X-Accel-Buffering: no`、`Cache-Control: no-cache`

Nginx（`api.ai24x.com` → core）建议：

```nginx
location /v1/chat/completions {
  proxy_pass http://127.0.0.1:8000;
  proxy_http_version 1.1;
  proxy_set_header Connection "";
  proxy_buffering off;
  proxy_cache off;
  proxy_read_timeout 360s;
  proxy_send_timeout 360s;
}
```

## 4. 上下文

- 截断：`TOKEN_PROMPT_MAX_CHARS` 默认 **120000**（原 10000）
- 上游优先传 **messages[]**（system 注入平台短 system；user/assistant 原样），无 messages 时再拼 prompt
- `max_tokens` 上限提到 **8192**（与 OpenClaw 档位示例对齐）

---

## 5. 风险与回滚

| 风险 | 缓解 |
|------|------|
| 流中断未扣费 | finally 按已累计文本估算扣 |
| 上游不发 usage | 文本长度估算（与现非流一致） |
| 真流式 bug | env `TOKEN_LLM_TRUE_STREAM=0` 回退假流式 |
| nginx 未改 | 仍可能 504；04 必须同步反代 |

回滚：关 `TOKEN_LLM_TRUE_STREAM` + 还原本设计涉及文件 + 重启 core。
