# L0 免费层联调（硅基流动）

DeepSeek（L1）Key 未通时，可用硅基流动免费额度先测通「平台 Key → 路由 → 扣费」全流程。

## 1. 注册拿免费 Key

1. 打开 https://cloud.siliconflow.cn  
2. 注册 / 登录 → API 密钥 → 创建  
3. 写入 `api/.env`：

```
SILICONFLOW_API_KEY=sk-你的硅基流动密钥
SILICONFLOW_BASE_URL=https://api.siliconflow.cn/v1
SILICONFLOW_MODEL=Qwen/Qwen2.5-7B-Instruct
```

```
pm2 restart core-8000 --update-env
```

## 2. 验证

http://127.0.0.1:8000/v1/models  

应看到：

- `upstream.l0_ready: true`
- `upstream.l1_deepseek_ready: true/false`（DeepSeek 另算）

控制台试调 `model=auto` 或 `siliconflow-free`：

- 成功：`provider: siliconflow`，`layer: L0`

## 3. 分层关系

| 层 | 用途 | 环境变量 |
|----|------|----------|
| L0 | 免费测试 / 引流 | `SILICONFLOW_*` |
| L1 | DeepSeek 主力 | `DEEPSEEK_*` |
| L2/L3 | 后续管理后台加 | `TOKEN_LLM_L2_*` … |

FREE 用户链：`L0 → L1`（L0 通了就不依赖无效 DeepSeek Key）。
