# 决策：国内外售价统一国际口径（2026-07-26）

- **国内市场（中国模型 API 付费开发者）可放弃**作营收主战场：以测试体验为主；真要规模开发的会直连大厂。
- **售价与产品权益与国际直接对齐**（不再国内倾销价 / 国际利润价双轨）。

- **唯一分轨：站点模板 + 结算通道 + 结算币种**

  - 套餐结构、路由、权益与「国际口径单价」对齐；国内收银台展示/扣的是按汇率折算后的 **CNY**，不是另做一套倾销价表

## 执行含义
1. **价表主数据 = 国际口径（建议 USD 锚定）**；国内收银台按汇率折 CNY 展示/扣款，不另做倾销体验价。
2. 取消「国内专属超低加油包 / 超大 VIP 日赠」作为长期策略（联调 Free 额度可保留严格日帽）。
3. Phase 1：微信/支付宝验履约；Phase 2：同一 SKU 上 PayPal 等。
4. **预留**：若引进国外大模型优惠版供国内，另开 SKU，不与中国模型国际价混表。
