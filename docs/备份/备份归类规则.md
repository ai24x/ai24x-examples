## 全量快照命名与内容

目录名：

```text
E:\AI24X\bak\ai24x01-YYYYMMDD_HHMMSS-<备注>/
```

例：`ai24x01-20260908_110434-BYOK基本正常版`

目录内至少：

| 项 | 说明 |
|----|------|
| `MANIFEST.md` | 时间、备注、git、库列表、回滚步骤 |
| `code/` | 代码树（或等价完整代码） |
| `databases/` 或 `databases/pgsql/` | `pg_dump -Fc` |
| `env_snapshots/` | `.env` 副本（勿外传） |
| `ai24x01.bundle` 或 `*.bundle` | git bundle |
| `ROLLBACK.md`（推荐） | 回滚命令 |

指针（二选一或都写）：

- `E:\AI24X\bak\LATEST_FULL.txt` → 指向最新全量绝对路径  
- `ai24x01\_backups\LATEST_FULL.txt` → 同上（便于仓内查找）
