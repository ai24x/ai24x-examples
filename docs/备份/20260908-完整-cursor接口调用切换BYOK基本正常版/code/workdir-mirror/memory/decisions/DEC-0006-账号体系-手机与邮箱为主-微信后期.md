# DEC-0006：账号体系（主站 / AI 行情官通用口径）

## 状态

已定稿（2026-04-18）

## 决策

1. **主身份与注册入口**：以 **手机号码 + 邮箱** 为主账号维度（可合并为「手机优先、邮箱辅助」或「双绑均可登录」，实现阶段再定字段约束）。
2. **登录方式（首期）**  
   - **手机号**：支持 **短信验证码登录**（及/或与密码并存，由产品二选一或并存）。  
   - **密码**：保留 **密码登录**（适用于已设密用户；邮箱登录通常走密码更常见）。  
3. **忘记密码 / 找回（首期必做）**  
   - **已绑定手机**：通过 **短信验证码** 校验身份后，允许 **设置新密码**（或走「无密码 + 仅验证码登录」策略时，可定义为「验证码登录后引导设密」二选一，对外统一称「找回账号访问」）。  
   - **已绑定邮箱**：通过 **邮箱内一次性链接**（推荐）或 **邮箱验证码** 校验后重置密码；链接/码 **短时有效、单次使用、作废旧会话**（与手机路径一致的安全基线）。  
   - **双绑**：用户任选其一通道；**均未绑定** 则只能走人工/工单（不在产品自助流程内承诺）。  
4. **微信**：**服务号/开放平台能力不挡首期上线**；**后期再补**「微信扫码登录 / 注册与账号绑定」，与已有手机/邮箱账号做 **绑定合并**（避免一人多号不可合并）。
5. **短信通道（已定）**：首期国内验证码走 **106 utf8 网关**（`api/sms_106_client.py` + `POST /v1/auth/sms/send`）；**腾讯云 SMS 作为备用通道**后期接入或双活。**密钥仅环境变量**，禁止写入仓库与聊天明文。

## 理由

- 首期 **不依赖微信审核链路**，开发、测试与合规沟通路径最短。  
- 手机验证码 + 密码覆盖 **无微信** 与 **弱微信意愿** 用户；微信作为 **增量转化** 而非唯一入口。

## 实现时注意（P0）

- 短信：**限频、图形/行为验证码、黑名单、成本监控**；对接 **腾讯云 SMS** 时区分 **登录 / 注册 / 找回** 等模板（或同一模板变量语义固定），并记录 **发送失败与回执** 便于排障与对账。  
- 密码：**强度策略、bcrypt/argon2**；**重置令牌** 与登录会话 **分离存储**，重置成功后 **可选踢掉全端 refresh token**（按安全等级选）。  
- 找回页：**不提示「该手机是否已注册」**（防枚举）；统一文案「若账号存在将发送验证码/邮件」。  
- 同一自然人：**手机 / 邮箱 / 微信 openid** 的绑定与冲突合并策略需写清（后期补微信时一次做对）。

## 首期页面与流程（产品约定）

### 入口

- 全站统一：**「登录」**、**「注册」** 两个入口（或登录页底部「没有账号？注册」）；**不出现微信扫码**（页脚可灰字「更多登录方式敬请期待」占位即可）。

### 登录页 / 注册页布局（同一套壳）

- **主切换**：顶部 **分段控件**「**手机号** | **邮箱**」，用户明确二选一。  
- **默认选中**：**手机号**（国内主路径；与腾讯云短信一致）。若某环境更偏海外，可配置为默认邮箱（实现时用配置项切换，产品默认仍建议手机）。
- **（2026-04 主站静态页）**：`web/login.html`、`web/register.html` 已实现 **手机号 + 密码** 与 **邮箱 + 密码** 二选一，**默认手机**；请求体为 `{ phone, password }` 或 `{ email, password }`。短信验证码登录/注册待后端与腾讯云就绪后按下列「手机号」小节叠加，不冲突。

### 手机号

- **登录**  
  - 同一页内 **子切换**：「**验证码登录**」|「**密码登录**」（或次要入口用链接切换，避免三排 tab 过重）。  
  - 「**忘记密码**」仅在 **密码登录** 视图显示；走短信验证后设新密码（与 DEC §3 一致）。  
- **注册**  
  - 手机号 → **短信验证码** → **设置密码**（推荐注册即设密，与「仅验证码登录」并存不矛盾）→ 勾选用户协议 → 完成。  
- **发送验证码**：场景区分 **注册 / 登录 / 找回**（后端校验模板与限频；文案防枚举）。

### 邮箱

- **登录**：邮箱 + 密码；「**忘记密码**」→ 邮件内 **一次性重置链接**（推荐）。  
- **注册**：邮箱 → **发验证邮件**（点击链接或填写邮件内验证码）→ **设置密码** → 勾选协议 → 完成。  

### 登录后

- **账号中心**提供 **绑定另一方式**（已有手机可绑邮箱、反之），避免注册时强迫双填；冲突合并规则单独实现（DEC §4 后期微信同理）。

## 后续动作（非本期阻塞）
