# DEC-0011：生产备份与回滚最小可靠策略（PG 为主，含异地与演练）

## 结论（最小可靠）

生产环境不要只保留“最近 2–3 天”。推荐最小可靠策略：

- **备份内容**：程序快照 + 配置快照 + PostgreSQL 全量备份（每个库）+（可选）关键数据目录
- **保留周期**：
  - 每日全量保留 **7 天**
  - 每周全量保留 **4 周**
  - 每月全量保留 **3–6 个月**
- **异地备份**：至少 1 份落到另一台机器/NAS/对象存储（与部署机物理隔离）
- **唯一标准**：定期恢复演练（不演练等于没备份）

## 回滚原则（先快后稳）

- 绝大多数事故先走 **代码/静态回滚 + 服务重启**（最快、影响面小）。
- 仅当确认涉及“表结构/不可逆数据写入”时，才进行 **整库恢复**（恢复前再做一次快照）。

## SQLite 策略

- SQLite 后续不作为生产主流程数据库：
  - **封存归档（只读对照）**，不删除但禁止继续作为现行口径
  - 新环境/新版本默认使用 PostgreSQL

## 进阶（建议）

- 稳定后为 PostgreSQL 开启 **PITR（WAL 归档时间点恢复）**，用于“回到误操作前 5 分钟”。
