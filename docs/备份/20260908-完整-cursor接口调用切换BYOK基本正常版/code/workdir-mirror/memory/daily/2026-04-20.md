## 作战卡（2026-04-20）— VIP年卡赠普通代理 + 返佣台账（人工结算）

### 上线口径（一句话）
购买 **VIP 年卡（999）** 支付成功后：开通 VIP（配额/到期顺延）并**赠送普通代理身份**；普通代理推荐带来的 **VIP 年卡（999）订单** 按 **20%** 生成返佣台账，**T+7** 进入可结算，先由后台**人工打款并标记**，不做自动打款与多级分佣（仅预留）。

### 链路 A（产品/前端/用户路径）
- **入口**：年 VIP 购买页（微信 Native 下单）→ 支付 → 成功后权益生效
- **代理侧**：个人页显示“普通代理（随年 VIP 赠送）”与到期；提供邀请码/推广链接（沿用现有 invite_codes）
- **后台**：代理与返佣面板

### 链路 B（后端/数据/部署）
- **订单表**：`pay_orders` 固化 `referrer_user_id` + `paid_at`（预留 refund 字段但默认不启用）
- **代理身份表**：`agent_status(user_id, level, expires_at, updated_at)`
- **返佣台账表**：`commission_ledger(out_trade_no UNIQUE, agent_user_id, buyer_user_id, plan, amount_fen, rate, commission_fen, eligible_at, status, paid_at, paid_note, created_at, updated_at)`
- **生成点**：微信回调 `pay_order_try_fulfill_wechat` 里完成：发放 VIP → 赠代理 → 固化推荐人 → 幂等生成返佣
- **动态配置（admin_config）**：
  - `agent_commission_enabled`（默认 1）
  - `agent_commission_rate_normal`（默认 0.20）
  - `agent_settle_delay_days`（默认 7）
