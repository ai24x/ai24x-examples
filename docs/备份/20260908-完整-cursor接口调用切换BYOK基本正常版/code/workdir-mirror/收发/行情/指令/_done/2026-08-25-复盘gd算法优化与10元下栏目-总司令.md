## 一、雷总反馈的两个问题

1. **主线滞后**：经常"刚找出的主线"就可能变成砸盘追高的板块（买在右侧中后段，容易接盘）。
2. **标的偏弱**：推荐选出的标的大多弱势、非强势；希望找出"刚右侧起来、特别强势"的标的。
3. **栏目优化**：沪深主线 / 科创主线 / 北证主线 / 北证全市场 / MACD首红 / 回踩企稳，6 个栏目都需要优化。
4. **新增栏目**：加「10元下」——找出符合优质标的（刚右侧起来）且股价 <10 元的标的。

## 二、根因诊断（总司令审码结论，供行情官复核）

代码位置：`p/a1/api/server/app/bj_screener.py`（约 283KB，六栏目共用核心）。

### 问题1 根因：主线识别是"滞后指标堆积"
- `reverse_mainline()`：从"已经异动过的票"（surgeStart/pullback2/ztPullback 等形态）反推题材 → 题材已经涨过一波才被识别。
- `board_hit()` 用东财 `f62`（今日主力净流入）+ `f164`（5日）确认热门 → 追的是"已经流进"的资金。
- `_fine_pass()` 对 mainHit/revHit 额外加分 → 越涨的板块越被反复确认，形成正反馈追高。
- 本质：主线确认走的是"累计涨幅 + 累计资金净流入"，是右侧已走出后才锁定，等于让用户在右侧中后段进场。

### 问题2 根因：筛选参数结构性偏好"低位+没涨"（防守形态）
- 硬门槛 `posMax=30`、`max5d=20`、`max10d=30`、`max60d=45` → 把"已经强势起来"的票卡在门外。
- `score_steady_up()` 给"稳步慢涨"打分（斜率 0.05%/日就给分）→ 弱趋势票反而得分高。
- `_evp()` 事件回踩优先 → king 位倾向"已回踩、短期动能偏弱"的票。
- final 分由位置/基本面/趋势/龙虎榜堆叠，强势动量（涨停/大阳/放量/创新高速度）只作 pattern 标签，不主导分数。
- 结论：当前 = "低位 + 回踩企稳 + 稳步向上"防守形态，天然选出弱势/滞涨票，与"刚右侧起来特别强势"相悖。

## 三、优化方案（分优先级）

### P0（解决两个核心问题）
1. **主线去滞后化**：主线排序权重从"累计涨幅/资金净流入"改为"增量动量"——
   - 板块内个股近 1-3 日「新增异动家数」（增量，非存量）
   - 量能拐头（今日放量 / 缩量后反转）
   - 涨停梯队晋级率（连板晋级 vs 炸板率）
   - 「首次上榜」优先（现有 ml_src=new 已有，需在排序权重里提前）
   - 连续上榜 N 日的板块 → 标记"高位过热"并降级（现有 overheat 标记未参与过滤）。
2. **新增「强势动量」评分轴**，作为 final 的独立加权项（与现有位置/基本面并列）：
   - 近 3 日涨幅斜率、涨停/大阳次数、量比、创新高速度、RSI 加速度、主力净流入拐头
   - 目标：让"刚右侧起来、放量、有涨停/大阳确认"的票分数压过"低位慢涨"的票。
3. **king 位口径调整**：king 位改"强动量 + 主线共振"，回踩低吸类降为备选/卡位角色，不再霸占 king。
4. **门槛校准**：用"右侧刚起 = 近期强动量 + 位置仍在中低位(<60%)"取代"位置<30% + 没涨"，避免误杀强势启动票。

### P1（栏目精简/去重）
- hs/kc/bj/bj_all 四个栏目本质是"池子不同、算法相似"，建议收敛为统一的"强势主线 + 强势标的"双轴口径，保留市场池差异（沪深/科创/北证/北证全市场）。
- macd/pb 是形态子集，保留但统一接入"强势动量"轴，避免口径割裂。

### P2（新增「10元下」栏目）
- 入选口径 = 复用"优质标的（刚右侧起来+强势）" + 价格 <10 元。
- 硬伤排除：ST/退市、面值退市警戒（<2 元）、流动性门槛（成交额/换手下限）、一字板不可交易。
- 建议独立 market_code（如 `low10`），前端 gd.html 加一个 tab，后端 `run_scan` 增加 market 分支与配置。
