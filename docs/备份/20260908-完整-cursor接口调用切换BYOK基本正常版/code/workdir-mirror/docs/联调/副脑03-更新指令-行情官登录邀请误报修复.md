> 发令时间：2026-07-27  
> 目标提交：`4bccd89`（`fix(a1): 登录成功后不再被邀请码绑定失败误报盖住`）

## 现象（已定位）

用户密码正确，登录接口成功，但页面提示「邀请码绑定失败，可在用户中心再试。」——实为浏览器残留分享邀请码在登录后自动绑定失败，**盖住了「登录成功」**。

## 本次改动范围（仅前端静态，不动支付/业务逻辑）

- `p/a1/web/index.html` — 登录不再自动消费 localStorage 邀请码；绑定失败不覆盖登录成功文案  
- `p/a1/web/account.html` — 邀请绑定失败提示软化  
- `p/a1/web/sw.js` — 缓存 `v22` → `v23`  
- `p/a1/web/js/shell.js` — SW 注册 `?v=23`  
- （顺带）`p/a/web/index.html` — 同口径（若 03 仍挂 p/a 静态则一并生效）

**不要**改 `.env`、不要改 `SMS_INTERNAL_KEY`、不要动支付回调。本指令只拉代码并刷新静态。
