# 副脑03 · 行情官忘记密码短信失败（内部密钥）

> 发令：2026-07-28（NSSM 版）  
> 现象：忘记密码发验证码 →「内部服务密钥未配置，请联系管理员」  
> 根因：`a.ai24x.com`（a1）转发主站 `/v1/auth/sms/send` 时，`X-SMS-Internal-Key` 缺失或与主站不一致。  
> **进程管理**：现网已 **PM2 → NSSM**，用 Windows 服务重启，**不要**再跑 `pm2 list` / `pm2 restart`。  
> **禁止**整文件覆盖 `.env`；只行级改键；勿动支付回调。

## 对齐规则（必须两边一致）

| 服务（NSSM） | `.env` 文件 | 键名 |
|--------------|-------------|------|
| `AI24X-core` | `C:\ai24x01\api\.env`（以现网路径为准） | `SMS_INTERNAL_KEY=...` |
| `AI24X-a1-api` | `C:\ai24x01\p\a1\api\server\.env` | `AI24X_SMS_INTERNAL_KEY=...`（**与上一行完全相同**） |

另确认 a1：`AI24X_IDENTITY_API_BASE=https://api.ai24x.com`（或内网可达的主站 API 根）。  
Nginx 服务本次**不用动**（只改密钥 + 重启两个 API 服务）。

---

## 执行（PowerShell · 可整段给 OpenClaw）

```powershell
# 0) 确认服务在（名称以现网为准）
Get-Service AI24X-core, AI24X-a1-api | Format-Table Name, Status, StartType

# 1) 脱敏核对主站密钥（不要把完整值贴回对话）
$coreEnv = "C:\ai24x01\api\.env"   # 若路径不同自行改
Select-String -Path $coreEnv -Pattern '^SMS_INTERNAL_KEY=' | ForEach-Object {
  $v = (($_.Line -split '=',2)[1]).Trim().Trim('"').Trim("'")
  "SMS_INTERNAL_KEY set=$([bool]$v) len=$($v.Length) tail=***$($v.Substring([Math]::Max(0,$v.Length-4)))"
}

# 2) 脱敏核对行情官密钥
$a1Env = "C:\ai24x01\p\a1\api\server\.env"
Select-String -Path $a1Env -Pattern '^AI24X_SMS_INTERNAL_KEY=' | ForEach-Object {
  $v = (($_.Line -split '=',2)[1]).Trim().Trim('"').Trim("'")
  "AI24X_SMS_INTERNAL_KEY set=$([bool]$v) len=$($v.Length) tail=***$($v.Substring([Math]::Max(0,$v.Length-4)))"
}
# 期望：两边 set=True，len 相同，tail 相同。不一致则只改 a1 去对齐「当前主站」的值。

# 3) 行级对齐（主站已有正确值时）：记事本打开 a1 .env
#    确保存在一行（无引号、无首尾空格、无省略号 …）：
#    AI24X_SMS_INTERNAL_KEY=<与主站 SMS_INTERNAL_KEY 完全相同>
#    AI24X_IDENTITY_API_BASE=https://api.ai24x.com
# notepad $a1Env

# 4) 若主站 SMS_INTERNAL_KEY 为空：先给主站行级写入强随机，再复制到 a1，再两边重启
# notepad $coreEnv

# 5) NSSM / Windows 服务重启（加载新 .env；勿用 pm2）
Restart-Service AI24X-core
Restart-Service AI24X-a1-api
Start-Sleep -Seconds 3
Get-Service AI24X-core, AI24X-a1-api | Format-Table Name, Status

# 6) 本机健康（端口以现网为准，常见 core=8002 a1=8001）
try { (Invoke-WebRequest "http://127.0.0.1:8002/health" -UseBasicParsing).StatusCode } catch { $_.Exception.Message }
try { (Invoke-WebRequest "http://127.0.0.1:8001/health" -UseBasicParsing).StatusCode } catch { $_.Exception.Message }
```

也可在行情官管理台「短信 → 内部密钥」填与主站相同的值并保存，然后仍须 **`Restart-Service AI24X-a1-api`**（若后台热加载已生效可跳过，以验收为准）。

## 验收

1. 打开 https://a.ai24x.com 忘记密码入口  
2. 填手机号 → 发送验证码  
3. 应提示已发送，**不再**出现「内部服务密钥…」  
4. 回报主脑：两边 `len` / `tail` 是否一致、两服务 Status=Running（**不要贴完整密钥**）

## 注意

- **不要** `pm2 list` / `pm2 restart` / 整文件 Write 覆盖 `.env`  
- 自检：无引号、无空格、无 Unicode 省略号 `…`  
- 本机开发 Key ≠ 生产 Key，勿把本机值盲目拷到生产  
- **2026-07-28 实锤**：a1 曾为 `sms-internal-ai24x-local-2026`（本机串）而对 core 为另一套短串；且 `AI24X_IDENTITY_API_BASE` 误为 `http://127.0.0.1:8000`。生产必须 `https://api.ai24x.com` + 与 core 同钥。  
- **P1**：现网钥仅 9 位且已出现在协作回执中，建议双方轮换为强随机后再重启 `AI24X-core` / `AI24X-a1-api`（勿贴完整值）。
