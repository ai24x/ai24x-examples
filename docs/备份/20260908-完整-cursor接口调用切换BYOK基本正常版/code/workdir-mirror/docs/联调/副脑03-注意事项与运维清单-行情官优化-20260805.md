## 二、下次更新副脑03 时的注意事项（按序执行）

1. **备份先行**：更新前在 03 先做一次全量备份（代码 + 数据库），确认成功再动手。
2. **拉码**：`git pull`（代码/文档会随 Gitee 同步；`.env` 不进 git，03 需手工改）。
3. **.env 手工核对**（不要复制粘贴明文密钥到聊天/指令）：
   - `AI24X_ADMIN_KEY`：与本地保持一致，**暂不轮换**（用户已确认）。
   - `sms_active_provider=tencent`：短信验证码走腾讯云直发。
   - `AI24X_JWT_SECRET_PREV`：**2026-08-12（7 天 token 有效期届满）后删除**并重启，本机与 03 同步操作。
   - `promo_tier_enabled=1` + 三档返点 `promo_tier_rate_bronze/silver/gold`（金银铜阶梯，见 102 更新指令）。
   - 定价项：`price_vip_trial_fen=880 / price_vip_month_fen=88800 / price_vip_year_fen=888800 / price_agent_growth_fen=500000 / price_agent_pro_fen=1000000`。
4. **测试订单标注同步**：若 03 库含同样 15 笔历史订单，执行同一条 upsert（`test_paid_order_ids` 等三键，见《测试价订单对账记录-20260805》），保持口径一致。
5. **重启与验证**：NSSM 重启 API/Web 服务，验证 health、后台短信登录、行情查询、build_stamp。
6. **密钥纪律**：Gitee 仓库含远程地址里的 token（ai24x01.git 的 https 凭据），勿外传；任何聊天指令不出现密钥明文。

## 三、回滚预案

- 代码：03 用更新前备份的 `code/` 还原，NSSM 重启。
- 数据库：`pg_restore --clean --if-exists -d <URL> 更新前.dump`。
- 配置：用备份 `env_snapshots/` 还原 .env。
