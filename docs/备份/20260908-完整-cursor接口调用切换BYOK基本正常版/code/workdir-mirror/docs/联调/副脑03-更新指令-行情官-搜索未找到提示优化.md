## 改动内容
- 搜索无任何匹配时：提示改为「未找到对应标的：请检查输入是否有误，或换关键词/输入代码（如 600519、贵州茅台）。」
- 单个弱匹配自动加载但 K 线失败时：不再显示「kline temporarily unavailable」等技术报错，统一提示「未能加载「xxx」：请检查输入是否有误…，如代码无误请稍后重试。」
- 查询进行中连点搜索时：提示「正在查询中，请稍候…」，不再无声无息。

3. 搜索 `600519` → 正常出图
