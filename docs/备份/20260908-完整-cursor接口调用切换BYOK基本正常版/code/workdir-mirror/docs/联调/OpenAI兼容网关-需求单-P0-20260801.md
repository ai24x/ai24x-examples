# AI24X OpenAI 兼容网关需求单（P0）

> 提交方：AI24X 指挥中心（主脑）· 2026-08-01 · 雷总转 Cursor 开发
> 背景：国际获客核心依赖开源生态接入。当前主接口为私有格式 `POST /v1/chat/run`（prompt 单字符串 + X-API-Key），**主流开源应用（LobeChat/Open WebUI/Dify/LangChain/AnythingLLM/Cursor/Claude Code）无法接入**——它们只认 OpenAI 兼容接口。DeepSeek 官方已完全兼容 OpenAI，可免代码直连，我们必须跟上。

---

## 一、目标

新增 **OpenAI Chat Completions 兼容接口**，使主流开源应用/工具可"复制即用"接入 AI24X，一次适配、批量接入整个生态。

## 二、接口规格（对标 OpenAI /v1/chat/completions）

```
POST /v1/chat/completions
Authorization: Bearer <AI24X_API_KEY>
Content-Type: application/json
```

请求体（OpenAI 标准）：
```json
{
  "model": "flash",            // 或 pro / ultra / vip-kimi / vip-gpt5 等
  "messages": [
    {"role": "system", "content": "..."},
    {"role": "user", "content": "..."}
  ],
  "stream": true,              // 支持 SSE 流式
  "temperature": 0.7,
  "max_tokens": 2048
}
```

响应（OpenAI 标准格式）：
```json
{
  "id": "chatcmpl-...",
  "object": "chat.completion",
  "created": 1234567890,
  "model": "flash",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "..."},
    "finish_reason": "stop"
  }],
  "usage": {"prompt_tokens": 10, "completion_tokens": 20, "total_tokens": 30}
}
```
流式：SSE 事件 `data: {...}` + 结束 `data: [DONE]`（OpenAI 标准 chunk 结构，含 delta.content）。

## 三、功能要求

1. **messages → 内部格式转换**：OpenAI messages 数组 → 现有上游所需格式（system/user/assistant 拼接或透传）；工具调用 messages（tool/role）需兼容或明确降级
2. **认证**：Bearer Token → 校验现有 API Key（与 X-API-Key 同一密钥体系）
3. **model 映射**：OpenAI 生态常用名 → 平台路由（如 gpt-4o/自定义名 → flash/pro；无匹配默认 flash）；支持平台自身别名 flash/pro/ultra/vip-*
4. **流式 SSE**：支持 stream=true（重要——多数应用默认开流式）
5. **兼容面**：至少覆盖 LobeChat、Open WebUI、Dify（OpenAI 兼容模式）、LangChain、AnythingLLM、Cursor、Claude Code（OpenAI 兼容端点）、n8n、vLLM 客户端
6. **错误格式**：OpenAI 风格错误 JSON（`{"error": {"message": "...", "type": "...", "code": "..."}}`）
7. **不影响现有**：/v1/chat/run 保持原样，双接口并存；路由/计费/用量逻辑复用

## 五、验收标准

1. `curl -X POST https://api.ai24x.com/v1/chat/completions -H "Authorization: Bearer <key>" -d '{"model":"flash","messages":[{"role":"user","content":"hi"}]}'` → 200 OpenAI 格式响应
2. stream=true → SSE 正常流式 + `[DONE]`
3. **Open WebUI 实测连接成功**（填 base_url + key → 对话通）
4. **LobeChat 实测连接成功**（自定义 OpenAI 兼容提供商）
5. **LangChain / AnythingLLM 实测通**（任选 1-2 个）
6. 现有 /v1/chat/run 回归无影响（环回 health + 一次对话）
7. 错误路径（无效 key/超限/未知模型）返回 OpenAI 风格错误
