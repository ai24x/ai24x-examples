# AI24X Token 聚合平台 · 完整产品规划（国际优先版）

> **版本**：v2.0 · 2026-07-25 · 主脑 AI24X永生
> **目标**：发给 Cursor（AI编程工具）作为开发参考
> **范围**：AI行情官（维护）+ Token聚合平台（主力）+ 副脑体系（底座）

---

## 一、核心方向

**国际优先。** 国内仅供测试验证，主力市场面向全球开发者。

### 为什么国际优先
- 国内开发者直接去 DeepSeek/Kimi 官网注册就行，不需要中间商
- 国际开发者想用 DeepSeek Flash（¥0.14/M）但注册门槛高、没英文文档
- DeepSeek Flash $0.02/M vs GPT-4o $15/M —— 150 倍价差，开发者自己会算账
- 国际支付（PayPal/Stripe）比国内支付（微信商户号）简单太多
- 副脑04 如果在新加坡/海外，就是完美的中转节点

### 战略定位
**中国模型的全球 API 超市** —— 把 DeepSeek、Kimi、豆包、通义等国产模型打包成一套国际开发者能直接用的 API。

## 二、双项目并行

### ① AI行情官（P2 · 维护模式）
- 产品在线，Bug 修复，不推不投
- 20个种子群轻运营
- 等牛市信号触发自动升级推广优先级
- 成本 ≈ ¥0/月（服务器已在跑）

### ② Token 聚合平台（P0 · 主力开发）
- MVP：注册 → 获取 API Key → 调 /v1/chat/run → 按 token 扣费
- 面向国际开发者为主
- 英文文档 + PayPal/Stripe 支付

## 三、模型路由策略

```
L0 免费引流层 → GLM-4-Flash(¥0) / SiliconFlow(极低价)
L1 白菜主力层 → DeepSeek Flash (¥0.14/M)
L2 VIP 增强层 → DeepSeek Pro (¥1.74/M)
L3 扩展层 → Kimi K3 / 豆包 Pro / 通义千问 / MiniMax
```

### 定价建议（国际）
| 模型 | AI24X 售价 | 对标国际价 | 优势 |
|------|-----------|----------|------|
| DeepSeek Flash | $0.03/M | GPT-4o $15/M | 便宜 500 倍 |
| DeepSeek Pro | $0.25/M | GPT-4o $15/M | 便宜 60 倍 |
| Kimi K3 | $0.30/M | Claude $15/M | 便宜 50 倍 |

### 容错链
```
FREE 请求 → SiliconFlow → DeepSeek Flash → GLM-4-Flash → 503
                         ↓ 3s 超时逐级 fallback

VIP 请求 → DeepSeek Flash → DeepSeek Pro → 豆包 Pro → Kimi K3 → 503
                         ↓ 5s 超时逐级 fallback
```

## 四、MVP 要做的事（P0 优先）

### 三个 501 接口
见 `TASK-TOKEN-MVP.md`，包括 API Keys 管理、计费系统、推荐返利。

### 额外需要做的

#### 1. 英文文档（P0）
- 英文首页（en.ai24x.com 或子路径）
- 英文 API 接入文档（快速开始、示例代码）
- 英文定价页（清晰列出 $0.03/M 等价格）

#### 2. PayPal 支付接入（P0）
```
用户点击充值 → 跳转 PayPal → 支付成功 → 余额到账 → 可用
```
PayPal API 对接文档：https://developer.paypal.com/docs/api/overview/

#### 3. 国际化部署
- 副脑04 如果是海外服务器 → 部署前端站 + 中转代理
- 国内用户连国内服务器，国际用户连海外节点

#### 4. 免费试用额度
- 新注册用户赠送 10,000 token 免费试用
- 每日限 100 次请求（防刷）
- 超过后提示充值

#### 5. 使用统计页面
- 用户能看到自己的 token 用量、请求次数、消费金额
- 按天/按模型汇总

## 五、系统架构

```
国际开发者 → www.ai24x.com/en → 英文文档 + 定价
              ↓
        副脑04（海外节点） → PayPal/Stripe 支付
              ↓
        副脑01（国内核心） → API 网关 + 缓存
              ↓ 路由
        DeepSeek / Kimi / 豆包 / 通义
```

### 副脑分工

| 副脑 | 角色 | 职责 |
|------|------|------|
| 副脑01 | Token 核心 | API 网关、缓存代理、预发布，4核8G |
| 副脑02 | 内容运营 | 社媒内容、教程文档、邮件通知（待部署 OpenClaw） |
| 副脑03 | 运维监控 | PM2、Nginx、安全告警、自动止损（已公网服务中） |
| 副脑04 | 国际中心 | 英文文档、PayPal/Stripe、海外社媒、中转节点（待启动） |

### 开发流程
```
Cursor 写代码 → 你本地测试 → git push GITEE
→ 副脑01 后台自动 Review（不阻塞）
→ 需要发版时：副脑01 预发布验证 → 副脑03 生产部署
```

## 六、改进建议

1. **副脑04 位置确认** — 副脑04（43.160.246.30）如果在海外（新加坡/美西），作为国际中转节点；如果在国内，先做英文内容和文档，出海节点另配
2. **PayPal 先上** — Stripe 要企业资质才能提现，PayPal 个人户也能收钱，前期更灵活
3. **定价留余量** — Flash 成本 $0.02/M，卖 $0.03/M 有 50% 毛利，但价格锚定 GPT-4o 的 $15/M，开发者觉得超便宜
4. **防刷** — 免费额度设 IP+设备指纹+日上限三件套
5. **邮件通知** — 注册确认、支付成功、余额不足时发邮件通知用户
