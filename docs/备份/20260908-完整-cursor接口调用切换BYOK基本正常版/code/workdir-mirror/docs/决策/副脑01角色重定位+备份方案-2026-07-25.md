## 三、移动硬盘备份方案

### 硬件
- 1TB+ 移动硬盘（USB 3.0，最好 SSD）
- 每周一插入，自动备份完成后可拔走（异地存放更安全）

### 备份范围

| 内容 | 路径 | 频率 | 方式 |
|------|------|------|------|
| 项目源码 | `E:\AI24X\ai24x-website\` | 每日增量 / 每周全量 | robocopy 镜像 |
| 数据库 | PostgreSQL dump | 每日 | pg_dump |
| OpenClaw 配置 | `~/.openclaw/` | 每周 | 打包压缩 |
| 帮助指南文档 | `E:\AI24X\帮助指南\` | 每周 | robocopy 镜像 |
| 工作记忆 | workspace memory | 每日 | 同步到帮助指南目录 |

### 备份脚本（Windows PowerShell）
```powershell
# 每日自动备份到移动硬盘 D:\AI24X_Backup\
robocopy E:\AI24X\ai24x-website D:\AI24X_Backup\ai24x-website /MIR /R:2 /W:5
pg_dump -U postgres -d ai24x -f D:\AI24X_Backup\db\ai24x_$(Get-Date -Format yyyyMMdd).sql
robocopy E:\AI24X\帮助指南 D:\AI24X_Backup\帮助指南 /MIR /R:2 /W:5
```

### 自动化
- 副脑03 的 cron 每日凌晨 3:00 触发备份
- 备份完成 → 飞书通知主脑
- 备份失败 → 飞书告警
