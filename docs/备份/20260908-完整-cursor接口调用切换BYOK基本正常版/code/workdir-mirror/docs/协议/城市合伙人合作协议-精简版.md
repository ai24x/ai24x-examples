## 一、合作性质
1.1 甲方运营「AI行情官」（a.ai24x.com）行情数据可视化工具；乙方自愿成为甲方在上述区域的授权城市合伙人，开展产品推广与客户基础服务合作。
1.2 本协议为**信息服务与市场推广合作**，不构成证券投资咨询关系，亦不构成合伙、代理（表见代理除外）或劳动关系。

## 二、产品定位与合规红线
2.1 产品为行情数据可视化工具。乙方推广时应如实描述，**不得**作出收益承诺、盈亏保证或投资建议；不得代客理财、代客操盘、非法荐股。
2.2 乙方**不得**以发展人员数量或收取费用作为计酬依据（禁止传销）；不得组织或参与任何形式的“拉人头”返利。
2.3 乙方不得冒用甲方名义对外签约、收款或作出超出授权范围的承诺；因乙方越权行为产生的后果由乙方自行承担。

## 三、业绩与结算
3.1 返点以“乙方邀请并经平台系统记录为**已支付订单**”的实付金额为基数计算；返点比例与结算周期以平台后台规则为准（当前试点：直推 15%~25% 按推广等级，T+7 可结算）。
3.2 现金结算是**签约试点模式**，乙方须提供有效开票/收款信息：
- 企业乙方：按实付金额开具“信息技术服务费 / 推广服务费”发票；
- 个人乙方：甲方依法代扣代缴个人所得税，或按甲方要求提供合规结算方式。
3.3 未开通现金试点的合作期间，回馈以查询额度、会员权益等**非现金形式**发放，不可提现、不可转让。
3.4 因退款、风控或违规处理导致订单取消的，对应返点/回馈相应冲减；乙方不得自买自返、恶意刷量。

4.1 甲方义务：提供推广链接/物料与后台结算记录；按约结算；因运营或监管需要调整规则时提前公告。
4.2 乙方义务：真实宣传、维护品牌形象、及时解答其客户的基础咨询；不得批量注册、养号刷量或进行任何影响平台正常运行的行为。
