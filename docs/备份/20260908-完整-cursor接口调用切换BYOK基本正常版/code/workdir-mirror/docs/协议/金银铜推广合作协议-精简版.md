## 一、合作性质
1.1 乙方通过「AI行情官」（a.ai24x.com）邀请机制推广本产品，甲方按本协议及平台规则向乙方发放推广回馈。
1.2 本协议为**信息服务推广合作**，不构成证券投资咨询关系、劳动关系或合伙关系。

## 二、金银铜推广等级
2.1 乙方推广等级（入门/铜/银/金）由平台按**近 30 天团队成交额与活跃直推人数自动评定并晋级**，无需付费购买；具体门槛与直推返点阶梯以平台后台配置为准（默认：铜 15% / 银 20% / 金 25%）。
2.2 乙方等级仅影响本协议项下推广回馈比例，不构成任何资格、股权或收益权。

## 三、合规红线
3.1 乙方推广时应如实描述产品，**不得**作出收益承诺、盈亏保证或投资建议；不得代客理财、代客操盘、非法荐股。
3.2 乙方**不得**以发展人员数量或收取费用作为计酬依据（禁止传销）；不得自邀、批量注册、刷量或买卖邀请关系。
3.3 违反本条任一情形的，甲方有权取消回馈、冻结或注销账号，并保留追偿权利。

## 四、回馈与结算
4.1 推广回馈以“乙方邀请并**实际支付成功**的订单”实付金额为基数计算；退款、风控取消的订单对应回馈同步冲减。
4.2 默认以查询额度、会员权益等**非现金形式**发放，不可提现、不可转让。
4.3 现金结算仅对**已签约城市合伙人**试点开放（另行签署《城市合伙人合作协议》），个人推广伙伴不适用。

## 五、双方义务与保密
5.1 甲方提供邀请链接、数据后台与回馈记录；乙方应真实宣传、维护品牌形象。
5.2 双方对合作中知悉的客户信息、结算数据等商业秘密负有保密义务。
