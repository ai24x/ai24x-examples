## 四、副脑分工（v3.5 · 内网外网版）

| 副脑 | 配置 | 位置 | 角色 | 职责 |
|------|------|------|------|------|
| **01** | **4核8G** | **国内 + VPN** | **国际增长引擎** | Google SEO 批量生产 · X/Reddit/HN 直接发布 · 竞品监控 · 数据分析 · 邮件自动化 |
| 02 | 2核8G | 国内 | 国内营销执行 | 种子群 · 中文教程 · 社媒 · 30台机房统调 |
| 03 | 2核8G | 国内 | 运维 | 公网服务 + PM2 + Nginx + 告警 + Phase 1 全包 API 服务 |
| 04 | 2核8G | 新加坡 | 国际节点 | 01 的灾备出口 · PayPal/Stripe · 海外 CDN · 英文文档 |

### 为什么这么分

- **01 有 VPN** → 全公司唯一能打 Google 的高配节点，24小时挂 VPN 跑国际营销
- **04 新加坡原生** → 01 的 VPN 如果挂了，04 是无 VPN 的天然外网灾备出口
- **03 全包 API** → Phase 1 流量为 0，不拆层。流量上来直接升级扩容 03 或 04
- **30台机房** → 后期归副脑02统调，按运营/内容/SEO/数据分组

### 内外网切分

```
国内云（内网）：
  01 VPN → 可访问 Google/X/Reddit → 国际增长引擎
  02 → 国内营销（种子群、教程）
  03 → 运维 + API 服务

新加坡（原生外网）：
  04 → 国际节点（01 灾备 + 支付 + 发布备份）
```
