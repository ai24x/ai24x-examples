## 四、加固方案（7 项）

### 1. 可信 IP 白名单机制（治本）
- 各副脑维护 `C:\AI24X\conf\trusted-ips.json`：主脑 122.239.106.193 + 雷总终端 + 各副脑互访 IP
- 防火墙：SSH/RDP 默认拒绝陌生 IP，仅白名单放行
- **主脑 IP 进「救援白名单」，永不禁封**（本次最大教训）

### 2. 指纹先比对，再定性
- 各副脑保存己方公钥指纹清单（主脑 main-brain@ai24x 等）
- 陌生 IP + 己方 key 登录 → 指纹匹配 = 自己人换 IP → 仅告警记录，不封锁

### 3. 告警分级处置（防误报扩散）
- 🟡 可疑（陌生 IP / 无效用户尝试）→ 记录 + 群告警
- 🔴 确证入侵（指纹不匹配 / 行为异常）→ 才封锁
- 封锁最小化：封具体 IP，不封段；不停 sshd；不动 authorized_keys

### 4. RDP 收紧（真实威胁）
- 3389 入站规则仅允许白名单 IP；或关闭公网直连改走 SSH 隧道
- 审核 RDP 登录记录（安全日志 4624/4625）

### 5. SSH 爆破防护（真实威胁）
- 各副脑启用失败登录自动封禁（类 Fail2ban，计划任务 + 脚本）
- 清理无效本地账户，Administrator 启用强密码策略

### 6. 通信冗余（破飞书单点）
- 主脑↔副脑以 SSH 为主通道，飞书降级为汇报通道
- 副脑失联时主脑仍可 SSH 救援（前提：救援白名单生效）

### 7. 复盘落盘与 SOP 更新
- 本文件为永久记录；各副脑将「先验指纹→分级处置→最小封锁」写入自身安全 SOP
