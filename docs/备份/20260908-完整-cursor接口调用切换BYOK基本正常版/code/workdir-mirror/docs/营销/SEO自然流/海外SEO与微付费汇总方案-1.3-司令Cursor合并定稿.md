## 0. 一句话定调

**品牌层卖 AI Gateway（One API · Every AI · Pay Less / Spend Smarter）；获客层借 DeepSeek/Qwen/GLM/Kimi「中国名模海外刚需」；转化层用 Codex/OpenClaw/Cursor 接入教程 + 免费试用 + PayPal/Card。**

**不要做成「DeepSeek 代充站」**——中间商已挤满该词（AiCredits / Token China / ChinaWHAPI / SiliconFlow / OpenRouter）。我们赢在 **一口价 + 多模型一 Key + 海外可付 + 工具接入**，价格战不打 OpenRouter 主场。

## 8. 微付费与 SEO 协同（采纳 Cursor 门禁模型）

| 原则 | 做法 |
|------|------|
| 先信号后花钱 | SEO/社区有注册→调用→付费再放大；**无信号不开投** |
| 落地页 | **www AI Gateway credits / open**，禁 Markets |
| 词 | 买「pricing / outside china / paypal」类；可先用 GSC 自然词中高转化词做种子词 |
| 预算 | $100→有付费再 $300；CAC 回收差立刻停 |
| 创意 | 截图：Codex 跑通 + 价格表一行，勿假官方 |
| 归因 | UTM 全链路：Blog→注册→调用→付费，周报给雷总 |

## 12. 对 04「请复核」七问的直接答复（合并版）

1. **分层合理？** 合理；补 **T0 工具接入簇** + `paypal / no chinese phone / openai compatible deepseek` + **Kimi（存量页激活）**；MiMo 保持 P3。  
2. **一模型一篇够？L4 提前？** 主指南够骨架；另加工具文 + 1 篇对比。对比 **紧跟 DeepSeek 作 P0.5，不整层抢 P0**。  
3. **技术 SEO 遗漏？** 补 HowTo/SoftwareApplication schema、dateModified、canonical 纪律、examples 外链、CWV/发版刷新、**Kimi sitemap、hreflang zh-CN 清理、SERP 基线周更**。  
4. **一口价做 title？** **副句可以，主词用意图词**（A/B 变体）；首屏表格打峰谷 + OpenRouter 三列对比。  
5. **商标合规？** 页脚免责句式 + 禁 official/affiliate 暗示 + 模型名仅作兼容说明 + 禁 bypass 表述。  
6. **节奏与其它流量？** W1 DeepSeek + Kimi 存量 + Codex + dev.to + X 热点；并行 GitHub/Reddit；YouTube B 级；微付费门禁后。  
7. **有无忽略流量源？** **dev.to 转载（S 级，竞品已占 SERP）** + Product Hunt（W4 备素材）。
