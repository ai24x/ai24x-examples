## 四、名模提及规范（SEO / 社媒）

**一轮里可点名（优先热词）**
全球名模：DeepSeek · Kimi · Qwen · GLM · GPT-5 · Claude · Gemini（仍单帖主推 1 个，结尾可带一句 also）
**写法**

- 英文帖优先英文名：`Kimi` `Xiaomi MiMo` `MiniMax` `Zhipu GLM` `DeepSeek` `Qwen`  
- 单帖 **主推 1 个名模**，结尾可带一句 “also：MiMo / MiniMax / …”  
- 链到对应落地（上线后）：`/models/kimi` 等；未上线前链 Pricing / Docs  

**不要**

- 一篇堆 20 个模型名装「最全」  
- 写「官方代理 / 白标 / 内部渠道价」  
- 把硅基、OpenRouter、副脑、联调写进用户可见文案
