## 3. 关键词怎么打（01 主责）

### 3.1 主攻簇（顺序）

1. **A 名模 + 性价比**（主攻）  
2. **B 跨境痛点**（PayPal / outside China）  
3. **C 接入案例**（OpenClaw / OpenAI compatible）  
4. D 排错 FAQ · E 品牌收口  

**不做主攻：** `best AI API`、`200+ models`、国内「免费 GPT」灰产词。

### 3.2 名模词表（轮换，勿只写 DeepSeek）

| 优先 | 英文检索示例 | 备注 |
|------|--------------|------|
| **Kimi / Moonshot** | Kimi API, Kimi 3, cheap Kimi API | 近热；VIP 点名优先 |
| **小米 MiMo** | Xiaomi MiMo, MiMo API | 能力向 / 性价比 |
| **MiniMax** | MiniMax M2, cheap MiniMax API | Agent / 编码 |
| **智谱 GLM** | Zhipu GLM, GLM API | 海外搜 Zhipu / Z.ai |
| DeepSeek / Qwen | DeepSeek Flash, Qwen API | 压舱；与轮换并行 |

**组词公式：** `{Model} API pricing` · `cheap {Model} API` · `{Model} API PayPal` · `{Model} OpenClaw` · `{Model} vs GPT cost`（数据诚实）。

**节奏建议（01）：** 每周至少 **1 个名模主词**专题/长文草稿（轮换：Kimi → MiMo → MiniMax → GLM → DeepSeek/Qwen）。

## 5. 渠道怎么参与（01 为主 · 04 不背文案）

| 渠道 | 建议动作 | 频率感 |
