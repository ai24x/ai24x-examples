## 0. 一句话结论

Google/Bing 要把 AI24X 理解成 **AI Gateway / AI Infrastructure**，而不是「便宜 Token reseller」。

SEO 宇宙四支柱（长期押注）：

| 支柱 | 代表词 |
|------|--------|
| AI API | OpenAI compatible API · multi model API |
| AI Gateway | AI gateway · LLM gateway · AI API gateway |
| AI Cost Optimization | LLM cost optimization · cheapest LLM API |
| AI Routing | AI model routing · LLM API fallback · BYOK |

漏斗：

```
关键词 / 社媒痛点
  → SEO 落地页 / Blog / Calculator
  → www 注册 或 open 拿 Key
  → 试用调用
  → pricing / console#billing 充值下单
```

社媒 **不直接堆 SEO 词**，要翻成观点句（见 §6）。

渠道纪律（2026-08）：

- **SEO**：可规模化，须真实数据 + 人工把关（见收发纪律任务）

- LinkedIn / YouTube / HN：真人环节 + 披露
