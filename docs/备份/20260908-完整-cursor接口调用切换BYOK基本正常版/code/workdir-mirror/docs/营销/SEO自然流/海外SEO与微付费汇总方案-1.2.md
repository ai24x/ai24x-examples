## 0. 一句话定调

**品牌层卖 AI Gateway（One API · Every AI · Pay Less / Spend Smarter）；获客层借 DeepSeek/Qwen/GLM 等「中国名模海外刚需」；转化层用 Codex/OpenClaw/Cursor 接入教程 + 免费试用 + PayPal/Card。**

不要把整站 SEO 做成「DeepSeek 代充站」——中间商已挤满该词；我们赢在 **一口价 + 多模型一 Key + 海外可付 + 工具接入**。

## 1. 目标与漏斗（修订）

```
搜索/社区痛点（DeepSeek 海外怎么付 / Codex 接中国模型 …）
  → 模型指南 or 工具接入文（open/www）
  → Hub 支柱文（Gateway / compatible / cost / BYOK）
  → 注册拿 Key（送试用 credits）
  → 真实调用（Codex / OpenClaw / curl）
  → Value Pack / Builder → Scale（VIP 点名）→ 世界名模档
```

| 层 | 动作 | KPI（90 天粗标） |
|----|------|------------------|
| SEO | P0 文上线 + GSC 索引 | 自然点击周环比↑；TOP20 词 ≥5 |
| 开源接入 | Codex/OpenClaw/Continue 等可复制配置 | GitHub/文档引荐注册 |
| 微付费 | 门禁齐后 $100→$300 | 有付费 ≥1 才加码 |
| 转化 | 注册→首次调用→首充 | 免费转付费可追踪 |

## 2. 对 04 调研的复核结论

| 04 观点 | 复核 |
|---------|------|
| DeepSeek ≫ Qwen > GLM，海外心智强 | **采纳**；P0 先 DeepSeek 簇 |
| MiMo 海外≈0，仅薄页 | **采纳**；P3，勿抢产能 |
| 中间商收割「credit card / outside China」 | **采纳**；我们差异化必须写进标题副句，勿纯堆「buy DeepSeek API」 |
| 一口价 vs 官方峰谷 | **可做对比表核心**，但 **title 主词仍应是意图词**（pricing / outside China），峰谷对比放 H2/首屏表格 |
| 一模型一篇 | **一模型一「主指南」**；另允许 1 篇对比 + 1 篇工具接入，禁止一词灌水 |
| L4 对比提前到 P0 | **不建议整层提前**；先出 DeepSeek 主指南，**对比作 P0.5**（紧跟 DeepSeek 上线后 1 周） |
| 定价 $0.33/M | **对外以线上 pricing 为准**（现口径常写 flash from **$0.35/M**）；文中对比表用「核实当日价」，禁写死过期数字 |

## 3. 关键词分层（优化版）

| 层 | 意图 | 优先级 | 代表词 | 落地 |
|----|------|--------|--------|------|
| **G0 Hub** | 品类/基建 | 已有 Phase1 | ai gateway · openai compatible · one api multiple models · byok · cost basics | www/open Hub |
| **C0 中国名模·获客** | 高购买意图 | **P0** | deepseek api pricing · deepseek v4 flash price · use deepseek outside china · buy deepseek api （慎用纯 reseller 味 title） | 深度指南 |
| **C1** | 次强名模 | **P1** | qwen api pricing · qwen vs deepseek · glm api · glm coding api | 指南 |
| **T0 工具接入** | 开发者场景 | **P0 并行** | openai compatible codex · openclaw deepseek · cursor china llm api | guides（可复用 examples） |
| **L4 对比** | 选型 | **P0.5→P1** | best chinese llm api 2026 · deepseek vs qwen vs glm | 1 篇权威对比 |
| **L5 转化** | 商业 | **P1** | ai gateway credits · paypal ai api | pricing + console |
| **L1 品牌** | 品牌 | **P2** | ai24x | 自然随外链起 |
| **C3 薄页** | 长尾 | **P3** | xiaomi mimo api | 薄页即可 |

### 更值得加打的词（04 稿补强）

| 词簇 | 理由 |
|------|------|
| `openai compatible deepseek` | 接 Codex/Cursor 搜索习惯 |
| `deepseek api paypal` / `deepseek api no chinese phone` | 支付摩擦痛点，我们强 |
| `llm gateway deepseek` | 把名模词拉回 Gateway 叙事 |
| `cheapest deepseek api` | 有量；文案用「flat rate / no peak surcharge」解释，勿虚标 % |
| `openclaw` / `codex cli` + model | 开源接入引流，竞品内容少 |

**少打或慎打**：纯 `deepseek api reseller`、假官方站味、Markets/美股词混进 Gateway 帖。

## 4. 内容矩阵（够不够？）

| 类型 | 数量策略 | 说明 |
|------|----------|------|
| Hub | Phase1 已 5 篇 | 持续内链加粗，不重复造 Hub |
| **一模型一主指南** | DeepSeek → Qwen → GLM | 价格表 + 峰谷对比 + 海外支付 + curl/OpenAI SDK + FAQ + CTA |
| **对比文** | 1 篇（三模对比） | DeepSeek 指南后 **7 日内** 发，不必整层升 P0 |
| **工具接入** | Codex / OpenClaw / Cursor 各 1（可短） | 与开源 examples 互链；**与 SEO 指南同期推** |
| MiMo | 1 薄页 | 有收录即可 |

**一模型一篇「主指南」够做骨架；不够的是「工具接入 + 对比 + Hub 回链」，不是再拆 10 个同义词页。**

### 主指南必含锚点（差异化）

1. 官方峰谷价表 vs **AI24X 一口价**（注明核实日期）  
2. 中国手机号 / 支付限制 → PayPal·Card·无国内号  
3. **一个 Key**：DeepSeek + Qwen + GLM + 世界名模 + 路由  
4. 注册试用 credits（以线上为准，勿写死过期数字）  
5. 可复制：`base_url` + Codex/OpenClaw 配置块  
6. 明确：**AI Gateway / aggregator，非官方**

## 5. Title / Meta：一口价能不能当主打？

| 做法 | 建议 |
|------|------|
| Title 主词 | **意图词优先**：`DeepSeek API Pricing (2026)` / `Use DeepSeek API Outside China` |
| Title 副句 | 可带差异：`Flat Rate · PayPal · Multi-Model Gateway` |
| H1 | 同意图；首屏表格打「peak vs flat」 |
| Meta | 痛点 + 差异 + CTA，禁「official DeepSeek」 |

更好卖点组合（按页选用，不必全塞 title）：

1. **Overseas-ready checkout**（PayPal / Card）  
2. **One key, many China + global models**  
3. **Flat rate（no peak window surcharge）**  
4. **OpenAI-compatible → Codex / OpenClaw in 3 steps**

**补遗（建议写入执行）**：

| 项 | 说明 |
|----|------|

| **与投流落地页一致** | 付费词落地 = Gateway credits 页，勿丢到无关 Blog |

| 周 | SEO | 开源/社区 | 微付费 |
|----|-----|-----------|--------|
| **W1** | DeepSeek 主指南上线 + GSC | Codex 接入短文 or examples 目录 | 门禁核对，**不放大** |
| **W2** | 对比文 or Qwen 开写；内链巡检 | OpenClaw 配置帖（Reddit/X） | $100 试水（门禁齐） |
| **W3** | Qwen 指南 | Continue/Cursor 择一 | 复盘停/续 |
| **W4** | GLM 指南（coding 角） | Show HN 素材准备（账号已养） | 达标才 $300 |
| 滚动 | MiMo 薄页；Hub 外链增强 | 周更社媒观点句（非堆词） | 赢家词加码 |

**内链结构优选**：

```
Hub(what-is-gateway / cost / compatible)
   ↑↓
DeepSeek 指南 ←→ Qwen/GLM 指南 ←→ 三模对比
   ↑↓
Codex / OpenClaw guides → pricing → register
```

## 8. 微付费与 SEO 协同

| 原则 | 做法 |
|------|------|
| 先信号后花钱 | SEO/社区有注册→调用→付费再放大（作战方案） |
| 落地页 | **www AI Gateway credits / open**，禁 Markets |
| 词 | 买「pricing / outside china / paypal」类，少买纯品牌大词 |
| 预算 | $100→有付费再 $300；CAC 回收差立刻停 |
| 创意 | 截图：Codex 跑通 + 价格表一行，勿假官方 |

## 12. 直接回答 04「请复核」六问

1. **分层是否合理？** 合理；补 **T0 工具接入** 与 `paypal / no chinese phone / openai compatible deepseek`；MiMo 保持 P3。  
2. **一模型一篇够不够？L4 是否 P0？** 主指南够骨架；再加工具文+1 篇对比。对比 **紧跟 DeepSeek，作 P0.5，不整层抢 P0**。  
3. **技术 SEO 遗漏？** 补 HowTo schema、dateModified、canonical 纪律、外链/examples、CWV/发版刷新。  
4. **一口价做 title 主打？** **副句可以，主词用意图词**；首屏表格打峰谷对比。  
5. **商标合规？** 页脚免责声明 + 禁用 official/affiliate 暗示 + 模型名仅作兼容说明。  
6. **节奏与其它流量？** W1 DeepSeek+Codex；并行 GitHub/Reddit；YouTube B 级；微付费门禁后。
