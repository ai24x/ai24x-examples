## 二、第一层：广泛触达 — 5大阵地打法

### 2.1 抖音（流量最大，风控最严）

**你的数据证明了一件事：一夜持股法这类"方法论图文"有自然流量。**

#### 内容方向（3条线并行）

**A线：方法论图文系列（主力，延续已验证模式）**

已验证：一夜持股法 → 2万播放。以下选题延续同一思路：

| # | 标题 | 核心内容 | 预估流量 |
|---|------|----------|----------|
| 1 | 一夜持股法8步详解 | 已发，2万播放 | ✅已验证 |
| 2 | 底部信号怎么确认？3条均线就够了 | MA14走平上翘+底信号 | 1-3万 |
| 3 | 涨停后回调多少可以买？N型战法 | 拉升→缩量回踩→二波 | 1-3万 |
| 4 | 5根均线看懂一只股票 | MA5/10/14/20/28/57用法 | 1-5万 |
| 5 | 缩量阴跌后什么时候进场？ | 量能判断+均线支撑 | 1-3万 |
| 6 | 什么时候该跑？3个风险信号 | B信号+均线死叉+MACD | 1-3万 |
| 7 | 均线粘合后爆发！3步选出潜力股 | 选股公式思路 | 2-5万 |

**制作要点**：
- 图文形式（非视频），制作成本最低
- 每张图一个知识点，3-5张图一个系列
- **绝对不说"买""卖""推荐"** — 只说"当出现X信号时，值得观察"
- 底部加："信号观察工具：AI行情官"

**B线：信号复盘图文（每周1条）**

- "本周3只股票出现底信号，后来怎样了？"
- 用AI行情官截图，展示信号出现→后续走势
- 不推荐个股，只回顾历史数据
- 底部："数据来源：AI行情官"

**C线：同花顺指标教程（差异化内容，引流利器）**

- "同花顺免费指标怎么装？手把手教你"
- "3个同花顺选股公式，帮你筛出潜力股"
- "同花顺指标编写入门：5分钟学会"
- **核心钩子**：评论区放"完整公式代码，关注后私信发你"
- 私信自动回复：发公式代码 + 一句话"用同花顺选出来的股，可以在AI行情官看信号确认"

#### 抖音防违规手册

| 绝对不做 | 替代说法 |
|----------|----------|
| 推荐股票 | 分析信号状态 |
| 买入/卖出 | 观察/关注/留意 |
| 稳赚/X%收益 | 历史统计/X次信号后表现 |
| 荐股神器 | 信号观察工具 |
| 跟着买 | 辅助判断 |
| 截图晒收益 | 展示信号+免责声明 |

**每条内容末尾必须加**：⚠️ 以上内容仅为技术分析方法交流，不构成投资建议

#### 抖音→注册转化路径

```
抖音图文 → 评论区"完整指标代码私信我"
    → 私信回复：公式代码 + "更多信号分析可体验 AI行情官"
    → 用户搜索"AI行情官" → 找到网站 → 注册
    （或直接在简介/置顶评论放网址，但要注意风控）
```

**关键**：抖音不直接放链接（会被限流），而是让用户主动搜索。


- 邀请码/链接一键复制
- 分享到微信/微博/抖音按钮

### 4.3 内容裂变（UGC）

**让用户帮你传播**：

- 用户截图信号→分享到雪球/微信群→其他股民看到→搜索"AI行情官"

**节奏**：第1个月50人群 → 第3个月200人群 → 第6个月500人群
