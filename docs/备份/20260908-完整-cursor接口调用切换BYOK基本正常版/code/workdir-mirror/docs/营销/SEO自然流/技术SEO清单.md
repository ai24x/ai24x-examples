# 技术 SEO 清单

> 工程细节与 IA 见 `docs\规划\网站SEO优化设计-自然引流-1.0.md`；本清单为每周核对项。

## 每周核对
- [ ] `robots.txt` 正确指向 sitemap，无错误 Disallow，允许主流爬虫
- [ ] `sitemap.xml` 更新并提交：Google Search Console / Bing Webmaster / 百度搜索资源平台
- [ ] 全站 https；`www` 规范统一；国际页 hreflang `en` 优先
- [ ] 每个页面 title / description 唯一且含目标关键词
- [ ] 结构化数据（Product / FAQ / Article）无报错（Rich Results Test 校验）
- [ ] 移动端适配；首屏 LCP < 2.5s
- [ ] 404 页正常；内链 / 面包屑 / 锚文本合理
- [ ] 新发布内容 24h 内能抓到（主动提交 / sitemap ping）

## 数据入口
- 收录与排名：`数据\收录与排名.csv`
- 流量：`数据\流量日报.csv`（GSC / 百度站长导出）
