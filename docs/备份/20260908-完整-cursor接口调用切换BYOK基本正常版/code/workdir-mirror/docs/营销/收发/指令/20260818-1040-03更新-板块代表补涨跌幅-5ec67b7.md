## 背景
老板反馈：gd.html 主线「AI服务器算力」的代表（浪潮信息/中科曙光/工业富联）没有涨跌幅数据。
根因：AI服务器算力 无东财同名板块，代表走复盘静态龙头表（SECTORS）兜底；08-17 23:54 生成归档时东财 ulist.np 补行情失败，leaders 的 pct 全为 null，旧归档读取后「代表：xxx」无涨跌幅可显示。
修复（仅后端，本次无前端改动、无版本号变更）：
1. bj_screener.py 新增 `_backfill_leader_quotes(payload)`：扫描 board_rank 各板块 leaders，对 pct 为空/None 的代表批量补拉实时行情（东财 ulist.np），带模块级 60s 缓存（_LEADER_Q_CACHE），不改写归档与扫描缓存。
2. main.py `/api/bj/screener` 所有返回出口（VIP 归档/新鲜扫描 + 非 VIP 板块视图 + macd）统一 `await _backfill_leader_quotes(...)`。
本地已实测：AI服务器算力 代表 pct 补上（浪潮 -2.45% / 中科曙光 -1.83% / 工业富联 -3.11%）；gd.html 渲染「代表：浪潮信息 -2.45%…」正常、无 JS 报错；其它板块保留归档快照不受影响。
