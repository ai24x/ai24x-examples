## 一、背景
1. **运营后台升级为平台视角**：`web/token-admin.html` 更名「AI24X 运营后台」，左侧新增一级菜单「产品运营」→ Markets 总览/订阅/订单/套餐（P1 只读）+ Open BYOK 占位（P3）。
2. **markets 子服务管理只读 API**：`p/markets/api/server/app/admin_api.py`（`/api/admin/summary|subs|orders|plans`），鉴权= X-Markets-Secret 签名 + 仅回环来源 + nginx X-Real-IP 非回环拒绝。
3. **core 统一网关**：`/v1/admin/products/markets/{kind}` 代理 markets（管理密钥鉴权 + kind 白名单 + 参数白名单透传，防开放代理）。
4. **管理后台安全加固**（core + open 同步）：配置独立 `ADMIN_API_KEY` 后仅接受该钥（SMS 内部密钥不再放行）；管理接口同 IP 每分钟限速（默认 60，可 `ADMIN_RATE_LIMIT_PER_MIN` 调）；可选 `ADMIN_IP_WHITELIST` IP/CIDR 白名单；密钥仍只存页面 sessionStorage；写操作审计日志已存在（`[ADMIN-AUDIT]`）。
5. **「产品运营 提示禁止访问」修复**（2026-08-22 老板反馈，6628f9a）：旧会话残留（短信内部密钥）自动恢复进入工作台时，面板请求 403 只显示裸「禁止访问」。已改为：会话恢复前先调 `/v1/admin/token/summary` 验钥，失败清会话回门禁并提示「用主站管理密钥 ADMIN_API_KEY」；任意面板 403 统一回门禁友好提示；门禁文案补充密钥位置（本机 api/.env / 生产 04 已配置）。
