## 三、Codex 接入配置（已实测的命令）

```powershell
# config.toml 增加 provider（或临时 -c 覆盖）
# [model_providers.ai24x]
# name = "AI24X"
# base_url = "https://api.ai24x.com/v1"
# env_key = "AI24X_API_KEY"
# wire_api = "responses"

$env:AI24X_API_KEY = "<你的key>"
"Reply with exactly: PONG" | codex exec -m flash -c 'model_provider="ai24x"' -c 'model_providers.ai24x.name="AI24X"' -c 'model_providers.ai24x.base_url="https://api.ai24x.com/v1"' -c 'model_providers.ai24x.env_key="AI24X_API_KEY"' -c 'model_providers.ai24x.wire_api="responses"'
```

## 四、Cursor 接入配置步骤（待人工验证）

1. Cursor → Settings → Models
2. 打开 `Override OpenAI Base URL`，填 `https://api.ai24x.com/v1`
3. OpenAI API Key 填 AI24X key
4. 选择/输入模型名 `flash`，对话测试
5. 预期：先修 `/v1/models` 后模型列表可直接选；修前手动填模型名

## 五、P0 修复项（阻塞多工具体验）

- [ ] `/v1/models` 返回完整模型列表（flash/pro/ultra/auto + 别名），带 context/max output 元数据
- [ ] `/v1/responses` 非流式 `output_text` 字段补齐（OpenAI SDK 客户端依赖）
- [ ] 模型名元数据：`/v1/models` 中模型 id 建议保留对外名（flash 等），供 Codex/Cursor 类客户端识别
