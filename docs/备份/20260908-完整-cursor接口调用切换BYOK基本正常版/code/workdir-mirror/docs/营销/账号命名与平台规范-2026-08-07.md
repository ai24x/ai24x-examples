## 一、命名规范

### 1.1 公司品牌号（全平台统一识别）

| 前缀 | 可用名（按优先级） | 用途 |
|------|--------------------|------|
| `ai24x` | ai24x / ai24xapi / ai24xhq | 官方内容、产品更新、Show HN、公告 |

- 全平台用同一名字 + 同一 logo 头像 + 同一简介（一句话叙事）
- 简介模板：`One API key for China LLMs (Kimi/MiMo/GLM/DeepSeek/Qwen) · PayPal USD · OpenAI-compatible`

### 1.2 工程师/个人号（技术人设，不冒充官方）

- 命名：`ai24x_dev` / `ai24x_eng` / 技术名 + ai24x 关联
- 用途：答疑、晒接入案例、参与 Reddit/HN/Discord 讨论
- 简介注明 `Engineer @ AI24X`，头像可用个人风格或统一 logo 变体

### 1.3 邮箱与账号关联纪律

- 社区平台（X/Reddit/HN/Discord）注册邮箱**不要全用 gmail 后缀**：用 protonmail / outlook 分散，防统一后缀关联
- 核心邮箱（aisohacom@gmail.com）只用于支付/Ads/GSC/域名管理，不注册社区号
- 所有账号开 2FA；登录设备/浏览器 Profile 固定分离

## 三、头像与视觉规范

- 头像：统一 logo 400×400（复用 `web/img/og-share.png` / favicon 同源图形），全平台一致
- 封面/Banner：统一渐变底 + 一句话叙事，各平台按尺寸出一套（X 1500×500 / YouTube 2560×1440 / GitHub 1280×640）
- 用户名被占用时：优先 `ai24xapi` → `ai24xhq` → `tryai24x`，保持前缀 ai24x 不变

## 四、注册节奏与防封

- 每天最多注册 1-2 个新平台账号，不批量注册
- 新号先人工养 2 周（浏览/少量互动），再上 OpenClaw 自动化
- 自动化纪律见 `AI24X-Token出海规划-1.0.md` §5.2（间隔随机 30-90 秒、每日登录 ≤3 次、发帖 ≤5 条）
