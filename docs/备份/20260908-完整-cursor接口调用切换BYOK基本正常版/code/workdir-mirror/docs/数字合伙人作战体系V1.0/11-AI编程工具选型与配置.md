

- 桌面版与 CLI **共用 `~/.codex/config.toml`**，配一次两者都生效

### 3. 环境要求
- Node.js ≥ 20（实测 v24 通过）
- Git（可选）

## 三、配置 DeepSeek（核心）

### 1. 配置文件 `C:\Users\Admin\.codex\config.toml`
```toml
model = "deepseek-v4-flash"
model_provider = "deepseek"

[model_providers.deepseek]
name = "DeepSeek"
base_url = "https://api.deepseek.com"
env_key = "DEEPSEEK_API_KEY"
wire_api = "responses"
```

### 2. 设置 API Key（用户级环境变量）
```powershell
setx DEEPSEEK_API_KEY "sk-你的key"
```
⚠️ **新开的终端窗口才生效**（setx 不作用于当前已开窗口）

### 3. 验证
```powershell
codex exec "Reply with exactly: OK"
# 期望输出 OK，无报错
```

## 四、避坑清单（实测踩过）

| 级别 | 坑 | 解法 |
|------|----|------|
| 🔴 | `wire_api` 必须 `"responses"`，`"chat"` 已废弃直接报错 | 用 responses |
| 🔴 | key 粘贴进 Codex 对话窗口 → 被当明文密钥泄露、卡对话 | key 只走环境变量/config |
| 🟡 | setx 后当前窗口报 `Missing environment variable` | 新开终端 / `$env:DEEPSEEK_API_KEY="***"` |
| 🟡 | `models_dev_url` 放 provider 里 → `unknown configuration field` | 放顶层（可选） |
| 🟡 | `Model metadata not found` warning | 无害，忽略（用 fallback 元数据） |
| 🟢 | 换 Pro 模型 | `model = "deepseek-v4-pro"`，CLI+桌面同时生效 |
| 🟢 | key 泄露 | DeepSeek 平台轮换 → 重跑 setx + 新开终端 |

**日常命令：**
```powershell
codex                          # 交互模式
codex exec "任务描述"           # 非交互模式
codex exec -C 项目目录 "任务"   # 指定项目
codex app                      # 桌面版
codex review                   # 代码审查
```

## 五、进阶：无法官网直连 DeepSeek？走 AI24X 接口（平台转售通道）

> 📌 **场景：** 无法/不方便在 DeepSeek 官网注册直连账号的用户（如海外用户、无国内手机号/支付方式），可以用 **AI24X 平台的接口**调用 DeepSeek。**用户端看到的还是 DeepSeek**，但请求实际走我们的网关——账号、计费、路由、回退全在我们手里。**这正是 AI24X 平台的价值和意义。**

> 📄 **完整版见《[Codex-DeepSeek配置指南-20260804.md](../Codex-DeepSeek配置指南-20260804.md)》**：含 Codex 走 AI24X 网关的完整配置、模型选择表、key 设置与验证步骤；本分册为摘要版。

### 1. 目标配置（拟）
```toml
model = "deepseek-v4-flash"
model_provider = "ai24x"

[model_providers.ai24x]
name = "AI24X"
base_url = "https://api.ai24x.com/v1"
env_key = "AI24X_API_KEY"
wire_api = "responses"
```

### 2. ⚠️ 前置条件（2026-08-05 探测结论）
- **平台需提供 OpenAI 兼容的 `/v1/responses` 端点**：Codex 0.146 只认 Responses API
- 当前探测：`https://api.ai24x.com/v1/responses` → **404**（未开放）；`/v1/models` → 200 正常（网关活跃，模型分层 auto/flash/pro/ultra 就绪）
- ✅ **2026-08-05 22:52 已确认支持**（04 带 key 实测 /v1/responses → 200，SSE 流式合规）：Codex/Cursor 全都能接 = 平台 API 转售通道直接打通
- 端点就绪后，把 `base_url` + `env_key` 换成上面对应值即可生效
- **Codex 可点名首选：** `vip-ds-flash`（1x 基准，最便宜）/ `vip-ds-pro`（3x 更强推理）/ `vip-kimi-code`（10x 编程）/ `vip-kimi`（39x 旗舰）——完整清单与价格见指南模型选择表

### 3. 一句话卖点（写网站案例用）
> 没有 DeepSeek 账号？用 AI24X 接口一样跑 Codex + DeepSeek——你看到的是 DeepSeek，背后是 AI24X 的网关（PayPal 可付、全球可注册、按量计费）。
