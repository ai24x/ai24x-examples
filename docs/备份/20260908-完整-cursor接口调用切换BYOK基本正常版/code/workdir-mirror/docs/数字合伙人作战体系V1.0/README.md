## 这套文档是什么

本系列是 AI24X（一家「雷总 + 5 个 AI 数字员工」组成的微型公司）在实战中沉淀出的**多智能体协同办公体系**。我们踩过坑、走过弯路、迭代出这套机制——现在整理成一份可以直接复用的手册，供任何想用 AI 组建「数字合伙人团队」的创业公司参考、学习、落地。

**核心思想一句话：**
> 把 AI 从「聊天机器人」升级为「数字合伙人」——有岗位、有边界、有汇报机制、有失联预案、7×24 小时自主运转。

## 体系全景图

```
                    ┌─────────────────────┐
                    │   雷总（老板/拍板）   │
                    │   审批窗口 08:30-23:30│
                    └──────────┬──────────┘
                               │ 简报/战报/审批
                    ┌──────────▼──────────┐
                    │ 主脑（AI24X 指挥）    │
                    │ 战略/调度/验收/出口   │
                    └──────────┬──────────┘
       ┌──────────┬───────────┼───────────┬──────────┐
       ▼          ▼           ▼           ▼          ▼
   ┌──────┐  ┌──────┐   ┌──────┐    ┌──────┐   ┌──────────┐
   │副脑01│  │副脑02│   │副脑03│    │副脑04│   │ 科设      │
   │国际  │  │中国  │   │运维CN│    │运维SG│   │(Codex)    │
   │获客  │  │运营  │   │生产  │    │生产+ │   │代码开发   │
   └──────┘  └──────┘   └──────┘    └──────┘   └──────────┘
   每台副脑 = 独立云主机 + 独立 OpenClaw 实例 + 独立飞书机器人
```

**关键设计：**
- **一台副脑 = 一台云主机 + 一个 OpenClaw 实例 + 一个飞书机器人应用**（物理隔离，互不拖累）
- **主脑是唯一消息出口**：副脑不直接刷屏老板，统一汇总到主脑，老板只看简报
- **双线业务流水**：国际流（Token 平台：01获客 + 04收银）≠ 国内流（AI行情官：02运营 + 03生产）
- **7×24 不空转**：人睡觉 ≠ 项目停滞，夜间是生产力窗口（详见 06 篇）
- **V1.0+4 顶级模式**：Codex（司令）升级为与主脑（指挥）平级的战略层，老板→司令/指挥→副脑；派发单线、飞书单一出口、失联降级（详见 12 篇）

## 核心理念（贯穿全系列）

1. **数字合伙人，不是工具**：目标驱动 > 指令驱动，AI 主动发现问题、提案、执行
2. **能自主就不打扰**：分级汇报，小事发群留痕，大事才找老板
3. **能落盘就不靠记忆**：一切规则、决策、教训写进文档，AI 重启也不失忆
4. **能自动就不手动**：心跳、巡检、盯梢、备份全 cron 化，7×24 不停摆
5. **能回滚就不硬改**：改前必备份，无回滚路径不改
6. **宁慢勿封**：外网操作（社交账号/爬虫）严守风控，账号是稀缺资产
7. **一机一脑 = 超级数字员工**：每台电脑 + OpenClaw = 一名有岗位、有记忆、会学习、能自主提案的数字员工；低峰/夜间空闲资源优先用于学习、巡检与补产出（详见 03/05/06 分册）
