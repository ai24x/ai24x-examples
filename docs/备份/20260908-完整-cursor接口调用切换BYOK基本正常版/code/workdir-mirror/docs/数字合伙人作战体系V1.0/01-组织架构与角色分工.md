## 三、指挥链路（消息怎么流动）

```
雷总（需求/拍板）
  ↓ 飞书私信
主脑（我）—— 唯一消息出口
  ↓ SSH 驱动（可靠）或飞书群通知
各副脑各自本地执行
  ↓ 回传 ops/ 文件 + 群记录
主脑汇总 → 雷总只看简报（晨报/战报）
```

**关键规则：**
1. **主脑是唯一消息出口**：副脑不直接刷屏老板；私信老板仅限 🔴 生产/密钥/支付/P0
2. **日常沟通直连飞书**：副脑间直接群@或SSH，形成纪要文档
3. **审批链路**：副脑 → 主脑 → 雷总（主脑把关质量，不只是转发）

## 四、权限边界（红线）

| 席位 | 能做 | 不能做 |
|------|------|--------|
| 主脑 | 战略拍板、仓库验收、发指令、汇总简报 | 改生产密钥、当日常客服、天天亲自部署、直接改项目代码 |
| 副脑 | 岗位职责内自主执行（🟢级） | 碰生产/密钥/支付（🔴必须审批） |
| 科设 | 所有核心代码开发 | —（代码唯一负责人） |
| 雷总 | 一切最终拍板 | — |

**代码开发分工铁律（2026-07-29 确立）：**
- 代码相关（主项目/行情官子项目）→ 全部交给科设（**Codex 主力，2026-08-05 起 Cursor 主要任务也移交 Codex**，偶尔 WorkBuddy）
- 副脑只负责自己电脑范围内的项目/运营/运维，不碰核心项目代码
- 主脑不直接改代码（未经允许不修改项目文件）
- 这条同样适用生产服务器：配置可以动，源码不动

**AI 编程工具效率实测排名（2026-08-05 雷总拍板）：**
> **Codex + DeepSeek ＞ Cursor ＞ WorkBuddy ＞ OpenClaw**
- 🥇 **Codex + DeepSeek V4 Flash** → 主脑级 AI 编程 / 核心大脑，**并接管科设主要编码任务**（2026-08-05 雷总拍板：以后 Cursor 的主要任务也都交给 Codex）
- 🥈 Cursor → 原科设主力，主要任务移交 Codex 后降为辅助（稳定可靠）
- 🥉 WorkBuddy → 备用开发工具
- 4️⃣ OpenClaw → 指挥/飞书中枢（定位是指挥链路与自动化，非编码主力）
- 详细配置与避坑 → 见分册 [11-AI编程工具选型与配置](11-AI编程工具选型与配置.md)（完整版另见《Codex-DeepSeek配置指南-20260804.md》）
