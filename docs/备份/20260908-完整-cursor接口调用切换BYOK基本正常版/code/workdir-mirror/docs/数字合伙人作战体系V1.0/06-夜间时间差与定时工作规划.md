# 06 · 夜间时间差利用与定时工作规划

> 版本：V1.0 · 2026-08-03 · AI24X 实战沉淀
> 解决的问题：怎么让公司 7×24 小时不停摆（人睡觉 ≠ 项目停滞）

---

## 一、核心理念

**晚上人睡觉 ≠ 项目停滞。** 23:30-08:30 是生产力窗口，任何任务不因「人睡觉」而空等。

AI 数字员工 7×24 小时全天候运转，不等人、不睡觉。老板审批窗口 08:30-23:30（15 小时）。

---

---

## 四、夜间执行原则

1. **不等人**：接到任务立即开工，不等主脑/雷总醒
2. **不打扰**：23:30-08:30 不私信雷总（P0 事故除外），成果写日志/文件
3. **天亮交付**：所有夜间任务以「08:00 前完成」为默认截止，晨报验收
4. **自主提案**：夜间思考产出 → 写入 `ops/proposals/`，周一汇报

- **晨间简报**（08:30 推送雷总）：夜间产出 + 今日计划 + 待审批

- **周一周报**（09:00）：各副脑上周成果 + 提案
