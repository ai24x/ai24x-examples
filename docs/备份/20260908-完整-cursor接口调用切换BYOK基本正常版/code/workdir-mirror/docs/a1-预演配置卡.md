## a1 预演配置卡（副脑01/03通用）

目标：把“环境未配齐”这类问题（502 / K线失败 / 注册登录失败）在预演阶段一次性暴露并固化为可执行流程。

### 一、先决条件（固定口径）

- **根目录**：`C:\ai24x01`
- **端口**：前端 `18001`，后端/管理 `18011`，主站 `8000`（见 `docs/PORTS.md`）
- **进程名**：`a1-web-18001`、`a1-api-18011`、`core-8000`

### 二、a1 后端（`p/a1/api/server/.env`）必配项

> 真实值不要入库。预演/生产建议先从 `.env.example` 复制一份再填。

- [ ] **数据库（PG）**：`AI24X_DB_KIND=pgsql` + `AI24X_DATABASE_URL=postgresql://...`
- [ ] **JWT 密钥**：`AI24X_JWT_SECRET`（长随机串）
- [ ] **管理后台密钥**：`AI24X_ADMIN_KEY`（32+ 随机串）
- [ ] **管理后台挂载路径**：`AI24X_ADMIN_MOUNT_PATH`（例如 `/admin20260501`，需与 Nginx location 对齐）
- [ ] **统一身份（主站）**：
  - `AI24X_IDENTITY_API_BASE`（指向主站 core，例如 `http://127.0.0.1:8000`）
  - `AI24X_SMS_INTERNAL_KEY`（与主站一致，用于转发短信发码）
- [ ] **数据源（可选/应急）**：
  - `AI24X_PAID_PROVIDER`（默认 `off`）
  - 若启用 TuShare：`AI24X_TUSHARE_TOKEN`（只放环境变量/不入库）
- [ ] **微信支付（如预演支付链路）**：`AI24X_WECHAT_*`（按 `.env.example`）

### 三、后台管理（a1 管理台）必做配置检查

入口：`http://127.0.0.1:18011<AI24X_ADMIN_MOUNT_PATH>`（如 `http://127.0.0.1:18011/admin20260501`）

- [ ] **系统配置**：读取成功（能看到当前配置摘要）
- [ ] **短信与统一身份**：
  - `identity_api_base` 已正确指向主站 core
  - `sms_internal_key` 已配置
- [ ] **数据源开关**：按预演策略设置（默认公共源即可）
- [ ] **代理/提现（如预演此链路）**：
  - 提现申请能列表/导出
  - 导出后可标记“已导出”

### 四、Nginx（域名/反代）必配项（最容易导致 502）

对 `a1.ai24x.com`（或预演域名）至少保证：

- [ ] `/` → `http://127.0.0.1:18001/`
- [ ] `/api/` → `http://127.0.0.1:18011/api/`
- [ ] `/docs`、`/health` → `http://127.0.0.1:18011/...`

> 判断原则：本机直连 `http://127.0.0.1:18011/api/kline?...` 是 200，但域名 `/api/kline` 是 502，则一定是 Nginx `/api/` 反代写错（端口/路径/尾斜杠）。

### 五、PM2 必做项

- [ ] `pm2 list`：`core-8000`、`a1-api-18011`、`a1-web-18001` 全部 `online`
- [ ] **预演机建议停用旧版**：`a-api-18031`、`a-web-18001` 设为 `stopped`（避免指到 `p/a`）

### 六、硬校验门禁（必须全 200，否则不算“预演通过”）

PowerShell：

```powershell
(Invoke-WebRequest -UseBasicParsing "http://127.0.0.1:18011/health").StatusCode
(Invoke-WebRequest -UseBasicParsing "http://127.0.0.1:18011/api/kline?secid=1.000001&period=day&count=10").StatusCode
(Invoke-WebRequest -UseBasicParsing "http://127.0.0.1:8000/login.html").StatusCode
(Invoke-WebRequest -UseBasicParsing "http://127.0.0.1:18001/index.html").StatusCode
```
