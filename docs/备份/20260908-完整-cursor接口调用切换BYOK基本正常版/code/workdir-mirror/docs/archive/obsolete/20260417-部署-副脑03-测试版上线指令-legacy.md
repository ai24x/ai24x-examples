### 3.2 前端静态（同域 a.ai24x.com）

静态目录：`/srv/ai24x/ai24x01/p/a/web`

建议 Nginx 同域托管静态，并反代：

- `/api/*` → `127.0.0.1:8001`
- `/docs` → `127.0.0.1:8001/docs`
- `/health` → `127.0.0.1:8001/health`

---

## 4. Nginx 最小示例（需要你按服务器路径改）

> 证书路径请替换为你实际签发路径。若暂时没有证书，可先用 HTTP 联调，后续再切 HTTPS。

### 4.1 `www.ai24x.com`

```nginx
server {
  listen 80;
  server_name www.ai24x.com;

  root /srv/ai24x/ai24x01/web;
  index index.html;

  location / {
    try_files $uri $uri/ =404;
  }
}
```

### 4.2 `a.ai24x.com`

```nginx
server {
  listen 80;
  server_name a.ai24x.com;

  root /srv/ai24x/ai24x01/p/a/web;
  index index.html;

  location / {
    try_files $uri $uri/ =404;
  }

  location /api/ {
    proxy_pass http://127.0.0.1:8001/api/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }

  location /docs {
    proxy_pass http://127.0.0.1:8001/docs;
    proxy_set_header Host $host;
  }

  location /health {
    proxy_pass http://127.0.0.1:8001/health;
    proxy_set_header Host $host;
  }
}
```

## 5. PM2 启动（推荐）

### 5.1 启动 a-api（8001）

```bash
cd /srv/ai24x/ai24x01/p/a/api/server

pm2 start ".venv/bin/python" --name "ai24x-a-api-8001" -- -m uvicorn app.main:app --host 127.0.0.1 --port 8001
pm2 save
pm2 status
```

> 若你的服务器是 Ubuntu/Debian，`pm2 startup` 需按提示执行一次（root 权限）。

### 5.2 常用检查

- API 健康：`http://127.0.0.1:8001/health`
- API 文档：`http://127.0.0.1:8001/docs`
- 线上（经 Nginx）：`https://a.ai24x.com/`、`https://a.ai24x.com/docs`
