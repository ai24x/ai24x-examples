## 🎨 UI统一方案

### 颜色方案
- 主色: `#6c63ff` (紫色)
- 辅色: `#00d4ff` (青色)
- 背景: 深色渐变
- 文字: 浅色系

### 字体方案
- 主字体: Inter, sans-serif
- 代码字体: monospace
- 大小: 14px基础，标题适当放大

### 间距方案
- 基础间距: 8px
- 卡片间距: 16px
- 区块间距: 32px

### 组件样式
- 卡片: 圆角、阴影、渐变边框
- 按钮: 渐变背景、悬停效果
- 输入框: 透明背景、发光边框
