# 短信验证码 · 国内已接 / 国际暂不接（2026-07-30）

## 拍板

| 项 | 口径 |
|----|------|
| 国内短信 | **已接入**（106 / 可选腾讯、聚合）；主站 API + 行情官 a1 共用 |
| 主站国际用户 | **邮箱 OTP**（SMTP），不靠短信 |
| **国际短信**（+1/+65 等） | **本轮不做**；迁副脑04 后若强需求再立项（Twilio 等） |

## 理由

1. 主站注册已是邮箱路径，国际增长瓶颈在邮件送达，不在短信。  
2. 行情官以国内 11 位号为主；当前通道硬限国内号。  
3. 国际短信成本高、要改号段闸门与模板合规，与「本机收齐 → 迁 04」主线无关。

## 升为 P0 的条件

明确要「海外手机号注册/登录」且邮件不可用占比高时，再开国际短信专项。
