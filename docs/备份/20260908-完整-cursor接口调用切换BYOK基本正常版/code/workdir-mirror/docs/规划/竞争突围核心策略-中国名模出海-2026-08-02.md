## 2. 支付双轨：为何竞品「不接」——不是难，是「不为 + 不敢」

雷总问得对：**接 PayPal + 微信/支付宝技术上不难**；Pateway 已接支付宝，证明竞品接得了。

| 真实原因 | 说明 |
|----------|------|
| **用户画像不需要（主因）** | LAYSO / TokenLab 主打欧美信用卡开发者；微信/支付宝对他们零价值，接了只加合规成本 |
| **PayPal「不敢」** | Stripe/卡往往够用；PayPal 对虚拟/预付费数字商品风控极严，不少 AI API 站冻过后放弃 |
| **主体/资质门槛** | 微信/支付宝直连要中国商户主体——美企/海外新站难直连，只能跨境聚合（费率+结算+审核） |
| **我们能双轨** | 因为本来就是**国内主体 + 国内支付资质**——这是「中国模型」定位的**天然配套**，不是刻意建的壁垒 |

**结论修正：**

- 双轨 = **必要不充分条件**。竞品想接随时能接（Pateway 即例），**不能当核心策略 / 护城河**。
- 它**验证垂直定位正确**：做 China models → 必须服务中国生态支付 + 海外可达充值 → 双轨是「中国模型可达性」的一部分，**跟着定位走，不是独立卖点**。
- 我们卡的是**那个位置（中国模出海）**，不是那个收款按钮。

## 3. 策略排序（修正后）

| 序 | 支柱 | 角色 |

| **5** | **信任补齐 + 投流只打差异化长尾** | guides / 真付信号 / China·Kimi 词；不打 cheapest |

### ① 产品定位：China 名模可达 = 主卖点

- 对外主句：**One key to China’s best models**（Kimi / GLM / MiniMax / Qwen / MiMo…）  
- 辅句：flash/pro 好记起步；VIP 再点名；支付写一句「PayPal / 本币」即可  
- **克制表述**：不说「全球唯一入口」，说「**专为中国名模出海设计的网关**」；国际旗舰只作 VIP 附属  

**可优化**：首页/投流减少「extreme value」；加重 **China 名模 + flash 起步价**；GPT/Claude 不进首屏。

### ② 定价：从「离谱」到「可接受」

- flash 目标约 **$0.45/M**；**不是**去追补贴最低价  
- **必须**：降锚同步抬 VIP `billing_mult`；中国模尽量硅基降本  
- 对外两行价：「flash 约 $X/M」「VIP 点名另计」

### ③ 订阅日赠

- Pro Pass 日赠（限 flash/auto/共享）作订阅锚；名模点名花预充  

### ④ 支付双轨（配套）

- 国际：PayPal USD（漏斗步骤清晰、失败文案友好、Live 小额信任）  
- 国内：微信/支付宝  
- 投流可带 `paypal` / `kimi api` 长尾，但**叙事主语仍是 China models**，不是「我们独家双轨」  
- 长尾词仍可用；勿写成「竞品永远接不了」

### ⑤ 信任补齐 + 投流

| 投 | 不投 |
|----|------|
| china llm api / kimi api / glm api | cheapest ai api |
| openclaw ai24x / lobechat china model | openrouter alternative（易进比价） |
| paypal + china model（作配套词） | 「唯一无卡护城河」话术 |

落地页 = 中国名模页或定价；**CTA → 注册 → 入门包**；物料写 China + flash，支付一句带过。
