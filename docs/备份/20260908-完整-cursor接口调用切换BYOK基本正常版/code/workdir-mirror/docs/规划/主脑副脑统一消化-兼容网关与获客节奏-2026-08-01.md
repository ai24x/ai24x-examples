## 一、下一刀：OpenAI 兼容网关（P0）

**为什么：** 国际获客核心依赖开源生态接入。当前主接口为私有格式 `/v1/chat/run`，主流开源应用（LobeChat / Open WebUI / Dify / LangChain / AnythingLLM / Cursor / Claude Code）只认 OpenAI 兼容接口，**一个都接不上**。补 `/v1/chat/completions` 适配层 = 一次适配、批量接入整个生态。

## 二、「网关绿」定义（验收口径，全团队统一）

以下三条**全部满足**才算绿：

1. ✅ `POST /v1/chat/completions` **公网可用**（OpenAI 标准格式响应，Bearer 认证）
2. ✅ **Open WebUI 或 LobeChat 实测连通**（填 base_url + key → 对话通，截图留证）
3. ✅ **现有 `/v1/chat/run` 回归无影响**（环回 health + 一次对话）
