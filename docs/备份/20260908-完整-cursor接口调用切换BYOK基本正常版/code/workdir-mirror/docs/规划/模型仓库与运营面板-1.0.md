# 模型仓库与运营面板（2026-07-30）

## 目标

给运营一张「模型广场 / 仓库」式总控台：一眼看清接入、映射、成本、售价毛利、容灾梯队；高性价比模型正式入库；高阶 VIP 可自选 OR 国际优质模型（计费倍率跟上）。

## 面板结构（已落地骨架）

管理台 **模型与系统** 内：

1. **系统开关** — 支付 / 模拟 / 上游模式 / 短信（可保存，立即生效）
2. **模型仓库**
   - 用户档位 auto/flash/pro/ultra → 层 / 当前上游 / FREE·VIP 容灾链
   - 层配置 L0–L3/QI：可改 model id 并保存
   - 目录：接入状态、成本 $/M、计费倍率、容灾下一档
   - 套餐毛利粗算（按 Flash 混合成本）
   - 容灾风险说明
   - VIP 自选通道开关（规划占位）
3. **流水毛利** — 近 N 日消耗/收入粗算

API：`GET|POST /v1/admin/token/model_warehouse`

## VIP 自选通道（拍板 · 2026-07-31）

**要做。** 国外买家常冲着「某一个国内名模」来；通用 `flash/pro` 试满意后，应能点名切到该模，**按该模倍率扣平台 credit**。

| 项 | 口径 |
|----|------|
| 谁可见 | 高阶 VIP（或 Pro Pass 及以上，具体档位上线前定） |
| 默认体验 | 仍用 `auto/flash/pro/ultra`，不强迫选模 |
| 自选列表 | **中国名模优先**（DeepSeek 系列、Qwen、GLM、Kimi…）；国际旗舰次之 |
| 路由 | **OR 能路由 → 只走 OR**；不为此先堆官方直连 |
| 直连加码 | 仅当：OR 长期贵/不稳/缺货 **且** 该模流水够大 → 再加官方 Key（DeepSeek 已有直连作回滚） |
| 扣费 | `消耗 × billing_mult`（对应该模成本）；控制台展示相对档位价 |
| 前台流程 | 控制台：档位试聊 →「解锁指定模型」列表 → 选模 → 调用带 model id → 账单可见倍率 |
| 宣传引导 | 英文首页/定价：**China models on demand (VIP)**；不在 hero 堆模型名清单 |

### 官方直连要不要多接？

| 策略 | 说明 |
|------|------|
| **目录广度靠 OR** | 名模上架以 OR model id 为主，后台仓库勾选启用即可 |
| **直连只保头腰** | 已有 DeepSeek；硅基作 L0；其余直连 = 运维+账单+熔断各一套 |
| **知名几家优先观察** | DeepSeek（已有）→ Qwen（百炼/国际区）→ 智谱 GLM → 月之暗面；有量再直签 |

## 容灾口径

- FREE：`L1 → L0`
- VIP：`L1 → L2 → L3`（自选模失败可降回同层默认，规则上线时写死）
- OR 整站挂：管理台切 `direct` + DeepSeek（不自动跨模式）
