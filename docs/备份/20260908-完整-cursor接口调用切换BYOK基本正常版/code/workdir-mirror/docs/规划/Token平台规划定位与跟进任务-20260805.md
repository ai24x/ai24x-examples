## 一、平台定位（一句话）

**AI24X Token = 国际统一 API 网关：鉴权 / 计费 / 路由 / PayPal，不自建大模型推理。**

卖平台 credit（flash | pro | ultra | auto | shared），用户不感知上游品牌；对外话术卖 AI24X Token，不宣称官方代理。

| 项 | 现行口径 |
|---|---|
| 正式生产 | 副脑04（SG）：www.ai24x.com + api.ai24x.com |
| 冷备份 | 副脑03 Token 同构机；日常发版默认捅 04，主脑明示才同步 03 |
| 注册 | www 邮箱为主；国内短信关 = 禁止一切手机注册（含内部密钥，已于 411c229 堵死） |
| 与行情官 | 分账号：a1 身份已本地在 03；不再写 04 auth_users |
| 上游默认 | OpenRouter（L1=DS Flash / L2=V4-Pro / L3=GPT-5-mini）；direct DeepSeek 作回滚 |
| 支付 | 国际 PayPal Live；国内微信/支付宝只服务行情官（03） |
| 预发 | 不做独立预发；本机合格 → Gitee → 04 生产门禁 |
| 两条流水 | 1. 国际 Token：主脑做通 → 04 收银 → 01 拉人 2. 行情官：主脑改功能 → 03 上线 → 02 运营 |

## 三、后续工作要点（按席位）

### ♟️ 主脑（AI24X 指挥）
- 战略拍板、仓库、Cursor 编码、验收、发生产指令、DEC
- Token 产品/计费/路由/控制台缺陷：本机修 → 推 Gitee → 只发 04 更新指令
- 跟进 P1（拍板后开单）：PayPal Webhook 第二履约；入门包国际价；MiMo 能力向 A/B；shared 质量与扣费策略
- 行情官线：功能改完发 03；勿把 a1 支付/身份再绑回 Token 库
- 禁：生产改密钥、日常客服、天天亲自部署

### 🔗 副脑04（AI24X国际token）· Token 正式收银
- 看店：www + api + 国际库 + PayPal Live + AI24X-core
- 日常：按主脑指令 git pull → 备份 → Restart-Service AI24X-core → 环回+公网烟测 → 飞书回执
- 保持：SMS_106_ENABLED=false + 管理台国内短信关；观察 token-admin 不再新增仅手机脏号
- 历史脏号：按需冻结；不擅自删库
- 监控：health、支付开关、OR/直连上游、控制台试调用
- 禁：行情官、国内支付商户、整文件覆盖 .env、手改业务代码

### 🛡️ 副脑03（AI24X行情官）· 行情官 + Token 冷备
- 主责：a.ai24x.com 部署门禁、备份、国内支付、本地身份/短信
- Token：仅冷备；无主脑明示不同步、不接正式 DNS
- 确认 a1 新注册不打 api.ai24x.com/v1/auth/register
- 禁：PayPal Live、国际获客 KPI、默认承接 www/api 正式流量

### 🚀 副脑01（AI24X游戏）· 获客末端
- VPN 出海：SEO / X·Reddit·HN / 英文内容 / 竞品 / 邮件
- 卖点对齐：统一 API、OpenAI 兼容接入、控制台试调用、PayPal 入门包
- 回传：线索与转化问题给主脑；支付/宕机转 04
- 禁：生产写权限、当收银机、搭预发

### 💬 副脑02（AI24X运营）· 行情官运营
- 种子群、社媒、教程、反馈初筛；不背国际 Token KPI

- 禁：生产部署、改计费支付
