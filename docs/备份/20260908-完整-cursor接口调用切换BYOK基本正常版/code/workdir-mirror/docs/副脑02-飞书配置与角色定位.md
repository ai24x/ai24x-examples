## 一、飞书通信配置（升级后用）

新版 OpenClaw 2026.7.1-2 已内置飞书通道。只需配置 appId/appSecret：

### 1. 查看你当前的飞书配置

```powershell
Select-String "feishu" "$env:USERPROFILE\.openclaw\openclaw.json"
```

如果有内容，说明旧版配置还在，直接重启就行：
```powershell
openclaw gateway restart
```

### 2. 如果配置丢了，重新配

```powershell
openclaw config set channels.feishu '{
  "enabled": true,
  "appId": "你的AppID",
  "appSecret": "你的AppSecret",
  "connectionMode": "websocket",
  "dmPolicy": "allowlist",
  "allowFrom": ["ou_abf1c1cb181f52a9455c1961cbc1b4f2"]
}'
```

> ⚠️ `appId` 和 `appSecret` 从飞书开发者后台拿，跟主脑用的是同一套的话直接复制就行。

### 3. 验证飞书通不通

```powershell
openclaw gateway restart
```

重启后在飞书给 Bot 发条消息，能回复就通了。
