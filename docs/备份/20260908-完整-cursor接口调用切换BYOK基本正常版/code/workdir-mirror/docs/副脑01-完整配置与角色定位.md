# 副脑01 · OpenClaw 完整配置 + 角色定位

---

## 一、升级（如果还没升）

```powershell
taskkill /F /IM node.exe 2>$null
npm install -g openclaw@latest
openclaw --version
openclaw gateway restart
```

---

## 二、DeepSeek 配置

先找回旧 Key：

```powershell
openclaw models auth list
echo $env:DEEPSEEK_API_KEY
Select-String "deepseek" "$env:USERPROFILE\.openclaw\openclaw.json" -ErrorAction SilentlyContinue
```

配置 Key：

```powershell
openclaw models auth add deepseek:default --provider deepseek --mode api_key
```

加别名：

```powershell
openclaw config set "models.deepseek/deepseek-v4-flash.alias" "DeepSeek"
openclaw config set "models.deepseek/deepseek-v4-pro.alias" "DeepSeek Pro"
```

---

## 三、飞书通信

检查旧配置：

```powershell
Select-String "feishu" "$env:USERPROFILE\.openclaw\openclaw.json"
```

有内容就重启，丢了就重新配：

```powershell
openclaw config set channels.feishu '{
  "enabled": true,
  "appId": "你的AppID",
  "appSecret": "***",
  "connectionMode": "websocket",
  "dmPolicy": "allowlist",
  "allowFrom": ["ou_abf1c1cb181f52a9455c1961cbc1b4f2"]
}'
```

重启验证：

```powershell
openclaw gateway restart
```

在飞书给 Bot 发消息测试。

## 四、⚠️ 重要！Gateway 别乱重启

```powershell
# ❌ 不要频繁 restart，容易卡死

# ✅ 改配置用热生效，不重启
openclaw config set xxx yyy

# ✅ 只有装插件、更新版本才需重启

# ✅ 如果卡死了：
taskkill /F /IM node.exe
openclaw gateway restart
```
