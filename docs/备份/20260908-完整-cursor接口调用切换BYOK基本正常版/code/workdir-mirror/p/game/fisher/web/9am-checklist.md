## 9 点验收清单（海王 · 山海渔 H5）

### 已开发完成（你可直接体验）

- **不重启即可生效**：`web/` 纯静态页，更新后用 **Ctrl+F5** 强制刷新即可
- **入口**：`index.html`（主钓场）、`bag.html`（仓库）
- **系统设置框架**：顶栏 `⚙️设置`
  - 声效开关（WebAudio）
  - 动效开关（reduced-motion）
  - 震动开关（如支持）
  - 夜晚模式开关（不喜欢可关闭）
- **角色徽章**：右上角显示当前角色 icon + 名称（后续可扩展成自定义头像入口）
- **天空元素可见**：太阳/月亮/云朵下移
- **夜钓聚光**：夜晚浮漂周边自动照亮（手电筒增强亮度/范围）
- **抛竿落水水花**：浮漂落水有水花
- **仓库展示增强**
  - 每格：鱼名 + 条数
  - 桌面端 hover：名称/持有/基准价/系统回收价 tooltip
- **仓库独立页（首期闭环）**
  - `bag.html`：回收 1 条 / 回收全部 / 一键回收（全部）
  - 数据本地持久化：刷新不丢（金币/阅历/库存/道具）
- **等待期轻互动**：随机出现蝴蝶/小乌龟/青蛙等，可点击触发反馈
- **更真实钓鱼流程（可爽感验收）**
  - 抛竿 → 等口 → **扬竿窗口期**（不及时会跑鱼，带随机）→ 遛鱼（需连续点扬竿）→ **抄网窗口**（抓住时机收鱼）→ 飞鱼入仓
  - 遛鱼进度条：越后面越拼手速，停顿会掉进度；并带少量“运气值”影响

### 待你确认（产品口径）

- **回收口径**：首期确认“仅系统回收价（当前为基准价的 80%）”，二期再开玩家市场
- **角色系统**：首期是否仅“选择角色”，还是要“头像/昵称/换装”同步上线
- **惊喜系统强度**：稀有事件触发频率（更爽 vs 更克制）
- **装备口径**：`hook/bait/float/rod` 首期是“一次买断”还是“次数/耐久消耗”

### 待你配合（对接后端/小程序前必须给的输入）

- **数值配置最终版**：鱼价/钓场解锁价/竿升级消耗（以 `产品规划-完整版-v1.0` 为准，是否需要微调）
- **合规策略**：UGC 打卡与分享是否计划进阶段三（需审核/举报/关键词）
- **域名与合法域名**：小程序请求域名白名单（预发/生产）
