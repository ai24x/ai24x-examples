## 玩法范围（老板定调）

不限于双人/多人——凡满足「吸引人玩（上瘾循环）」+「刺激邀请分享裂变（挑战卡片/好友排行/每日关卡）」的玩法都进矩阵：
- 双人/多人 PK（异步挑战为主，实时对战待版号）
- 单机魔性玩法（合成/跳跃/解压等）+ 好友排行
- 每日挑战（同种子关卡）、答题比拼等

## 通用约定

- 一项目一目录：p/game/<key>/（api/web/miniprogram/docs/scripts + README.md）
- 数据库：中台用独立 game_core 库；渔悦暂与 a1 预发共用本机 PG，样本快照见 p/game/fisher/db/
- 合规红线：实时匹配对战需版号+文网文+ICP；版号前只做异步挑战/单机+社交层
- 验收纪律：每款按 5 条标准（过审≤2 次/UV>500/7 天收入>0/次留≥30%/分享≥15%/≤30 天），达标复制、不达标 2 周内砍
