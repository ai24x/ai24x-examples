# 小游戏 AppID 注册指引（给游戏官）

> 主体：乐清市速度网络有限公司 ｜ 域名：game.ai24x.com ｜ 2026-08-13

## 一、AppID 获取流程

1. 登录 **https://mp.weixin.qq.com**（微信公众平台）
2. 右上角「立即注册」→ 选 **「小游戏」** 类目
3. 填主体：**企业 → 乐清市速度网络有限公司**（需营业执照、法人身份证、对公打款或法人微信验证）
4. 注册邮箱：需**未绑定过**微信公众平台的新邮箱
5. 管理员：雷总扫码绑定
6. 注册后 → 后台「开发 → 开发设置」→ **开发者ID(AppID)**

## 二、架构要求

- **每个游戏一个独立账号 = 独立 AppID**：
  - P0-1「别听它的」→ AppID-1
  - P0-2「离谱合成实验室」→ AppID-2
- 一套中台（core-api）+ 各游戏独立 AppID

## 三、服务器域名配置

- 后台「开发 → 开发设置 → 服务器域名」→ request 合法域名填 **https://game.ai24x.com**
- 域名已备案（继承 ai24x.com 主域名备案）

## 四、软著/版号

- 软著：**暂缓**（发布时平台要求再申请）
- 备案：已备案过，不重复办

## 五、注意事项

- AppID 注册需雷总操作（企业主体 + 管理员扫码），游戏官负责核对配置
- 注册完成后，把 AppID 登记到本文件 + 告知总司令备案
