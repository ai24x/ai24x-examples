# P0-1「别听它的（反口令反应战）」PRD

> 定稿：2026-08-13 ｜ 负责人：司令 ｜ 类目：小游戏·休闲益智 ｜ 变现：纯 IAA（免版号）
> 一句话：45 秒反直觉指令连击游戏——明知故犯的挫败感 + 连击段位 + 好友挑战，让人「再来一局」。

## 一、玩法规则（v1，先做最简闭环）

- **一局 45 秒**：屏幕顶部出指令，玩家在按钮区做「相反」操作，答对 +1 连击，答错连击清零。
- **指令类型（v1 上 3 种，节奏错开）**：
  1. 颜色指令：说「点【红】」→ 玩家必须点「绿」（反色）；字体颜色与字义冲突（Stroop 干扰，如「红」字用绿色显示）。
  2. 方向指令：显示「→」→ 玩家必须按「←」；方向用图标+文字双重干扰。
  3. 数字指令：显示数字 N → 玩家必须按 N+1（如显示 3，按 4）。
- **难度递增**：指令间隔 1.5s → 0.8s；v1 固定梯度 5 档，按连击数升档。
- **积分**：基础分 + 连击倍率（连击×1 到 ×5 封顶）；单局总分 = 段位升级依据。
- **段位**：青铜→白银→黄金→铂金→钻石→星耀→王者（累计积分升级，v1 本地判定，v2 入中台）。
- **续命**：倒计时结束 → 弹「看视频续 15 秒」（激励视频），每局限 1 次。
- **双倍积分**：开局可选「看视频本局双倍积分」。

## 二、裂变钩子（分享/挑战）

1. **挑战卡片（主钩子）**：单局结束 → 「我击败了 87% 好友，敢来吗？」卡片 → 好友进入同种子 45 秒局 → 回传比分 → 双方战报。
2. **每日挑战**：每日同种子固定序列，全服比分数，榜单刺激次日回来。
3. **段位/连击炫耀**：连击 10/20/50 彩蛋截图一键分享。
4. **排行**：好友周榜（开放数据域渲染）+ 超越 X% 好友文案。

## 三、广告点位（IAA，全部激励视频 + 低频插屏）

| 点位 | 类型 | 触发 | 频控 |
|---|---|---|---|
| 续命 15s | 激励视频 | 倒计时结束 | 每局限 1 次 |
| 双倍积分 | 激励视频 | 开局可选 | 每局限 1 次 |
| 每日挑战重试 | 激励视频 | 每日挑战失败 | 每日 2 次 |
| 插屏 | 插屏 | 每 3 局结束 | 低频，v1 可先关 |

## 四、技术方案

- 引擎：Cocos Creator 3.8（先出 H5 原型，微信构建发布到 miniprogram/）。
- 中台：p/game/core（登录/榜单/挑战/埋点/广告验证）。
- 关键埋点：首局完成率、次留、分享率、人均激励视频数（对应 5 条验收标准）。
- 包体目标：主包 < 4MB（无外部美术素材，纯色块+字体+粒子动效）。

4. 次日留存 ≥30%、分享率 ≥15%；
