# P0-1「别听它的」微信小程序原型（原生）

> 状态：原型 v0.1（2026-08-13）｜ 形态：微信小程序（原生 WXML/WXSS/JS，未用 Cocos）
> 目标：在微信开发者工具中直接体验完整玩法闭环，验证「反口令 + 连击倍率 + 段位 + 续命 + 挑战卡分享」链路
> 玩法 PRD 见 ../docs/PRD.md；H5 可玩原型见 ../prototype/index.html

## 快速开始
1. 打开微信开发者工具 → 「导入项目」
2. 目录选择本目录 `p0-1/miniprogram`
3. AppID 选择「测试号」（已内置游客 appid `touristappid`，可直接编译）
4. 编译运行，首页点「开始挑战」即可试玩

## 已实现（对应 PRD v1）
- 一局 45 秒倒计时；三种指令：颜色（Stroop 字义/颜色冲突）/ 方向 / 数字 N+1
- 指令间隔随连击提速 1.5s → 0.7s（每 5 连击 +1 档）
- 计分：基础 10 分 × 连击倍率（每 10 连击升 1 档，最高 ×5）；答错连击清零
- 段位：青铜 → 白银 → 黄金 → 铂金 → 钻石 → 星耀 → 王者（v1 本地累计积分判定）
- 续命：时间到可看（模拟）激励视频 +15s，每局限 1 次
- 双倍积分：开局可选看视频本局得分 ×2
- 结算页：得分/段位/答对/最大连击/击败百分比 + 挑战卡分享（open-type=share）
- 每日挑战：按日期同种子固定序列（占位，v2 联调中台全服榜单）
- 本地存档：最高分/累计积分/局数/最近 20 局历史/每日挑战记录

## 目录结构
```
miniprogram/
├── app.js / app.json / app.wxss      # 全局
├── project.config.json               # 开发者工具配置（游客 appid）
├── sitemap.json
├── utils/
│   ├── game.js                       # 游戏核心逻辑（纯函数，可单测）
│   ├── store.js                      # 本地存档
│   └── ad.js                         # 激励视频封装（原型=模拟广告）
└── pages/
    ├── index/                        # 首页：规则/双倍开关/每日挑战/榜单
    ├── play/                         # 游戏页：45s 反口令循环/续命浮层
    └── result/                       # 结算页：战绩 + 挑战卡分享
```

## 模拟与占位（上线前替换）
| 项 | 现状 | 上线前 |
| --- | --- | --- |
| 激励视频 | utils/ad.js 内置 1.5s 模拟广告 | 开通流量主后填 adUnitId |
| 好友榜 | 首页本地模拟数据 | 中台 /rank + 好友关系链 |
| 挑战卡回传 | 仅分享文案/落地首页 | 中台 /challenge 同种子局 + 战报回传 |
| 登录 / 埋点 | 无 | 中台 /auth + /events |

## 与 H5 原型差异
- 新增：双倍积分开关、续命浮层、本地存档、每日挑战入口、段位展示
- 计分/连击/难度曲线与 H5 完全一致（utils/game.js 为纯逻辑，可跑单测）

## 已知边界（原型取舍）
- 数字指令按钮 1-6，正确率未做随机干扰；每日挑战未做「失败看视频重试」（PRD 广告点 3）
- 开发者工具中 `wx.vibrateShort` 无效果属正常，真机生效
- 中台（p/game/core）联调前，全部数据为本地存储，删除小程序缓存即重置
