### 产出 A：体验问题清单（12 条，现象→原因→改进建议）
1. 提示语直接剧透答案：hint 全程显示「显示3→按4」「说点红→点绿」，玩家照做即可，反口令挑战感消失。
   原因：hint 设计为教学但无阶段切换。建议：前 3 题保留教学提示，之后只给规则提醒。
2. 首题无预热：点开始瞬间出题，玩家易漏看第一题。原因：start() 立即 tick+spawn。建议：3-2-1 倒计时 + GO 再开局。
3. 答题空窗期可重复点按刷连击：答对后到下一题渲染前（1.5s~0.7s）同一题可连点多下。
   原因：answer() 后未锁定输入。建议：答后立即锁定，新题渲染完再解锁。
4. 后台/切标签倒计时漂移：tick 用 setTimeout 递减计数，页面隐藏时浏览器节流定时器，45 秒被拉长。
   原因：以递减计数而非绝对时间戳计时。建议：用 Date.now() 的 endAt 计算剩余。
5. 答错反馈弱：只有「错!」文字。原因：无视觉/听觉/触觉强化。建议：红闪 + 按钮区抖动 + 低沉音 + 震动。
6. 全程静音：对/错/彩蛋/结束无音效，爽感出不来。原因：无音频。建议：WebAudio 合成音效（无外部素材）。
7. 移动端无震动反馈。原因：未调 navigator.vibrate。建议：答对轻震、答错重震、彩蛋连震。
8. 连击 10/20/50 无彩蛋（PRD 明确设计）。原因：未实现。建议：彩蛋横幅 + 音效 + 震动 + 埋点。
9. 结算页「击败 X%」爽感不足：只有一行文字。原因：无视觉强调。建议：击败进度条动画 + 一键复制挑战文案。
10. 移动端适配不足：点击区偏小、无安全区、双击缩放/长按选择干扰操作。
    原因：桌面优先样式。建议：min-height 64px、env(safe-area-inset-bottom)、touch-action: manipulation。
11. PRD「看视频双倍积分」未落地。原因：v1 原型只有续命占位。建议：首页加双倍开关（占位），本局得分 ×2，game_start 带 doubled。
12. 续命按钮点击立即 +15s，与真实激励视频体验不符。原因：无广告模拟。建议：1.2~1.5s「模拟广告」遮罩后再发奖，埋点 life_used。
