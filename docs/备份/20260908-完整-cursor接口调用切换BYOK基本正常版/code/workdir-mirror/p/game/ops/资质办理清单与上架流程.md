# 资质办理清单与上架流程（游戏官 定稿 2026-08-13，官方口径已核实）

## 一、架构定论：一游戏一小程序 + 中台（不做平台盒子）
每款小游戏 = 独立 AppID（独立小程序），统一复用中台 core（账号/排行榜/广告配置/埋点/合规 SDK）。四硬理由：
1. 合规红线：平台运营规范 5.10 禁止「对小程序/小游戏排行、推荐、推广或集中设立跳转、添加平台服务」；盒子/聚合互跳明确违规，轻则整改重则封号。跨游戏导流一律走公众号/分享/搜索自然流量，不在小程序内做导航互跳。
2. 包体限制：小游戏主包约 4MB、总包约 20MB 级，多游戏同包必然超限，被迫分包+远程资源，工程复杂度大增。
3. 结算与风控隔离：广告按 AppID 独立结算；独立 AppID = 单游戏违规不连坐、独立对账、独立投放测试。
4. 运营聚焦：独立小程序可独立获客（搜索/分享/投流）、数据干净、快速验证哪款能跑，跑通即复制。

## 二、数量限制（微信官方口径核实 2026-08-13）
| 项目 | 企业主体 | 个体户 | 个人 |
|---|---|---|---|
| 小程序注册上限 | 50 | 5 | 5 |
| 小游戏注册上限 | 100（第三方转载官方通知口径，官方文档页与小程序同表） | 5 | 5 |
| 小程序备案上限 | 50 | 5 | 5 |

- 绑定上限：1 手机号/身份证/微信号 绑定小游戏 ≤ 3 个主体下所有小游戏；绑定小程序 ≤ 5 个；1 微信号最多成为 50 个小程序/小游戏开发者。
- 一个邮箱只能注册 1 个小程序/小游戏。
- 结论：按保守口径 50 个/主体规划，矩阵 20-30 款完全够用；未来扩容 = 新增企业主体（现已有 乐清市速度网络有限公司）。
- 真瓶颈不是数量，是每款都要：独立邮箱 + 企业认证 300 元/年 + 备案工时 + 管理员绑定资源。

## 三、每款小游戏上架全流程（时间线）
1. 注册：mp.weixin.qq.com 小游戏模板注册（独立邮箱）→ 填主体（乐清市速度网络有限公司）→ 法人/对公验证。
2. 微信认证：企业 300 元/年/款（需营业执照 + 对公账户信息）。
3. 备案：后台-设置-小程序备案（第 2 款起用「复用主体资料」，主体负责人短信确认）→ 平台初审 1-2 工作日 → 管局 1-20 工作日 → 24 小时内工信部短信核验。备案不可省：上架报错 errcode 86369「小程序上架需先完成备案」。
4. 开发联调：体验版不需要任何资质，开发线全程不停；中台 core 联调 + 广告 SDK 接入。
5. 提审：类目选「小游戏-休闲」；纯 IAA 休闲小游戏免版号；审核 1-7 天。
6. 发布 → 开通流量主（累计独立访客 ≥1000 + 微信认证，以平台后台提示为准）→ 接入激励视频/插屏。

## 四、名称避雷（备案前置审批关键词，官方表节选）
避开：动漫/动画/网络文化/演出/音像/新闻/直播/出版/教育/培训/金融/投资/基金/保险/医疗/药品/网约车/商城/商贸/公司/集团/监管/政府 等。
对策：P0-1/P0-2 用纯中文玩法名（如「别听它的」「离谱合成」），不带「软件」「公司」等字样；软著按 IAA 口径后置（纯 IAA 休闲小游戏备案非必填，保险方案=电子版权证书 10-15 天/加急 1 个工作日）。

## 六、待办排序（等雷总确认后派指令给主脑）
1. 注册 P0-1 小游戏账号（与开发并行，不阻塞）
2. 微信认证（300 元）
3. 备案（复用资料加速后续每款）
4. 开发完成 → 提审 → 发布 → 流量主

## 七、注册决策门：玩法验证先行（2026-08-13 雷总定）

- 原则：**注册/认证/备案一律等玩法验证通过后再启动**，不与开发抢跑。注册提交后主体信息即固定（公司名/法人/对公账户不可换），名称虽可改但有次数限制、内容可迭代——所以「先验证好不好玩」是零风险投入。
- 验证路径（全部免费，不需要正式账号）：
  1. H5 原型：`p0-1\prototype\index.html`，浏览器直接玩，0 成本（已就绪）。
  2. 微信开发者工具 + 测试号：扫码即用，不注册正式 AppID，微信内真机体验小游戏 API（广告除外）。
  3. 试玩样本：≥10 人（朋友/同事/目标玩家）。
- 通过标准（建议，可调整）：试玩者 ≥70% 玩满 3 局 或 主动要求再玩一局；≥50% 表示愿意分享挑战卡片。
- 通过后启动注册：注册 → 认证 300 元 → 备案（复用主体资料）→ 提审 → 上架。
- 不阻塞项：H5/小程序玩法迭代、中台 core 联调（测试号即可）、广告 SDK 联调（需 AppID 后置）。
