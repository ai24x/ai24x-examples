# 板块排名与主线判定优化任务书

> 日期：2026-08-18 ｜ 提出：司令（Codex） ｜ 目标会话：AI行情官开发会话 ｜ 状态：待拍板范围后开工
> 数据基准：2026-08-18 实盘归档（hs/kc/bj/bj_all + 复盘 20260818）

## 一、背景与目标

用户反馈「板块排名找不准主线、筛选不出优秀个股，只想要精准主线 + 刚底部异动/首板右侧上拐的优质标的」。经深度核查今日实盘数据，板块排名链路整体成立，但存在 3 类可优化点：

1. **新晋主线判定门槛偏松**：两条升线路径都不看资金，导致「5日主力仅 2.8 亿、板块 5日 -0.76%」的煤炭仍升主线占 key 位；
2. **北证板块分桶未归一化**：煤炭开采/煤炭/焦煤/煤化工被拆成多个桶，主线被稀释；
3. **MACD首红 / 回踩企稳两栏数据源太窄**：今日均空转或仅 2 只，达不到「帮用户筛出好票」的效果。

目标：在不破坏既有「收盘后定型数据（15:10）」口径的前提下，提升主线判定精准度、板块榜可解释性、两栏内容丰满度。

## 二、现状链路（煤炭入选复盘，供开发对照）

- 今日 15:06 复盘（daily_report）锁定主线：AI服务器算力、通信光模块CPO（延续）+ 煤炭（新增）；半导体退潮。
- 煤炭判定：板块 6 只体检样本 top5 均值 75.2（全场最高）、今日平均 +1.44%、2 只涨停 → 命中「top5≥58 且 avg_up≥0」与「情绪确认（≥1涨停）且 top5≥55」两条新晋主线路径（均无资金门槛）。
- 掘金 hs/kc 读取复盘主线 → `_board_rank_funds` 按复盘顺序强制 king/key/key（资金不参与前置）→ 煤炭占「重点关注」位。
- 实据反差：煤炭 5日主力 +2.8 亿、今日 +0.95 亿、板块指数 5日 -0.76%。
- 北证两栏（bj/bj_all）走 `reverse_mainline`（异动家数+成交额反推），今日出 通用设备/半导体/种植业 等，不强制跟复盘主线。

## 三、P0 优化项（建议本次必做）

### P0-1 新晋主线资金/量能二次确认

**文件**：`p\a1\api\server\app\daily_report.py` → `pick_main_lines` / `mainline_judgment`

**现状**：新晋主线三条路径中，两条（top5≥58 且 avg_up≥0；confirmed 且 top5≥55）不查资金。

**方案**：新晋主线增加「资金/量能二次确认」硬门槛（三选一，满足任一即升主线，否则降级观察）：

- a) 今日板块主力净流入 f62 > 0 且 5日主力 f164 ≥ 10亿；
- b) 涨停家数 n_zt ≥ 2（强情绪可放宽资金：仅要求今日 f62 > 0）；
- c) 昨日主线延续不适用本规则（延续走既有独立规则，保持不变）。

**细节要求**：
- 资金数据缺失（plate_data 无 f62/f164，或值为 None）时，一律按「未通过资金确认」处理 → 降级观察，不允许「数据缺失当通过」；
- 技术达标但资金未确认的板块 → 进入 observes（观察），次日资金确认后再升主线；
- 主线上限 3 条、每日新晋≤3 的既有约束保持不变；
- 排序仍用 composite（top5×0.5 + 资金标准化×30 + 情绪×20）不变。

**回归验证**：对 2026-08-18 复盘数据回放——煤炭（5日主力 2.8 亿、今日 +0.95 亿、2 涨停）应因条件 b（n_zt≥2 且 f62>0）仍升主线；构造「1 涨停 + 资金弱」用例应入观察。

### P0-2 板块桶名归一化（北证栏）

**文件**：`p\a1\api\server\app\bj_screener.py` → `reverse_mainline`（约 2617 行）

**现状**：分桶用原始 f128 概念串，行业兜底用原始 f100；`_norm_name`（1072 行）只用于 board_hit 标注，不用于分桶。「煤炭开采/煤炭/焦煤/煤化工」各自成桶，主线被稀释。

**方案**：
- 新增 `_bucket_norm(name)`：去空格、去「概念/行业/板块/开采加工/化工」等业务性后缀，并按别名映射归一（复用 `daily_report.SECTOR_BOARD_ALIASES` 与 `_MAINLINE_BOARD_MAP` 反向表，未知名称保留原文）；
- 分桶顺序不变（f128 概念优先、f100 行业兜底），但键统一用归一化后的桶名；
- 同一只股票命中同一归一桶的多个概念词时只计一次（去重）；
- 桶展示名保留最规范名称：映射表规范名 > 概念原文 > 行业名；
- `board_hit` 热点判定对归一前/归一后名称都尝试匹配，避免热点漏标；
- 影响面：北证主线（bj）、北证全市场（bj_all）两栏；沪深/科创不受影响（走 `_board_rank_funds`）。

## 四、P1 优化项（建议本次顺带做，或排下一轮）

### P1-1 板块排序命中率归一化 + 形态加权（北证栏）

**文件**：`bj_screener.py` → `reverse_mainline`

**现状**：按（-count, -amount）排序，count 为原始异动家数；6 种形态等权，surgeStart（强异动）与 smallYang（弱小阳）同为 1。

**方案**：
- 每个桶统计 `total_cands`（候选池内属于该桶的候选总数，含未命中形态者），计算 `hit_rate = count / total_cands`；
- 排序分建议：`rank_score = count × (1 + min(hit_rate, 1) × 0.5)`，防止大板块绝对容量占优；amount 仍作次级排序键；
- 形态加权（仅用于排序分，展示仍显示整数异动家数）：ztPullback / pullback2 / surgeStart / firstBoardRight 权重 1.0，pullback 0.8，baseUp / smallYang 0.6；
- 对「count 相同」的板块，hot（板块榜命中）优先。

### P1-2 MACD首红数据源拓宽

**文件**：`bj_screener.py` → `macd_view` / `run_scan` 中 macd_red_pool；`daily_report.py` 复盘样本

**现状**：`macd_view` 复用「all」扫描（沪深京全市场重扫 1-2 分钟，今日无 all 缓存；hs/kc/bj 归档 macd_reds 全空）。`macdFirstRed` 要求金叉 1-3 根红柱 + 首红日量≥1.2×前 20 日基准 + 位置≤50% + 站稳 MA5，门槛偏严。

**方案**：
- A（推荐，零上游成本）：从每日复盘 `sector_score.json` 全量体检样本（约 16 板块 × 6 只）中提取「MACD翻红第 1-3 天 + 位置≤50% + 无 hard 风险」标的，展示 code/name/score/red_days/up_pct，保证今日必有内容；
- B：all 扫描时放宽首红量能门槛（1.2× → 1.0×），位置放宽至 ≤60%，减少漏检；
- A、B 都做：A 保证当日有内容，B 保证全市场不漏；数据源标注（复盘样本 / 全市场扫描）随接口返回。

### P1-3 回踩企稳数据源拓宽

**文件**：`bj_screener.py` → `pb_view`

**现状**：只过滤 hs 扫描 picks+runners（约 12 只）中的 ztPullback / pullback2 / firstBoardRight，今日仅出 潞安环能、至纯科技 2 只。

**方案**：
- 改为基于 all 扫描（与 MACD 首红共用一次全市场缓存，不重复触发）；过滤条件不变；
- 或独立「板后回踩」轻筛：近 10 日有涨停（含首板）→ 回调≥1 日不破板日低/MA5 → 今日放量上拐（仅 K 线，不跑 AI 快照，成本低）；
- 前端 scope 文案同步改「沪深京全市场·首板回踩企稳」（gd.html + m/gd.html）。

### P1-4 板块榜透传主线判定小字

**文件**：`bj_screener.py`（board_rank 条目）+ `web/js/bjscreener.js`（renderBoardRank）+ `web/gd.html` + `web/m/gd.html`

**现状**：hs/kc 榜 key 位显示「5日主力/今日主力/5日涨幅」，煤炭这种「5日 -0.76% 但新晋主线」用户看不懂为什么上榜。

**方案**：
- board_rank 主线条目（king/key）增加 `ml_src`（new/cont）与 `ml_why` 字段（如「新晋主线 · top5 75.2 / 2涨停 / 今日 +1.44%」「延续主线 · 资金主攻」），数据复用 `_dml_info`（mainline_judgment 已产出，透传即可）；
- 前端：主线条目在数据行前渲染「新晋/延续」徽标 + ml_why 小字（复用主线卡片样式）；
- 非主线 backup 保留现状。

### P1-5（可选）科创榜代表股按市场过滤

**文件**：`bj_screener.py` → `_board_rank_funds` / leaders 展示

**现状**：kc 榜煤炭代表显示 中国神华/陕西煤业/兖矿能源（沪主板），与科创栏目错位。

**方案**：板块榜 leaders 按市场过滤（kc 只留 30/688）；无科创成分时显示「板块代表为沪市主板龙头（仅供参考）」或留空。影响面小，可并入 P1-4 前端一并处理。
