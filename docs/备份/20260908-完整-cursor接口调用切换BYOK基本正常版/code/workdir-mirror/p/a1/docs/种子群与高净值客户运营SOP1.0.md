# 种子群与高净值客户运营 SOP 1.0

> 目标：把现有几十人种子群变成「转介发动机」，逐步发展高净值、重度、愿付费用户。
> 定位：行情数据可视化工具。一切运营话术不得越过《产品合规红线清单》。

---

## 一、客户分层与转化路径

| 层级 | 权益/价格 | 目标 | 转化动作 |
| --- | --- | --- | --- |
| 免费体验 | 每日/每周限额 | 体验价值、留存 | 群内每日干货 + 限额提醒 |
| 体验卡 | 8.8 元 | 首单付费 | 限时体验卡 + 对比免费版额度 |
| 月卡 | 888 元 | 高频使用 | 连续使用案例 + 到期提醒 |
| 年卡 | 8888 元 | 锁长期 | 年卡折合月价对比 + 专属服务 |
| 成长档 | 5000 元 | 重度用户 | 1对1技术支持 + 数据源优先级 |
| 合作伙伴 | 10000 元 | 转介/合作 | 合作协议 + 专属通道 + 转介权益 |

## 二、种子群日常运营（每周节奏）

- **周一**：行情数据周报（数据解读，不出买卖建议）。
- **周三**：产品功能演示/新版本更新说明。
- **周五**：答疑专场（限时 1 小时，主理人亲自答）。
- **每日**：早报 1 条（数据快照）+ 群公告维护。
- **每周**：统计「邀请转化榜」，给前三名小额权益奖励（非现金）。

## 三、高净值客户开发路径

1. **识别**：从付费/高频/深度使用用户中筛选，关注其对数据源、稳定性、深度的诉求。
2. **触达**：先 1 对 1 私聊了解需求，再约 15 分钟线上演示，不群发不打扰。
3. **转化**：按需推荐年卡/成长档/合作伙伴；强调服务、数据优先级、技术支持，不承诺收益。
4. **交付**：签约后 24 小时内建专属服务群（客户+业务负责+客服），明确响应时效。
5. **转介绍**：客户满意后自然提一句「如有同类需求的朋友可以转介」，转介权益按平台规则发放，不搞拉人头话术。

## 四、转介机制（合规版）

- 邀请回馈只挂钩「实际支付成功订单」，按金银铜等级阶梯返点。
- 现金结算仅对签约城市合伙人开放；普通用户回馈为非现金权益。
- 严禁：发展人数计酬、多级返利、自买自返、收益承诺话术。

## 五、关键指标（每月复盘）

- 免费→付费转化率；月卡→年卡升级率；转介带来的新增占比；高净值用户（≥年卡）数量与续费率；客单价。

## 六、证据与留档

- 每期干货、每场答疑、每次 1 对 1 沟通要点均记录存档（群文件/CRM）。
- 群公告、活动规则截图留存，防止事后被断章取义。
