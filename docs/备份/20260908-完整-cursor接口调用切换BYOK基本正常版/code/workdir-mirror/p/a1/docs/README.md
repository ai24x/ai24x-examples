### 计次与使用规则（MVP，重要）

- **默认预览不扣次**：首次进入 `demo.html` 的默认指数展示、以及刷新后恢复到上次标的/周期，均为预览模式（不扣次）。
- **主动操作才计次**：点击“查询”或切换周期（日/周/月）会按规则计次（仅在 K 线数据成功返回时扣次；失败/离线不扣）。
- **4 个指数免扣次（白名单）**：
  - 上证指数 `1.000001`
  - 深证成指 `0.399001`
  - 创业板指 `0.399006`
  - 北证50 `0.899050`
- **去重窗口**：同一标的同一周期在 **60 秒**内重复查询会去重（减少来回切换浪费次数；可通过环境变量 `AI24X_DEDUPE_SECONDS` 调整）。
