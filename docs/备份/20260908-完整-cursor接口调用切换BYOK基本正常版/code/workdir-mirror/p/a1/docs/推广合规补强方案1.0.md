## 一、核心定位修正（先改叙事，再谈推广）

### 当前定位 vs 建议定位

| 维度 | 当前叙事 | 建议叙事 | 原因 |
|------|----------|----------|------|
| 品类 | 股票信号分析 | **金融数据可视化工具** | 工具类合规门槛远低于投资类 |
| 核心能力 | 底/B信号 | **K线图智能标注 + 多周期数据对比** | 去"信号"化，强化"数据"化 |
| 用户价值 | 辅助判断买卖 | **让K线图一眼看懂** | 从"帮你决策"变成"帮你阅读" |
| 对标 | 同花顺指标 | **TradingView + AI** | 对标国际工具而非本土荐股软件 |
| 口号 | AI信号一页看清 | **行情数据一目了然** | 中性化、工具化 |

### 一句话新定位

> AI行情官 — 用 AI 帮你看懂 K 线图的数据可视化工具。

### 网站上需要调整的措辞（优先级高）

| 位置 | 当前措辞 | 建议改为 |
|------|----------|----------|
| 首页标题 | 含"信号""底""B" | "智能K线标注，行情一目了然" |
| 功能描述 | "底信号/B信号" | "技术形态标注（标注A/标注B）" |
| CTA按钮 | "查看信号" | "查看行情" |
| 分享卡片 | "AI行情官·信号一页看清" | "AI行情官·行情数据一目了然" |
| 注册引导 | "每天看信号" | "每天看行情" |

> 这些改动本身不改变产品功能，但会显著降低平台审核的风险判断。

## 二、平台合规生存指南（补充已有手册）

已有手册覆盖了抖音的"不说买/卖"，这里补充**更隐蔽但致命的坑**：

### 2.1 微信生态（公众号+视频号+朋友圈+群）

**微信是监管最严的平台**，但也是股民最大的聚集地。

#### 绝对红线（比抖音更严格）

| ❌ 触之必封 | 原因 |
|------------|------|
| 公众号文章含股票代码+分析 | 微信对"荐股"零容忍 |
| 朋友圈频繁发K线截图 | 被好友举报→封朋友圈 |
| 微信群名含"股票""炒股""荐股" | 群名敏感词扫描 |
| 公众号/视频号认证为"财经"类 | 需要资质，个人无法通过 |
| 文章中直接放网址链接 | 触发广告审核 |
| 诱导分享（"转发到3个群免费看"） | 微信最恨裂变 |

#### 安全做法

| 场景 | 安全做法 |
|------|----------|
| 公众号 | 注册为"科技/工具"类而非"财经"类；内容教"怎么看数据"不教"怎么买" |
| 视频号 | 发"K线图怎么看"教程，不分析个股；简介写"数据可视化工具" |
| 微信群 | 群名"AI行情官·用户交流"（去"股票""信号"）；群公告放工具链接 |
| 朋友圈 | 每月发1-2条工具功能介绍，不晒股票分析；配文"自己做的小工具" |
| 公众号文章 | 文末放"阅读原文"跳转官网，不在正文放链接；加"体验工具"引导 |

#### 微信搜一搜 SEO

微信搜一搜流量不容忽视。优化方向：
- 网站标题/描述含"K线""行情""数据"而非"信号""荐股"
- 公众号名字注册为"AI行情官"（先占坑）
- 公众号发5篇以上原创文章，才有搜一搜权重

### 2.2 抖音补充：账号等级与养号策略

已有手册说"不发买/卖"，但实践层面有更多坑：

#### 账号等级

| 等级 | 判断标准 | 内容策略 |
|------|----------|----------|
| 新号（0-30天） | 无权重 | 只发"学习方法"类内容，不提任何工具名 |
| 成长期（1-3月） | 有基础权重 | 开始发方法论+工具植入（隔条植入） |
| 稳定期（3月+） | 权重稳定 | 正常内容节奏，可适当加大工具曝光 |

#### 养号期（前2周）内容策略

前10条内容**完全不出现AI行情官**，只发纯方法图文：
- "K线入门：一根K线看4个信息"
- "均线是什么？3分钟看懂"
- "成交量怎么看？缩量放量是什么意思"

目的：让抖音算法把你标记为"知识分享类"而非"股票营销类"。

#### 避免触发审核的关键词（除买/卖外）

| 敏感词 | 安全替代 |
|--------|----------|
| 信号 | 标注/提示/观察点 |
| 选股 | 筛选/过滤 |
| 赚钱/盈利 | （不说） |
| 稳赚/必涨 | （绝对不说） |
| 跟单/带单 | （绝对不说） |
| 公式 | 规则/条件（"公式"在抖音不算敏感，但"选股公式"组合较敏感） |
| AI推荐 | AI标注/AI可视化 |

## 三、新增线上渠道（已有方案未覆盖）

### 3.1 同花顺指标广场（零成本，极高精准度）⭐⭐⭐⭐⭐

**这是最被低估的渠道。** 你在同花顺指标广场发布公式=在几千万股民面前免费打广告。

#### 操作策略

1. **发布7套公式到同花顺指标广场**
   - 每套公式的描述里写："本指标来自AI行情官" 或 "更多指标请搜索AI行情官"
   - 指标名称统一格式："AI行情官-XXX指标"（如"AI行情官-均线趋势"）
   - 截图展示效果，让人一眼看出差异化

2. **指标下载页藏钩子**
   - 在公式注释里埋一句引导：`// 更多免费指标：a.ai24x.com/indicators`
   - 同花顺公式支持代码注释，注释内容用户在导入时可见

3. **效果预估**
   - 同花顺日活几千万
   - 指标广场每天大量用户搜索"选股公式""均线指标"
   - 一套好的公式可能被下载数万次
   - 这些用户100%是精准股民

#### 执行清单

| # | 行动 | 优先级 |
|---|------|--------|
| 1 | 所有公式名称加"AI行情官-"前缀 | 🔴最高 |
| 2 | 公式注释埋入a.ai24x.com | 🔴最高 |

- 股吧吧主可能删帖，不要频繁发
- 不要开多账号灌水

## 五、工具定位的合规赋能

### 5.1 核心原则：工具免责

你的防御逻辑是：**如果 AI行情官只是一个"画图的工具"，那你和 WPS、Excel 没有本质区别。WPS 不负责用户写了什么文档，Excel 不负责用户分析了什么数据。**

#### 哪些事能证明你是"工具"而非"投顾"

| 证据 | 做法 |
|------|------|
| 工具性质 | 首页明确写"数据可视化工具，不含投资建议" |
| 免责声明 | 注册时勾选确认"本工具仅为数据展示，不构成投资建议" |
| 无个股推荐 | 不做个股推荐，只展示数据 |
| 无收益承诺 | 不出现任何收益率数字 |
| 用户自主 | 强调"用户自主判断，工具仅辅助" |
| 备案/资质 | 考虑申请 ICP 备案、软著（增强合规印象） |

#### ICP 备案建议

- 你的网站 a.ai24x.com 是工具型网站
- 申请 ICP 备案：增加合规可信度
- 非经营性备案即可（不需要增值电信许可证）
- 有了 ICP 备案，微信/抖音的审核也会更宽松

---

### 5.2 软著申请（优先级中）

申请"AI行情官K线可视化系统"软件著作权：
- 费用：免费（中国版权保护中心）
- 作用：证明你是正规软件产品，而非野生荐股号
- 用途：微信小程序上架可能需要、平台申诉时提供
- 周期：约1-2个月
