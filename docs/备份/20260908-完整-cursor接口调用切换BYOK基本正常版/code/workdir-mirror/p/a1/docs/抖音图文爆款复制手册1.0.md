## 零、爆款拆解：为什么这条能爆

### 爆款基因三要素

| 要素 | 一夜持股法图文的表现 | 为什么有效 |
|------|----------------------|-----------|
| **1. 方法论清晰** | 8步，每步一个具体数值条件 | 用户看完觉得"我会了"，有获得感 |
| **2. 操作性强** | 涨幅3-5%、量比≥1、换手率5-10%、市值50-200亿 | 每步都能直接执行，不是空话 |
| **3. 信息密度高** | 8个步骤+具体数值+筛选逻辑 | 比普通"股票知识"内容实用10倍 |

### 用户心理

```
看到标题 → "这个方法我好像可以学" → 点进来
看到8步 → "哇，好清楚" → 滑到最后
看到具体数值 → "我今天就试试" → 点赞+收藏+关注
```

**核心公式：具体数字 × 操作步骤 × 即学即用 = 爆款**

## 一、爆款图文的万能结构

每条图文必须是这个结构，缺一不可：

```
图1（封面）：标题 + 一个震撼结论
图2：步骤1-2（核心筛选条件）
图3：步骤3-4（进一步过滤）
图4：步骤5-6（确认条件）
图5：步骤7-8（买卖时机）+ 免责声明
```

### 封面标题公式（从8种爆款公式中选最适合股票类的3种）

**A. 痛点唤醒型**（最适合股票类）

| 公式 | 示例 |
|------|------|
| X个信号，帮你判断___ | 3个信号，帮你判断要不要加仓 |
| ___怎么看？X步搞定 | 底部信号怎么看？5步搞定 |
| ___后怎么办？X条对策 | 涨停后回调怎么办？3条对策 |

**B. 清单体型**（信息密度最高，收藏率最高）

| 公式 | 示例 |
|------|------|
| X个___条件，筛出___ | 6个选股条件，筛出底部反转股 |
| ___的X个关键指标 | 缩量回调的5个关键指标 |
| X步选出___ | 8步选出拉升回踩二波股 |

**C. 对比反差型**（引发好奇）

| 公式 | 示例 |
|------|------|
| ___vs___，区别在X | 底1vs底2，区别在1个条件 |
| 90%的人___都错了 | 90%的人看均线都错了 |

## 三、图文制作SOP（每条15分钟）

### 步骤1：选选题（1分钟）
从50条选题库中选一条，或套用标题公式自创。

### 步骤2：写内容大纲（3分钟）
按照万能结构填写：
```
图1：封面 — 标题 + 核心结论
图2：步骤1-2
图3：步骤3-4
图4：步骤5-6
图5：步骤7-8 + 免责
```

### 步骤3：制作图片（10分钟）

**工具**：Canva / 美图秀秀 / PowerPoint / 手机自带拼图

**图片规格**：
- 尺寸：1080×1440（3:4竖版，抖音图文最佳比例）
- 字号：标题40px+，正文24px+
- 背景：深色底+浅色字（专业感+护眼）
- 品牌：每张图右下角半透明"AI行情官"水印

**配色方案**（统一，建立品牌识别）：
- 背景：深蓝 #0A1628
- 标题：白色 #FFFFFF
- 重点：红色 #FF4D4F 或 金色 #FFB800
- 正文：浅灰 #E8E8E8
- 次要：蓝色 #4DA6FF

**每张图的固定元素**：
- 顶部：步骤编号（第1步/第2步…）
- 中部：核心内容（文字+图表）
- 底部：半透明水印"AI行情官"
- 图5底部：⚠️ 以上内容仅为技术分析方法交流，不构成投资建议

### 步骤4：发布（1分钟）

**发布时间**：
- 工作日：11:30-12:30（午休）或 19:00-21:00（晚间）
- 周末：10:00-12:00

**话题标签**（每次选5-8个）：
```
#股票 #股票知识 #干货分享 #技术分析 
#一夜持股法 #选股 #均线 #底部信号
```

**文案**：
```
{标题}

{1句话概括核心价值}

⚠️ 以上内容仅为技术分析方法交流，不构成投资建议。
```

## 四、一夜持股法图文 → 爆款复制清单

这条爆款的每个元素都要在后续内容中复用：

| 爆款元素 | 复制方式 |
|----------|----------|
| "8步"清单体 | 每条都是"X步/Y个条件"清单体 |
| 每步有具体数值 | 每个条件必须有数字（不是"放量"而是"量≥1.2倍均量"） |
| 信息密度高 | 一张图=1-2个知识点，不注水 |
| 深色背景+大字 | 统一配色方案 |
| 方法论类图文（非视频） | 图文成本低、制作快、不露脸、不怕直播风控 |
| 股票干货标签 | 固定#股票 #干货分享 #技术分析 |
| 不推荐个股 | 只讲方法，不提具体股票代码 |
| 免责声明 | 每条末尾都有 |

## 七、关键红线（抖音防封）

### 绝对不出现

| ❌ 禁止 | 替代 |
|----------|------|
| 买入/卖出/推荐 | 观察/关注/留意 |
| 稳赚/X%收益 | 历史统计/信号回测 |
| 荐股/带单 | 方法分享/技术交流 |
| 截图晒实盘收益 | 展示信号状态+免责 |
| "跟我买" | "辅助判断" |
| 具体股票代码+买卖建议 | 只讲方法不提个股 |

### 每条必加

- ✅ 图5末尾：⚠️ 以上内容仅为技术分析方法交流，不构成投资建议
- ✅ 话题标签不包含：#荐股 #买卖点 #跟单
- ✅ 标题不含：买/卖/推荐/赚/翻倍

---

*核心理念：你生产的是"方法"，不是"建议"。方法可以分享，建议不能给。这个边界守住，抖音就不会封你。*
