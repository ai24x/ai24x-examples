## 在同花顺中导入（通用步骤）

不同客户端版本菜单名称可能略有差异，以软件内帮助为准：

1. 打开 **公式管理** / **自定义公式**（或「工具 → 公式管理」类入口）。
2. 新建 **技术指标公式**（主图或副图按你习惯；本指标含均线与 `DRAWTEXT/DRAWICON`，多作为主图叠加使用）。
3. 将 `formula.txt` 中内容 **完整粘贴** 到编辑器。
4. **语法检查** → 通过则保存命名（例如：`雷神_LeiShen`）。
5. 在 K 线界面 **切换/叠加该指标**，确认显示正常。

若提示语法错误：同花顺对 `:=` 与 `=` 的区分、输出语句规则可能因版本而异，请按客户端提示把中间变量统一为该平台要求的赋值形式（部分环境中间量用 `:=`、输出用 `:`）。

- **雷神买点 1 或 2**：提示进场、潜伏参考。

- **结合其它指标**：低位侧重买点信号，高位侧重卖点与风险信号；偏 **中线波段** 使用思路。

## 研发备注（强烈建议阅读）

1. **`REF(JC3, -5)`**  
   多数国内行情语言的 `REF(x, n)` 在 **n 为正**时表示历史；**n 为负**时在不同软件中可能表示 **向前引用（未来数据）** 或 **非法**。请务必在同花顺帮助中确认 **负数 REF 的语义**。若实为「未来 K 线」参与计算，则图表上可能异常「精准」，但 **实盘与严格回测不可用同一逻辑**，否则存在 **前视偏差**。

2. **`TS2` 两次赋值**  
   源码中对 `TS2`、`TS2_ONCE` 各有一次更新，属于「先算再过滤」的写法；若某版本编译器不允许重复赋值，需改为不同变量名再合并条件。

3. **均线体系**  
   同时存在 14/28/57 与 5/10/20 两套周期，信号可能密集；是否适合你的品种与周期（日线/60 分钟等）需自行验证。

4. **合规与产品化**
