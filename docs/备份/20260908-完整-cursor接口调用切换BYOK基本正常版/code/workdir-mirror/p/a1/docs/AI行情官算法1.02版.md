## 三、趋势过滤（Regime Filter）

### 斜率计算
```python
slope_28_6 = (ma28[now] - ma28[now-6]) / abs(ma28[now-6])
slope_57_6 = (ma57[now] - ma57[now-6]) / abs(ma57[now-6])
```

### 判断阈值
```
两者斜率 > +0.15%  → 上升趋势 (regime=1)
两者斜率 < −0.15%  → 下降趋势 (regime=-1)
否则              → 震荡 (regime=0)
```

### 特殊豁免
- 深度超卖（closePos ≤ 0.25）+ 底2信号 → 允许底部买入
- Q1双下区域 + 底1信号 → 允许抄底
- 34日高点RSI背离 → 允许顶部卖出

## 六、MACD 系统

```python
# 参数
EMA12 = EMA(close, 12)
EMA26 = EMA(close, 26)
DIF = EMA12 - EMA26
DEA = EMA(DIF, 9)
MACD_BAR = (DIF - DEA) * 2

# 金叉/死叉
golden_cross = DIF[prev] <= DEA[prev] AND DIF[now] > DEA[now]
dead_cross   = DIF[prev] >= DEA[prev] AND DIF[now] < DEA[now]

# MACD方向状态（滞后1日）
if golden_cross: macd_dir = 1
if dead_cross:   macd_dir = -1

# MACD增强：金叉时B信号改亮红，死叉时卖信号改亮绿
```

## 九、信号冷却机制

### ATR自适应冷却
```python
atr14 = ATR(14)
atr_pct = atr14 / close * 100
cooldown = max(6, min(16, int(atr_pct * 3.5 + 2)))
```
高波动 → 长冷却；低波动 → 短冷却。

|------|----------|----------|

## 十、MACD二重确认

```
金叉 + B信号 → 信号加强（红色加深）
死叉 + 卖信号 → 信号加强（绿色加深）
无金叉/死叉 → 信号原色不变

底信号/小底/↗拐点 → 不受MACD影响（保持蓝色/浅蓝/青色）
```
