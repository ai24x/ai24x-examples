## AI 行情官｜灯塔版（1.01）（a.ai24x.com）定价与权益口径（MVP）

目标：先跑通“可用 + 可控 + 可运营”的最小闭环；避免对第三方免费数据源作刚性承诺。

## 1. 计次口径（必须统一）

- **扣次点**：仅在 **K 线成功返回**时扣次（`/api/kline` 成功）。
- **搜索不扣**：`/api/suggest` 不扣次。
- **失败不扣**：第三方接口失败/无数据/超时不扣次。
- **去重不扣**：同 `secid + period` 在 `dedupe_seconds`（默认 30 秒）窗口内重复请求不重复扣次（依赖 `idempotency_key`）。

## 2. 免费与 VIP（国内优先验证版）

### 免费（free）

- **周额度**：100 次 / 周
- **日上限**：20 次 / 天

### VIP 月卡（¥888，`vip_month`）

> 定价：888 元/月；权益按“额度/功能”描述，不承诺特定数据源永久可用。

- **周额度**：500 次 / 周
- **日上限**：150 次 / 天

### 体验卡（¥8.8，`vip_trial_99`）

- **限购**：**每用户账号仅允许成功购买 1 次**（以已支付订单为准），防止反复薅体验价；需要更多请走月卡/年卡。
- **有效期**：7 天（与月卡/年卡区分，便于低成本试用）。
- **额度**：默认 **100 次 / 周 + 20 次 / 天**（可环境变量调整），低于正式 VIP；折算单次成本**不低于**月卡，避免体验价比月卡更“划算”。

### VIP 年卡（¥8888，`vip_year_999`）

- **周额度 / 日上限**：与月卡一致（500 / 150）。
- **有效期**：按年（365 天）。

### 开发与联调说明（仅文档，用户端不写这些）

以下内容仅供部署与排障；**用户可见页面**（如 `account.html`「开通 VIP」）只保留：微信扫码、定价、限购、刷新配额、复制付款链接等说明。

- **支付方式**：微信主扫（业内常称 Native / code_url）。接口：`POST /api/billing/wechat/native`，返回 `code_url` 供用户扫码；**支付成功后**由微信支付异步通知服务端写订单与配额（用户侧表述为「自动生效」即可）。
- **二维码图片**：前端可用在线二维码服务根据 `code_url` 生成图片（便于静态站零依赖）；若图片失败，用户可复制 `code_url` 到微信内打开。
- **小额真实扣款（联调）**：非生产环境可在服务端开启「按标价以外金额真实扣款」（如 **0.1 元**）用于微信通道联调；**生产环境勿启用**。前端在「标价与实付不一致」时，对用户只提示「应付金额以微信收银台为准」，不出现「开发」「试扣」「联调」等字样。

可附加的“站内粘性功能”（后续逐步上）：

- 自选/收藏与分组
- 信号回放与最近信号列表
- 订阅推送（站内/企业微信等）

## 3. 邀请（裂变）建议（先稳后放量）

- 先做**一级邀请**。
- **发奖触发式**：不在绑定邀请码时直接发奖；建议在被邀请人完成**首次有效查询**后发放。
- **奖励次数（当前默认配置）**：
  - 邀请人：每激活 1 人，当日 +20 次（**当日奖励封顶 200**，防刷）、当周 +100 次（**每周奖励封顶 1000**，防刷）
  - 被邀请人：无额外赠送（注册即享免费档 100 次/周、20 次/天）
- **周封顶 / 日封顶**：对邀请奖励设置周封顶与单日封顶，防刷。

## 4. 文案边界（风控）

- 常驻免责声明：仅供学习研究演示 / 非投资建议 / 自行决策。
- 避免承诺：实时、永久稳定、全市场覆盖、收益保证等表述。
- 对外口径优先写“额度/功能/体验”，把数据源替换空间留足。

## 5. 订单与后台（对账 / 客诉）

- 管理端「VIP 订单」：筛选、导出 CSV、点击行跳转用户；与支付成功写配额对应关系见 **`VIP订单与后台管理-核心说明.md`**。
