## 一、总体策略：重新定义叙事

### 你不是炒股工具，你是"数据分析工具"

| 禁止说 | 改说 |
|--------|------|
| AI 买卖点推荐 | AI 市场信号观察 |
| 跟着买就赚 | 辅助判断市场节奏 |
| 收益率 X% | 信号触发后市场表现统计 |
| 炒股神器 | 金融信息可视化工具 |
| 荐股 | 市场结构分析 |

### 核心人设：客观、克制、专业

不是"老师"，不是"大 V"，不是"带单大神"。
是一个**用数据说话的技术观察者**。

- 每次分析必须有数据支撑
- 从不预测涨跌，只描述信号状态
- 从不推荐具体操作，只展示信号组合
- 永远附带："以上为数据分析结果，不构成投资建议"

## 二、雪球运营方案（主力战场）

### 2.1 为什么雪球是第一优先级

- 雪球是国内最大的投资者社区，用户天然有股票分析需求
- 允许发 K 线截图、技术分析内容（比微信宽容得多）
- 搜索流量大，优质帖有长尾效应
- 可以直接放链接引流（不需要像微信那样各种规避）

### 2.2 账号定位

**账号名**：AI行情官（或 "灯塔信号" / "K线信号观察"）

**简介**：
> 用数据观察市场，记录 AI 信号系统对主要指数的分析。
> 不构成投资建议，仅为技术交流。
> 工具：AI行情官 · 灯塔版

**头像**：灯塔图标（已有）

### 2.3 内容矩阵

#### A. 日常信号帖（每周 3-5 篇）— 流量基石

**格式**：
```
【{日期} 信号观察】{标的名称} {周期}

[K 线截图 + 信号标注]

今日信号：
● 日线：{信号类型}（偏强/偏弱/关注/无信号）
● 周线：{信号类型}
● 关键均线：MA14 @{值} | MA28 @{值} | MA57 @{值}

一句话：{简洁的信号状态描述}

#K线信号 #技术分析 #市场观察
```

**选题轮换**：
- 周一：上证指数周线观察
- 周二：热门板块信号扫描（AI/新能源/半导体轮换）
- 周三：北证50 信号观察（差异化内容）
- 周四：创业板信号 + 市场情绪
- 周五：本周信号回顾 + 下周关注

**示例**：
```
【5月12日 信号观察】上证指数 日线

[截图：上证指数日K+信号标注]

今日信号：
● 日线：小底（提前关注区）+ MA28 支撑
● 周线：B（偏强，连续第3周）
● 关键均线：MA14 3320 | MA28 3280 | MA57 3150

一句话：日线进入关注区域但周线仍偏强，短期震荡概率较大。

#A股 #上证指数 #技术分析
```

#### B. 深度方法帖（每周 1 篇）— 人设建立

教用户**怎么看**，不是告诉用户**怎么买**。

**选题库**：
1. "如何用均线组合判断市场结构"（MA14/28/57 用法详解）
2. "K 线底部信号：小底和底的区别在哪里？"
3. "为什么北证50 最近值得关注？用数据说话"
4. "信号系统的误判与正确率：一个诚实的数据分析"
5. "不同周期信号的协同效应：日线+周线+月线怎么看"
6. "均线粘合与发散：市场选择方向的信号"

**格式**：
- 1500-3000 字
- 3-5 张截图配说明
- 结尾引导："以上分析使用了 AI行情官 工具，可在评论区获取体验链接"

#### C. 互动帖（每周 1-2 篇）— 社区活跃度

- 投票："今天你更关注哪个板块？A. AI 概念 B. 新能源 C. 医药 D. 消费"
- 提问："你认为当前市场处于什么阶段？底部 / 反弹 / 震荡 / 顶部"
- 复盘："上周我观察的 X 信号，市场后来怎么走了？"

### 2.4 发布节奏（首月）

| 周一 | 周二 | 周三 | 周四 | 周五 | 周六 | 周日 |
|------|------|------|------|------|------|------|
| 上证周线观察 | 热门板块扫描 | 深度方法帖 | 创业板观察 | 周回顾+投票 | 休息/互动 | 休息 |

### 2.5 引流路径

```
雪球帖子
  ├── 文末引导："更多信号分析见评论区置顶"
  ├── 评论区置顶：放体验链接（a.ai24x.com/demo.html?i=你的邀请码）
  ├── 私信自动回复：关注后自动发送体验链接 + 使用说明
  └── 签名档：简短的"AI行情官"介绍
```

**关键**：不在正文直接放链接（容易被判广告），放评论区置顶更安全。

### 2.6 增长飞轮

```
发帖 → 雪球搜索流量 → 关注者增长
  → 每周 2-3 篇干货 → 转发 → 更多曝光

      → VIP 转化 → 收入
```

## 三、知乎运营方案（长尾获客）

### 3.1 知乎的定位

知乎的流量特点是**搜索长尾**。一篇好回答可以持续带来流量 6-12 个月。

### 3.2 账号定位

**遵循"不装懂、不装神、用数据说话"原则。**

**简介**：
> 用数据工具观察市场的技术人。不预测股价，只描述信号。
> 所有分析仅供参考，不构成投资建议。

### 3.3 回答策略（主力）

**目标问题类型**：
1. "怎么入门股票技术分析？"
2. "有哪些好用的股票分析工具？"
3. "K 线图怎么看？"
4. "均线系统怎么设置？"
5. "北证50 值得关注吗？"
6. "如何判断股票的底部信号？"

**回答模板**：
```
[简短结论，1 句话]

[方法/工具介绍，300-500 字]

[配图：K 线截图 + 信号标注]

[实操建议，200 字]
- 怎么看均线排列
- 怎么识别信号组合
- 怎么避免误判

[总结 + 工具推荐，50 字]
"以上分析使用了 AI行情官 的灯塔信号系统，
感兴趣可以去体验一下（免费额度）"
```

### 3.4 专栏文章（辅助）

每 2 周 1 篇深度文章，同步发雪球和知乎：
- 知乎专栏用于搜索 SEO
- 雪球帖子用于社区互动

### 3.5 知乎引流技巧

- **不能直接放链接**：知乎对外链很敏感，容易被折叠
- **替代方案**：在个人简介放"AI行情官"，让用户自己搜索
- **私信引导**：在回答结尾说"需要工具链接可以私信我"
- **关键词埋设**：每篇回答自然提到"AI行情官" 1-2 次

## 四、合规红线（必须遵守）

### 绝对不能做的

- ❌ 承诺收益："用这个方法稳赚 X%"
- ❌ 推荐买入/卖出："现在可以抄底了"
- ❌ 晒实盘："我昨天买了 X，今天赚了 Y"
- ❌ 预测股价："下周必涨到 X 元"
- ❌ 带单/喊单："跟着我一起买"
- ❌ 虚假宣传："准确率 100%"
- ❌ 贬低他人："XX 大 V 的分析全错了"

### 可以做的

- ✅ 展示信号状态："日线出现 B（偏强）信号"
- ✅ 回顾历史："上次出现此信号后，市场表现如下（统计数据）"
- ✅ 分享方法："我如何用均线排列判断趋势"
- ✅ 技术教学："底 1/底 2 信号的区别"
- ✅ 工具推荐："AI行情官提供了这些分析功能"

### 每篇内容必备要素

**底部强制声明**：
> ⚠️ 免责声明：本文为技术分析方法交流，所有内容仅供学习参考，不构成任何投资建议。市场有风险，投资需谨慎。

## 五、素材库建设

### 截图规范
- 使用深色主题截图（视觉效果更好）
- 截图包含：K 线 + 信号标注 + 信号图例
- 统一分辨率：1200x800
- 可加水印："AI行情官 · 灯塔版"（半透明，右下角）

### 标题库（可直接使用）
1. "今日信号：上证指数日线出现关注信号"
2. "用数据看北证50：信号系统的客观记录"
3. "K 线底部信号真伪辨别：两个关键验证方法"
4. "信号系统的诚实自评：最近 30 天信号触发后市场表现统计"
5. "均线系统实战：MA14/28/57 组合的三种经典形态"

### 评论回复模板
- "请问这个信号怎么用？" → "信号是客观参考，不是买卖指令。建议结合你自己的交易系统和风险偏好来判断。"

- "收费吗？" → "基础功能免费，每天有免费额度。深度功能是付费的，支持开发者的持续优化。"

## 七、扩展建议

当基础内容运营稳定后（约 2-3 个月），可以考虑：

1. **B 站视频**：K 线入门教程系列（10 分钟/集，5 集），B 站财经区对技术分析内容较友好
2. **小红书**：以"学习笔记"人设发 K 线学习记录，吸引年轻投资新手
3. **社群运营**：建立免费交流群（QQ/Telegram），每日推送信号摘要，群内答疑
4. **KOL 合作**：邀请雪球中小 V 试用工具并分享使用体验（提供 1 个月 VIP）
5. **自动发帖工具**：开发信号截图自动生成 + 一键发布到雪球的功能（提升效率）
