3. 点「开始扫描」→ 全市场北证 344 只 → 市值/成交额粗筛 → 逐只拉K线做形态体检 → 前 12 名调 AI行情官 快照复核 → 输出 3~5 只；扫描完成自动保存为「今日结果」
4. 结果可「存入历史」（本机 localStorage，同日自动覆盖、保留最近 30 天）、「复制简报」（Markdown 文本）

## 内置选股标准（核心）
- **刚底部走多上拐**：站上 MA20 且 MA20 上翘、MA5>MA10、MACD 红柱
- **底部放量异动启动（核心新增）**：近 15 日内有"涨幅≥4% 且 量≥1.8×20日均量 且 异动当日位置≤50%"的放量异动，且发生在近 N 日内、当前重新站回 MA5——量化"刚底部异动起来"
- **异动拉升一小波后回踩企稳**：异动后缩量回踩不破、重新站回均线
- **一路小阳**：近 5 日 ≥3 根阳线、单日最大涨幅 ≤8%、5 日涨幅温和
- **未大幅拉升 + 刚启动约束**：5日≤20%、10日≤30%、20日≤30%、60日≤45%（均可调）
- **主线板块共振（新增）**：自动拉取行业/概念板块榜（5日涨幅≥4% 取前 12 名），个股所属行业命中则打"主线"标签并加分；可选"必须命中"（热门板块/题材关键词/强势资金三选一）
- **资金与活跃度**：主力净流入>0 加分；换手率须在 2%~20% 区间（硬过滤，防过热/冷门）
- **其它综合条件**：位置 ≤30%、总市值 5~40 亿、成交额 ≥3000 万、非 ST、零风险标签优先（AI 复核后，有风险标签者降为"次选"）
