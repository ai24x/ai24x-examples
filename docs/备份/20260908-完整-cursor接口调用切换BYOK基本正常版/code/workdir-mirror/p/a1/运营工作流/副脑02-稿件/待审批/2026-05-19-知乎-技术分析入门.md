> 问题：怎么入门股票技术分析？

---

**答：从均线系统入手是最快的入门路径，3步就能建立自己的分析框架。**

---

刚开始学技术分析容易迷失在几十种指标里——MACD、KDJ、RSI、布林带...其实没必要。

我的建议是：**先只学均线（MA），把这一套用熟了再扩展。**

### 第一步：认识3条关键均线

技术分析里均线参数没有标准答案，但我长期用的三线组合效果不错：

- **MA14**（约3周）：短期趋势线，判断短期方向
- **MA28**（约1.5个月）：中期支撑/压力线
- **MA57**（约3个月）：中长期牛熊分界线

这三条线的排列方式就能告诉你很多东西：
- MA14 > MA28 > MA57 → **多头排列**，市场偏强
- MA57 > MA28 > MA14 → **空头排列**，市场偏弱
- 三条线缠绕在一起 → 市场在**震荡选择方向**

### 第二步：学习2个基础信号

基于上面3条均线，我最常看的两个信号：

**1. 底部信号**
MA14拐头向上穿越MA28，价格站稳MA14上方——关注区域。

**2. 顶部信号**
MA14拐头向下穿越MA28，价格跌破MA14——预警区域。

就这么简单。不要追求复杂的信号组合，先用最简单的。

### 第三步：固定分析流程

每天花3分钟：

1. 打开K线图，看3条均线的排列状态
2. 判断当前是偏强、偏弱还是震荡
3. 只看信号，不做预测

**最重要的一点：技术分析是工具，不是水晶球。** 它告诉你现在的市场状态，不告诉你明天涨多少。
