3. **大盘风险**：上证"底+金"为日线级别信号，跌破 MA20（约 3900 一线）则整体逻辑终止；

5. 市值/评分数据来自公开接口，可能滞后或有口径差异；AI行情官 评分为技术统计，不代表未来走势；
