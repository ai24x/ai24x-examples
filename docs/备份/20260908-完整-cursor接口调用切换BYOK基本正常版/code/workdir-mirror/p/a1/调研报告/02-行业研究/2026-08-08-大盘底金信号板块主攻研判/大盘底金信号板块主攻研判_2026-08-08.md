## 五、锁定 2 大板块（双确认后）

### 5.1 PCB（印制电路板）—— 资金主攻第 1 + 技术最强，主升确认

**为什么是它（逻辑）**：
- 事件催化延续：DeepSeek API 涨价 → AI 算力资本开支上行 → 服务器/交换机对高多层板、HDI、载板需求提升，**AI 硬件制造链最直接受益**；
- 资金主攻：行业 5 日主力净流入电子 **+627.7 亿（全市场第1）**、印制电路板 **+304.5 亿**、PCB 概念今日 **+247.0 亿（第1，较 08-06 放大近 4 倍）**——持续性最好的方向；
- 业绩确认："2026中报预增"概念 5 日净流入 +596.7 亿（第2），PCB 龙头普遍有业绩兑现能力。

**为什么是它（数据确认）**：
- 板块评分均值 **70.0**（7 大板块第 2），6/6 成分股全部站上 MA20、均线金叉、MACD 翻红 2~3 天；
- 龙头梯队：鹏鼎控股 77.4 / 沪电股份 77.0 / 胜宏科技 75.6 / 深南电路 69.8 / 生益科技 64.4——**梯队齐整、量价配合**；
- 但注意：位置已从 08-06 的 32~38% 抬升至 45~53%，多数个股带"5日涨幅过大"（胜宏 +12%、生益/景旺涨停）——**已进入主升加速段，不是低吸点**。

**操作参考**：
- **不追高**，等龙头回踩 MA5/MA10（深南/沪电/鹏鼎）缩量企稳再低吸；
- 已持有者沿 5 日线持有，跌破 MA10 减半、破 MA20 清仓；
- 优先"MACD 翻红 + 站上 MA20 + 位置仍低"的补涨品种（如生益科技、景旺电子回踩后），回避 5 日涨幅过大的追高。

### 5.2 创新药/CXO —— 当日爆发新主线（资金+涨幅+评分三高）

**为什么是它（逻辑）**：
- 当日主攻实证：医疗服务行业 +8.34%（同花顺行业第1）、医疗研发外包 +13.03%、CRO 概念 +10.84%（概念涨幅第1）、创新药概念 +5.43%；

- 产业逻辑：创新药出海授权（BD）交易活跃 + CXO 订单回暖 + 减肥药（GLP-1）赛道景气，业绩确定性与题材共振。

**为什么是它（数据确认）**：
- 板块评分均值 **73.8（7 大板块最高）**：药明康德 87.2 / 泰格医药 85.0 / 博腾股份 81.0 / 康龙化成 73.8 / 贝达药业 69.4；
- 多数个股 MACD 刚翻红第 1~4 天、站上 MA20、均线金叉、量价配合——**典型的底部右侧首日启动结构**；

**操作参考**：
- **当日爆发后不追高**，等 1~2 日回踩缩量企稳（博腾 +20% 涨停、康龙 +14%，次日分歧概率高）；
