## Phase 1：好玩（本周）

### 1.1 遛鱼手感优化
- 震动反馈（navigator.vibrate）按鱼大小分级
- 鱼挣扎方向可视化（左右箭头）
- 抄网窗口倒计时条
- 传说鱼专属闪光特效

### 1.2 每日任务系统
- 3 个日常任务随机刷新
- 任务类型：钓 N 条鱼、卖鱼获、去某钓场、钓特定鱼种
- 奖励：金币/道具/积分
- 连续 7 天额外奖励

### 1.3 天气联动钓鱼
- 雨天：鲫鱼/鲤鱼活跃+30%
- 风暴：大鱼概率×2，耐久消耗×2
- 雪天：传说鱼概率微升
- 天气预报面板（未来 3 次变化）

### 1.4 鱼竿预览面板
- 设置面板内展示各级鱼竿外观缩略图
- 显示当前级→下一级的属性变化

---

## Phase 2：社交（2-4 周）

### 2.1 好友系统
- 微信好友关系链（小程序端）
- 互访钓场、赠鱼饵
- 组队钓鱼（稀有率+20%）

### 2.2 鱼市交易
- P2P 挂单/求购
- 鱼价走势图
- 拍卖行（每周传说鱼拍卖）
- 手续费 5%（平台收入）

### 2.3 私人资产
- 私有钓场购买
- 码头/游艇建设
- 豪宅展示稀有鱼获

---

## Phase 3：裂变+AI（4-8 周）

### 3.1 分享裂变
- Canvas 渲染精美分享海报
- 朋友圈/群聊一键分享
- 钓鱼短视频自动生成
- 全服排行榜

### 3.2 AI 深度整合
- AI 钓鱼教练
- LLM 驱动 NPC（有记忆）
- 鱼情预测模型
- 自动生成剧情任务

### 3.3 真实经营
- 赛事系统（周赛/月赛）
- 渔场经营（雇佣 AI 渔工）
- 赞助商冠名
