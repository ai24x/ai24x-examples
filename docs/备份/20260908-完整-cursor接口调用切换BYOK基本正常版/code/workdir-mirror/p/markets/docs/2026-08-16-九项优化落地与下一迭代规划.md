## 二、第 7 项：电脑/手机是否拆成 m/ 单独目录 —— 结论：暂不拆

国际版当前一套响应式方案已覆盖 375px~1280px：

- `isMobileView()` 媒体断点自适应：手机首屏 68 根/主图 380px 高，桌面 142 根/460px 高；
- lightweight-charts `autoSize` + resize 同步，旋转/窗口变化自动重算可见范围；
- 桌面与手机的差异仅剩「图表尺寸/根数」，尚未出现功能级差异。

拆分 `m/` 需要双份页面、双份维护与双份缓存版本号，收益低、风险高。建议：**等出现桌面/手机功能分叉（如手机端改竖屏双栏、桌面端加多图联动）再拆**，届时参考国内版 `p/a1/web/m/quote.html` 结构。
