## 三、MVP 做什么（范围）

1. **英文 UI 五页**：Landing（产品说明+定价）→ 注册/登录（核心层邮箱）→ 主应用（搜美股代码 → K线/指标 → AI 点评）→ 账户/订阅。
2. **行情与指标（免费，公开）**：
   - 数据源：腾讯美股主源（15 分钟延迟、免费）+ 东财/新浪日K兜底（详见 §五矩阵；Yahoo 实测云机房 IP 全线 429，降为后置）
   - 覆盖：美股个股 + ETF（SPY/QQQ/DIA…）+ 指数（^GSPC/^IXIC/^DJI/^VIX）
   - 图表：日/周/月 K线 + MA5/10/20/60 + MACD + RSI + 量能（复用行情官信号引擎与 lightweight-charts 渲染）
3. **AI 点评（Pro 主力功能）**：
   - 输入：K线统计/均线/MACD/RSI/位置/量能 → 输出「技术体检报告」式描述，非买卖结论
   - 每日每标的缓存（省 token、稳定）；免费档每日 3 次
4. **自选 watchlist**：免费 3 个，Pro 50 个。
5. **订阅**：PayPal（核心层 `api\pay_paypal.py` 已有 Live 能力）；MVP 用「一次性买月/年卡，custom_id 标记时长，服务端到期校验」最简实现，PayPal 订阅 API 后置。
6. **合规硬件**：全站免责 + AI 输出黑名单过滤 + 仅英文 + 不接中国支付 + ToS/Privacy 声明面向海外。

## 四、MVP 不做什么（排除项）

- ❌ 不接实时行情（$1-4/用户/月 授权费后置）
- ❌ 不做交易执行 / 券商连接 / 下单
- ❌ 不收集用户持仓 / 风险偏好做定制输出（个性化 = 投顾红线）
- ❌ 公开面不用 trade / signal / advisor / tips / picks / broker 等词
- ❌ 不做按量充值 / Token 额度售卖
- ❌ 不做国内获客 / 中文页面 / 国内支付
- ❌ 不做开发者 API 订阅（中层，后置）
- ❌ 不引入 Polygon / Alpha Vantage 等付费数据（备源仅留接口，不进 MVP 预算）

### 数据源兜底矩阵（2026-08-15 实测）

|---|---|---|---|---|
| 主源 | 腾讯美股 | `web.ifzq.gtimg.cn/appstock/app/usfqkline/get?param=usAAPL,...` + `qt.gtimg.cn/q=usAAPL` | ✅ 本机+新加坡双测可用 | 与行情官腾讯解析格式 100% 兼容（`candles_from_tencent_like_pack` 直接复用）；含 15 分钟延迟标注；免费接口商用 ToS 灰色，靠低调用量+缓存+署名控制，正式商用前需授权 |

> ⚠️ 腾讯美股 K线后缀坑（Phase 1 实测定位）：`usAAPL` 只回 2 根（2011 + 最新日），**必须带市场限定后缀**才回全量——个股 `usAAPL.OQ`、纽交所/Arca ETF `usSPY.AM`、多代码股 `usBRK.A.N`、指数 `usINX/usIXIC/usDJI` 不带后缀。实现：非指数标的先从 `qt.gtimg.cn` 快照取 field[2]（market_code，如 `AAPL.OQ`），拼 `us`+market_code；快照失败再按 `.OQ → .AM → .N` 候选逐个试（已落地 providers_us.py `fetch_tencent_kline`）。
| 兜底1 | 东财美股 | `push2his` secid=105/106/107.AAPL + `push2` 快照 | ✅ 本机+新加坡双测可用 | 数据最全（1 万+ 根）；走既有 push2his 节流纪律（keep-alive/慢重试/熔断）；名称字段为中文需忽略 |
| 兜底2 | 新浪美股（仅日K） | `US_MinKService.getDailyK`（全历史日K） | ✅ 日K双测可用；❌ 快照海外 403 | 快照 `hq.sinajs.cn` 对海外 IP 403，只做 K线兜底 |
| 后置 | Yahoo Finance | chart API（K线+现价） | ❌ 云机房 IP 全线 429（本机 403） | 实测 04 新加坡节点 chart/主页/crumb 全 429，直连不能做生产主源；需要 Yahoo 叙事就走付费授权经销商（Polygon/Intrinio）后置 |
| 冷启动/交叉 | Alpha Vantage / Finnhub 免费 key | EOD 日线 | 待注册 | 免费额度小，适合预热缓存，不适合生产主源 |
| 后期付费主力（可选） | TuShare 美股 | `us_daily`（日线全历史，自动复权行情）+ `us_adjfactor`/`us_basic` | ❌ 当前不可用（未配置 token / 积分门槛） | 美股日线**单独 2000 元**购买项（每分钟 500 次、每次 8000 行）；全球指数 `index_global` 另需 6000 积分；需新增 `us_daily` 适配器（现有 `_secid_to_tushare_ts_code` 只认 6 位 A股代码，AAPL 返回 None）；建议收入起来后再评估 |
| ❌ 排除 | 同花顺 | fuyao 仅 A股端点；公开美股接口 404 | 实测失败 | 美股需 iFinD 付费账号，成本高，不进 MVP |
| ❌ 排除 | Stooq | CSV | 实测被 JS 挑战拦截 | 不可靠 |

04 节点复核（2026-08-15 实跑）：腾讯 K线+快照 ✅ / 东财 K线+快照 ✅ / 新浪日K ✅（快照 `hq.sinajs.cn` 海外 403）/ Yahoo chart+主页+crumb 全 429。

降级规则：**腾讯 → 东财 → 新浪日K → 最近缓存兜底**（页面标注数据延迟/缓存来源）；每源独立 _RateGate + 日缓存 + 熔断（沿用行情官纪律）；所有源统一转成 signals.Candle rows，信号引擎零改动。

## 七、合规红线嵌入点（写进代码/文案）

| 红线 | 落地 |
|---|---|
| 不做个性化 | 不采集持仓/风险偏好；AI 输入仅代码+公开行情 |
| 不喊单 | prompt 硬约束 + 输出黑名单 + 人工抽检 |

| 数据署名/不转售 | 页面标注 15-min delayed + 数据源署名；无数据导出 / 无行情 API 转售（腾讯免费接口商用前需授权，见矩阵备注） |
| 面向海外 | 仅英文、仅 PayPal、ToS 声明、不主动招揽国内 |
| 教育定位 | 全站免责 + AI 输出附「for educational purposes, not investment advice」 |
