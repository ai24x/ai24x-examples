## 骨架

- `api\server\` 产品后端（独立端口 18012）
- `web\` 产品前端（英文，独立子域）
- `docs\` 产品文档（MVP 清单 / 合规边界）
- `收发\` 与副脑通信信箱（沿用平台惯例）
- `scripts\` 数据源探测 / 运维脚本

## 硬规则（沿用平台）

1. 共享不复制：账户 / 支付 / 模型引擎在核心层 `api\`，本产品只调用，不各自接上游
2. 合规红线：不接交易执行、不个性化、不喊单、仅英文、仅 PayPal、不接国内支付
3. 数据源主链：腾讯 → 东财 → 新浪日K → 最近缓存（详见 MVP 清单矩阵）
4. 公开面禁用词：trade / trading / signal / advisor / tips / picks / broker
