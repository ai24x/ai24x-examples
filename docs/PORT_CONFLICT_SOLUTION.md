# 🔧 端口冲突解决方案

## 📅 问题发现时间
2026-03-19 22:39:06

## 🔍 问题描述
启动网站服务时，与OpenClaw网关发生端口冲突，导致网关卡死。

## 📊 当前端口占用情况
### 关键端口
- **端口 18789**: OpenClaw网关端口
- **端口 3000**: 原网站服务端口 (冲突源)

### 可用端口
3001, 3002, 3003, 3004, 3005

## 🎯 解决方案
### 方案1: 修改网站服务端口 ✅ **推荐**
将网站服务端口从 **3000** 改为 **3001**

**优点:**
- 无需修改OpenClaw网关配置
- 快速解决冲突
- 风险最低

**实施步骤:**
1. 使用新的服务器文件: server-no-conflict.js
2. 启动命令: 
ode server-no-conflict.js
3. 访问地址: http://localhost:3001/

### 方案2: 修改OpenClaw网关端口
将OpenClaw网关端口从 **18789** 改为其他端口

**缺点:**
- 需要修改网关配置
- 可能影响其他服务
- 需要重启网关

### 方案3: 使用反向代理
使用Nginx等反向代理统一管理端口

**优点:**
- 专业解决方案
- 支持多服务
- 负载均衡

**缺点:**
- 配置复杂
- 需要额外软件
