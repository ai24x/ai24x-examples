## 一、一句话核心（唯一主叙事）

**重点只做一件事：解决国外开发者的跨境调用痛点，满足其对中国模型「极致性价比」的调用需求。**

| 半句 | 含义 |
|------|------|
| **国外开发者痛点** | 直连中国 upstream 麻烦（账号、付款、发票、多 Key、不稳定）；要美元付、一个 Key、文档能接进自己的工具 |
| **中国模型极致性价比** | 主推矩阵见 **§3.1.1**（DeepSeek / Qwen / Kimi / 小米 MiMo / MiniMax / 智谱 GLM…）；卖平台 credit + 档位/VIP 点名；**靠路由与履约换省事，不靠自杀价装便宜** |

**不是主叙事**：全球最全模型目录、对标 OpenAI 旗舰齐全度、国内行情官获客。

引流漏斗（国际 Token）：

```
痛点内容 / 性价比对比 / 接入案例
  → 英文落地（China models · value · PayPal）
  → 注册试用 → flash/pro 验证「够用且便宜」
  → 付费加码 / VIP 点名心仪中国模
  → Integrations 扩大日常调用场景
```

## 二、我们卖什么 / 不卖什么（推广红线）

### 对外主卖点（英文优先 · 句句扣痛点/性价比）

| 卖点 | 用户一句话 | 对应 |
|------|------------|------|
| Extreme value China LLMs | 同样能力档，中国模调用更省 | 极致性价比 |
| One key · PayPal USD | 境外好付、少注册五家 | 痛点 |
| flash / pro 先验证再加购 | 先便宜试通，再按需升 | 性价比路径 |
| VIP named China models | 冲着某一个国产模来的也能点名 | 痛点 |
| Drop into OpenClaw / SDK | 接进现有工作流，不另学一套 | 痛点 |
| SG gateway | 国际入口（延迟诚实表述） | 信任 |

### 禁止话术（各副脑一律不发）

- 「全球最全模型」「比 OpenAI 更强/更全」
- 「官方代理 / 白标 DeepSeek·OpenAI」
- 「国内便宜突破限制用 GPT」（灰产）
- 「与本地同延迟」无依据承诺
- 用户端暴露：硅基 / OR / SMTP / 副脑 / 联调 等运维词
- 国际帖里硬推「AI 行情官 / 同花顺」（产品线混淆）

## 三、SEO 核心（关键词与内容）

### 3.1 关键词簇（国际 · 英文为主）

| 簇 | 示例意图 | 落地 |
|----|----------|------|
| **A. 性价比 + 名模品牌**（主攻） | 见下方 **名模词表**；模板：`{Model} API` / `cheap {Model} API` / `{Model} API pricing` / `{Model} vs GPT cost` | Pricing · 单模专题 · VIP 点名 |
| **B. 跨境痛点** | `use {Model} outside China` / `{Model} API PayPal` / `pay China AI API with PayPal` | Docs + 注册 |
| **C. 接入案例** | `OpenClaw {Model}` / `OpenAI compatible {Model}` | Integrations + GitHub |
| **D. 问题解决** | 401 / rate limit / tokens not credited | FAQ |
| **E. 品牌** | AI24X API | 全站 |

**主攻顺序：A（按名模轮换产出）→ B → C**；D 减客服；E 品牌收口。  
**不做主攻**：泛词 `best AI API`、拼目录的 `200+ models`；国内「免费 GPT」灰产词。

#### 3.1.1 中国名模关键词清单（01 必扫 · 随热度更新代数）

| 厂牌 / 系列 | 优先英文检索词（示例） | 中文/别称（社媒可混） | 内容备注 |
|-------------|------------------------|----------------------|----------|
| **DeepSeek** | DeepSeek API, DeepSeek V4, DeepSeek Flash, DeepSeek Pro, cheap DeepSeek API | 深度求索 | 默认档位叙事常客；性价比锚点 |
| **Qwen / 通义** | Qwen API, Qwen 2.5, Qwen 3, Alibaba Qwen API pricing | 通义千问 | 长尾 + EU/国际向 |
| **Kimi / Moonshot** | Kimi API, Kimi K2, Kimi K2.5, Kimi K2.6, **Kimi 3**, Moonshot API, cheap Kimi API | 月之暗面、Kimi3（用户口头） | **近期高热**；专题必做；VIP 点名优先 |
| **小米 MiMo** | Xiaomi MiMo, MiMo API, MiMo-V2, MiMo-V2-Pro, MiMo Flash, Xiaomi LLM API | 小米大模型、MiMo | **OR 流量顶流之一**；能力向/性价比文 |
| **MiniMax** | MiniMax API, MiniMax M2, MiniMax M2.5, MiniMax M2.7, cheap MiniMax API | 稀宇、MiniMax | Agent/编码向长尾；性价比对比文 |

**组词公式（每篇选 1 主模 + 1 意图）：**

- `{Kimi|MiMo|MiniMax|GLM|DeepSeek|Qwen} API pricing`
- `cheap {Model} API` / `best value {Model} API`
- `{Model} API PayPal` / `use {Model} with PayPal`
- `{Model} OpenClaw` / `{Model} OpenAI compatible`
- `{Model} vs Claude cost` / `{Model} vs GPT-4o mini`（诚实数据，勿黑稿）

**产出节奏建议（01）：** 每周至少覆盖 **1 个名模主词**（轮换：Kimi → MiMo → MiniMax → GLM → DeepSeek/Qwen），避免只写 DeepSeek。

## 四、引流渠道重点（非 SEO 一并统一）

| 渠道 | 主责 | 重点 | 禁止 |
|------|------|------|------|
| **Google SEO / 长文** | 01 | 上表 A–D 簇 | 堆砌关键词、伪原创农场 |
| **GitHub examples** | 01（主脑建仓） | README 可复制配置 | 提交密钥 |
| **X / Reddit / HN** | 01 | 晒接入案例、成本对比、问题解决；链 Pricing | 一天多号刷屏、假测评 |
| **Product Hunt 等** | 01 择机 | 产品叙事稳后再发 | 履约未稳就上热榜 |
| **国内社媒 / 社群** | 02 | **行情官**为主；Token 仅「体验/联调」口径 | 国际 Token 当国内主 KPI |
| **微信/支付宝活动** | 03 配合 02 | 行情官转化 | 不承担国际 SEO |
| **PayPal 到账体验** | 04 | 履约稳 = 口碑引流前提 | 不管内容创作 |

**口碑前提（全员知悉）**：公开大规模获客前，PayPal 履约与控制台试调必须稳；入门体验价是否抬正式国际价听主脑发令。
