## 三、git 双推纪律

```powershell
git add <本次文件...>        # 只显式 add，严禁 git add -A / git add .
git commit -m "..."
git push gitee master
git push origin master
```

- 工作树常年有大量无关脏改动（docs 删除、迁移等），**只 add 本次涉及文件**
- 代码提交和指令文档是**两个提交**（指令文档在后，HEAD 会前进）

## 四、部署脚本（指令 .ps1）写法要点

1. **必须 UTF-8 带 BOM**：脚本含中文时 04 的 PS5.1 直跑会按 GBK 误读导致语法错。生成方式：node 写 `'\uFEFF'+src`，或 PS 里 `[IO.File]::WriteAllText($p, $c, [Text.UTF8Encoding]::new($true))`
2. **HEAD 校验用 `git merge-base --is-ancestor $EXP HEAD`**：health 返回完整 12 位 hash，用 `-notlike "$EXP*"` 前缀校验必误报 FAIL
3. **所有 `Invoke-WebRequest/RestMethod` 必须带 `-UseBasicParsing`**（防 IE 引擎安全弹窗）
4. 脚本结构（照抄模板改 EXP 即可）：
   - git fetch + pull → 校验 HEAD 含目标 commit
   - marker 检查（`Get-Content -Raw` 断言关键代码片段存在）
   - 改生产配置（先 `Copy-Item` 备份 `.bak-时间戳`）
   - `Restart-Service AI24X-core -ErrorAction Stop`（重启对应服务）
   - 业务同步（如 Dodo 商品同步）
   - 公网验证（plans API / 页面标记 / 版本号）
   - 输出 `DONE EXP=... HEAD=...`

## 五、Dodo 商品同步（特定坑）

- 生产双因素后 **HTTP 触发 sync 会 403**，直接在 04 上：
  ```powershell
  Push-Location C:\ai24x01\api
  python -c "import asyncio, json; from pay_dodo_products import sync_dodo_products; print(json.dumps(asyncio.run(sync_dodo_products()), ensure_ascii=False))"
  ```
- override JSON（`api/data/token_plans_override.json` 等）是 **utf-8 无 BOM**（Python json.loads 拒绝 BOM），写回用 `UTF8Encoding($false)`
- 改价 = 改 override + 重启服务 + 重跑 sync（Dodo 商品 PATCH）

## 六、派发命令

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\deploy04.ps1 "docs\营销\收发\指令\<指令名>.ps1"
```

- 同步等待，超时 600s，通常 2-3 分钟完成
- 遇 `EmbeddedAttemptSessionTakeoverError`：scp 已送达不算失败，先查 04 会话尾部确认任务是否在跑，然后重试一次
- 卡住先查：`C:\Users\Administrator\.openclaw\agents\main\sessions\*.jsonl`（最新 mtime）+ `ops\<task>.out.log`，别只盯本机输出
- 路由缺失：`route add 43.160.246.30 mask 255.255.255.255 192.168.2.1 metric 1`

## 八、版本号纪律（缓存坑高发）

改共享资源（`locales.js / api.js / console.js / shell.js`）必须**全站统一升 ?v=**，禁止各页各版本；批量版本扫尾必须与内容改动**同一批提交**，否则 04 验收报「旧版本残留」。

## 九、重大项放行规则

首页/导航/定价/支付/登录/账户/视觉/多页批量改动 → 本地 QA 全绿 → 列「关键页面清单 + 预期效果」给老板 → 老板本机过目回复「放行」→ 才允许双推 + 04 更新。普通文案/单点 bug 走快速通道。
