# 【04 更新】PayPal/支付宝回跳按下单来源动态选择 · 目标 ee8daf0

> 通道：司令直连 04（deploy04.ps1 同步 600s）。验收全 PASS 后自动发指挥部群回执；有问题先回传司令，不发群。

## 背景
- 老板要求检查「套餐支付 跳转回转充值」链路。检查发现：生产 PayPal/支付宝回跳写死 `https://www.ai24x.com/console.html`，而 open.ai24x.com 用户登录态按域名 localStorage 隔离，付完款会被带到 www 控制台并踢到登录页（资金安全，体验断裂）。
- 本批修复：后端按下单请求 Origin 动态选择回跳域——open 站下单 → 付完回 `https://open.ai24x.com/console.html` 自动确认到账；www / 未知来源 → 保持配置默认不变（不影响 www 存量）。

## 本批改动（ee8daf0，只动 3 个路径）
1. `api/main.py`：`billing_alipay_wap` / `billing_paypal_order` 把请求 Origin 传给 service
2. `api/token_pay_service.py`：新增 `_origin_console_url()`；`create_alipay_wap` / `create_paypal_order` 增加 origin 参数并按来源动态覆盖 return/cancel URL
3. `scripts/check04_paypal_env.ps1`：只读查询脚本（新增，无运行影响）
- 本地已验证：`scripts/_qa_paypal_return.py` 单测 4 项全过（PayPal open 回跳 / 无来源保持 www / 支付宝 open 回跳 / helper 映射），py_compile OK。
- 纯后端 py 改动：**无前端、无版本号变化、无静态同步**。

## 注意事项
- 只动 3 个路径；04 工作树其它历史未提交文件一律不动（按预案备份+checkout 仅针对本次 2 个 py 路径）。
- 部署后需重启 `AI24X-core`（8002）生效；open 静态目录 `C:\nginx\html\ai24x` 本次不动。
- ⚠️ 不要在生产用真实 PayPal 下单做验收（live 会真扣款）；行为验收用「helper 单测 + 代码标记 + 公网 plans CORS」。

## 副脑04 执行脚本（整段复制运行）
```powershell
# === AI24X 更新部署验收 · 目标 ee8daf0 ===
$ErrorActionPreference = "Stop"
$REPO = "C:\ai24x01"
$SRV  = "AI24X-core"
$EXP  = "ee8daf06ff56"
$FILES = @(
  "api/main.py",
  "api/token_pay_service.py"
)

Set-Location $REPO

"--- 1) 2 个 py 路径如有本地改动：备份后 checkout ---"
foreach ($f in $FILES) {
    $dirty = git status --short -- $f
    if ($dirty) {
        $bn = ($f -replace "/", "_")
        Copy-Item "$REPO\$f" "C:\Users\Administrator\ops\dirty-$bn-20260817-2050" -Force
        git checkout -- $f
        if ($LASTEXITCODE -ne 0) { Write-Host "!! checkout 失败: $f" -ForegroundColor Red; exit 1 }
        "dirty backup + checkout: $f"
    } else {
        "clean: $f"
    }
}

"--- 2) 拉取并校验目标提交已包含且 2 个 py 路径与目标一致 ---"
git pull
$HEAD = (git rev-parse --short=12 HEAD).Trim()
"HEAD=$HEAD"
git merge-base --is-ancestor $EXP HEAD
if ($LASTEXITCODE -ne 0) { Write-Host "!! 目标 $EXP 不在 HEAD 历史中" -ForegroundColor Red; exit 1 }
git diff --quiet $EXP HEAD -- api/main.py api/token_pay_service.py
if ($LASTEXITCODE -ne 0) { Write-Host "!! 2 个 py 路径在 $EXP 之后仍有改动，停止" -ForegroundColor Red; exit 1 }
"target_verified=ok"

"--- 3) 代码标记校验 ---"
$m = Get-Content "$REPO\api\main.py" -Raw -Encoding UTF8
"mark_origin_paypal=$($m.Contains('origin=request.headers.get("origin")'))"
$t = Get-Content "$REPO\api\token_pay_service.py" -Raw -Encoding UTF8
"mark_helper=$($t.Contains('_origin_console_url'))"
"mark_open_return=$($t.Contains('https://open.ai24x.com/console.html'))"
if ((-not $m.Contains('origin=request.headers.get("origin")')) -or (-not $t.Contains('_origin_console_url'))) {
    Write-Host "!! 代码标记缺失" -ForegroundColor Red; exit 1
}

"--- 4) helper 行为单测（不触网）---"
$h = python -c "import sys; sys.path.insert(0,r'$REPO\api'); from token_pay_service import _origin_console_url; print(_origin_console_url('https://open.ai24x.com')); print(_origin_console_url('https://www.ai24x.com')); print(_origin_console_url(None))"
$h
$expH = "https://open.ai24x.com/console.html`nNone`nNone"
if ($h -ne $expH) { Write-Host "!! helper 行为不符" -ForegroundColor Red; exit 1 }

"--- 5) 重启 core (8002) ---"
Restart-Service $SRV -Force
$ok = $false
for ($i = 0; $i -lt 12; $i++) {
    Start-Sleep -Seconds 5
    try { $h = Invoke-RestMethod -Uri "http://127.0.0.1:8002/health" -TimeoutSec 10 -UseBasicParsing; $ok = $true; break } catch {}
}
if (-not $ok) { Write-Host "!! /health 未就绪" -ForegroundColor Red; exit 1 }
"local-health=$($h.status) commit=$($h.commit)"
if ($h.commit -notlike "$EXP*") { Write-Host "!! 服务未生效，commit=$($h.commit)" -ForegroundColor Red; exit 1 }

"--- 6) 公网验收 ---"
$pub = Invoke-RestMethod -Uri "https://api.ai24x.com/health" -TimeoutSec 20 -UseBasicParsing
"pub-health=$($pub.status) commit=$($pub.commit)"
if ($pub.commit -notlike "$EXP*") { Write-Host "!! 公网 commit 未生效" -ForegroundColor Red; exit 1 }
$plans = Invoke-WebRequest -Uri "https://api.ai24x.com/v1/billing/plans" -Headers @{ "Origin" = "https://open.ai24x.com" } -UseBasicParsing -TimeoutSec 20
"pub-plans-status=$($plans.StatusCode)"
"pub-plans-cors=$($plans.Headers['Access-Control-Allow-Origin'])"
if ($plans.StatusCode -ne 200 -or $plans.Headers['Access-Control-Allow-Origin'] -ne 'https://open.ai24x.com') {
    Write-Host "!! 公网 plans/CORS 验收失败" -ForegroundColor Red; exit 1
}

"--- 全部 PASS ---"
Write-Host "=== 部署成功 OK ===" -ForegroundColor Green
```
