  3. 非交易日同样拦截（展示最近收盘归档）。
  4. 顺手修正桌面状态栏盘中文案：stale + intraday 时显示「💡 今日未收盘：展示上一交易日（2026-08-17）结果」（原误显示「今日无合格标的」）。
- 版本号：bjscreener.js v78→v79、bjscreener.css v75→v76（gd.html 引用已同步）。
- 本地实测（375px + 1280px，真实后端）：按钮禁用、备注可见、点击 0 次 /start 调用、无 JS 报错。
