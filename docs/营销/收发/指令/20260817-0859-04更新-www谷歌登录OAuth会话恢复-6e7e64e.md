# 【04 更新】Google 登录 OAuth 会话恢复 + G/Apple 图标 · 目标 6e7e64e

> 通道：司令直连 04（deploy04.ps1 同步 600s）。验收全 PASS 后自动发指挥部群回执；有问题先回传司令，不发群。

## 背景
- 老板反馈：谷歌登录可点了，但跳转 Google 选账号点登录后「登录不成功」。
- 根因：OAuth 回调后端只在响应里种 `Domain=.ai24x.com` 的 cookie（后端本来正确），但前端登录态以 localStorage 为准；只有 login/register 页的 `handleOAuthReturn` 会把 cookie 同步到 localStorage。从 markets app 发起 Google 登录 → 回跳 console.html → console 守卫读 localStorage 为空 → 踢回 login，表现为「登录不成功」。
- 本轮改动（6e7e64e1f）：
  - **api.js 新增 OAuth 会话恢复**：`readCookie()` + `syncAuthFromCookie()`（模块加载时执行）——页面加载时若 localStorage 无 token 且 cookie 有 token，自动同步到 localStorage + 解析 auth_user cookie。任意入口（console/markets/dashboard 等）回跳都能恢复登录态。
  - **login.html / register.html**：Google/Apple 按钮加官方 SVG 图标（G 四色 18px、Apple 单色 18px），文字包进 span（防 i18n 覆盖时清掉 svg），按钮 gap:8px。
  - **markets app.html**：未登录态 social-login 的 Google/Apple 链接加 14px SVG 图标 + inline-flex 对齐。
  - 共享 api.js 内容变更：**全站 42 页 `api.js?v=20260817e → 20260818e`**，旧版残留 0（locales/shell 版本不变，仍 20260818d / 20260818c）。
  - QA：`_qa_oauth_www_20260817.js` 25 项全 PASS（含 cookie→localStorage 同步、console 回跳恢复、图标、版本）；`_qa_www_20260817.js` 回归 23/23 PASS。
- 04 生产 core(8002) 已配 Google OAuth 凭据，后端无需改动。

## 注意事项
- 本批动 www 静态 `web/`（pull 即生效 + 重启 core 8002）+ markets 静态 `p/markets/web/app.html`（需同步 `C:\sites\markets.ai24x.com\app.html` + 重启 markets 18012）；**无后端 py 改动**。
- PowerShell 断言一律单引号字面量，`?` 用 -SimpleMatch；所有 Invoke-WebRequest/-RestMethod 带 `-UseBasicParsing`。
- HEAD 校验用「目标前缀 + merge-base + 关键路径 diff --quiet 与目标一致」（指令文档自身也是新提交）。
- 公网 Google OAuth 冒烟由 04 服务器侧执行：`/v1/auth/google/login` 应 302 到 `https://accounts.google.com/...`。
- 端到端「选账号后登录成功」依赖真实 Google 账号交互，自动化冒烟只能验证到 302 + cookie 链路代码存在；若条件允许，04 用真实账号手动走一遍 Google 登录（www → 登录 → Google → 选账号 → 应回 console 且不再踢回 login）。

        if ($LASTEXITCODE -ne 0) { Write-Host "!! checkout 失败: $f" -ForegroundColor Red; exit 1 }
        "dirty backup + checkout: $f"
    } else {
        "clean: $f"
    }
}

"--- 2) 拉取并校验目标提交 ---"
git pull

"HEAD=$HEAD"
git merge-base --is-ancestor $EXP HEAD
if ($LASTEXITCODE -ne 0) { Write-Host "!! 目标 $EXP 不在 HEAD 历史中" -ForegroundColor Red; exit 1 }

if (Test-Path "$SITES\app.html") { Copy-Item "$SITES\app.html" "$SITES\app.html.bak-20260817-0859" -Force }

Restart-Service $SRV_WWW -Force
Restart-Service $SRV_MK -Force
$okW = $false; $okM = $false
for ($i = 0; $i -lt 15; $i++) {
    Start-Sleep -Seconds 5
    if (-not $okW) { try { $hw = Invoke-RestMethod -Uri "http://127.0.0.1:8002/health" -TimeoutSec 10 -UseBasicParsing; $okW = $true } catch {} }
    if (-not $okM) { try { $hm = Invoke-RestMethod -Uri "http://127.0.0.1:18012/health" -TimeoutSec 10 -UseBasicParsing; $okM = $true } catch {} }

"markets-health=$($hm.status)"

"local_login_gicon=$($lg.Contains('fill="#4285F4"'))"
"local_login_v18e=$($lg.Contains('api.js?v=20260818e'))"
if (-not ($lg.Contains('fill="#4285F4"') -and $lg.Contains('api.js?v=20260818e'))) { Write-Host "!! login 图标/版本验收失败" -ForegroundColor Red; exit 1 }

$rg = (Invoke-WebRequest -Uri "http://127.0.0.1:8002/register.html?x=l6e7e64e" -TimeoutSec 20 -UseBasicParsing).Content
"local_register_gicon=$($rg.Contains('fill="#4285F4"'))"
"local_register_v18e=$($rg.Contains('api.js?v=20260818e'))"
if (-not ($rg.Contains('fill="#4285F4"') -and $rg.Contains('api.js?v=20260818e'))) { Write-Host "!! register 图标/版本验收失败" -ForegroundColor Red; exit 1 }

$oldVer = @(Get-ChildItem "$REPO\web" -Recurse -Filter *.html | Select-String -Pattern 'api.js?v=20260817e' -SimpleMatch -List)
"local_old_ver_residual=$($oldVer.Count)"

"--- 6) 公网验收 + Google OAuth 冒烟 ---"
$pubP = (Invoke-WebRequest -Uri "https://www.ai24x.com/v1/auth/providers?x=w6e7e64e" -TimeoutSec 25 -UseBasicParsing).Content
"pub_providers=$pubP"
