# 【03 更新】复盘页数据日统一口径：未收盘展示上一交易日一律标「昨日」，今日收盘定型才标「今日」

> 03 主机：123.207.199.238 · 仓库 C:\ai24x01 · 服务 AI24X-a1-api（NSSM，8001）· 无 D 盘（备份落 C:\backup\ai24x_a\）
> a1 /health 无 commit 字段：验收用「文件标记 + 进程新建时间 + 公网内容标记」

## 背景
老板反馈「今日数据没出的，应统一叫昨日；今天收盘后更新完成的叫今日」。此前页面在盘前/盘中（展示上一交易日收盘结果）时仍大量显示「今日」标签，口径混乱。
本次纯前端修复（无后端改动），新增统一口径函数 `dataDayLabel(d)`：
- `intraday`（盘中未收盘）/ `off_market`（非交易日）/ `today_missing`（今日数据未生成）/ `stale`（今日无合格展示上一交易日）→ 一律标「昨日」
- 今日收盘更新完成（无上述标志）→ 标「今日」；归档页 → 标具体数据日期
落地范围（桌面 bjscreener.js v84→v85 + 手机 m/gd.html）：
1. 板块排行第 1 名徽章 `⭐ 今日主线` → `⭐ 昨日主线`（未定型时）；排行状态行「今日主力」→「昨日主力」；主线卡判定依据「今日主力」同步。
2. 标的区标题「今日标的 · 买什么」→「昨日标的 · 买什么」；空态「今日无合格标的」→「昨日无合格标的」；「今日仅 N 只」→「昨日仅 N 只」；放宽兜底/主线缺口提示同步。
3. 大盘卡区块标题与观察门禁：label 动态（今日/昨日大盘）、「今日观察」→「昨日观察」。
4. 状态栏「已加载今日缓存」→「已加载昨日缓存」（未定型时）。
5. 手机版顶部标题「今日 AI 筛选」→「昨日 AI 筛选」（未定型时）。
本地已实测（Playwright，23 项全 PASS + 主线唯一回归 14 项全 PASS）：实况 intraday 场景全部「昨日」标签、无「⭐ 今日主线/今日主力/今日标的」残留；mock 今日收盘场景正常显示「今日」；mock 今日无合格场景显示「昨日」；无 JS 报错。
