## SSH 命令模板（Windows 远程）
```
ssh -o ConnectTimeout=10 -o StrictHostKeyChecking=no -o BatchMode=yes Administrator@<IP> "<命令>"
```
- 注意：远程是 Windows（OpenSSH 远端 cmd/PowerShell），Linux 语法（`~`、`2>/dev/null`）会报"系统找不到指定路径"，统一用 `powershell -NoProfile -ExecutionPolicy Bypass -File <script.ps1>`
- 跨文件用 scp 传脚本再执行，避免内联引号转义问题
