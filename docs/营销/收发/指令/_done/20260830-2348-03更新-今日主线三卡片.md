## 背景
本地 `gd.html`「今日主线」已是主攻 / 观察 / 回避三张卡片。上次 03 只上了 AI雷达，**三卡片样式未提交**（`bjscreener.css` 的 `.ml-trio`），公网仍是旧版 `?v=101`。本次补上 CSS 并升到 `?v=102`。

## 执行步骤（PowerShell，整段复制运行）
```powershell
$ErrorActionPreference = "Stop"
$REPO = "C:\ai24x01"
$EXP  = "bac391db9530"

Set-Location $REPO

"--- 1) 拉码 + HEAD 校验 ---"
git pull origin master
$HEAD = (git rev-parse --short=12 HEAD).Trim()
"HEAD=$HEAD"
git merge-base --is-ancestor $EXP HEAD
if ($LASTEXITCODE -ne 0) { Write-Host "!! HEAD 不含目标提交 $EXP" -ForegroundColor Red; exit 1 }

"--- 2) 文件标记 ---"
$css = Get-Content "$REPO\p\a1\web\css\bjscreener.css" -Raw -Encoding UTF8
$html = Get-Content "$REPO\p\a1\web\gd.html" -Raw -Encoding UTF8
$okTrio = $css.Contains(".ml-trio{")
$okV = $html.Contains("bjscreener.css?v=102")
"mark_trio=$okTrio mark_v102=$okV"
if (-not ($okTrio -and $okV)) { Write-Host "!! 文件标记缺失" -ForegroundColor Red; exit 1 }

"--- 3) 公网验收（静态，无需重启 API）---"
$gd = Invoke-WebRequest -Uri "https://a.ai24x.com/gd.html" -UseBasicParsing -TimeoutSec 20
"gd_status=$($gd.StatusCode)"
if ($gd.StatusCode -ne 200) { exit 1 }
if ($gd.Content -notmatch 'bjscreener\.css\?v=102') { Write-Host "!! 公网 gd.html 仍非 v=102" -ForegroundColor Red; exit 1 }

$cssPub = Invoke-WebRequest -Uri "https://a.ai24x.com/css/bjscreener.css?v=102" -UseBasicParsing -TimeoutSec 20
"css_status=$($cssPub.StatusCode) len=$($cssPub.Content.Length)"
if ($cssPub.StatusCode -ne 200) { exit 1 }
if ($cssPub.Content -notmatch '\.ml-trio\{') { Write-Host "!! 公网 CSS 无 .ml-trio" -ForegroundColor Red; exit 1 }

"--- DONE ---"
Write-Host "✅ 03更新完成｜今日主线三卡片｜EXP=$EXP HEAD=$HEAD｜公网 gd.html v=102 + .ml-trio" -ForegroundColor Green
```
