# 压测回执：多 worker 隔离（2026-09-02 22:20）

在 04 本机对 `127.0.0.1:8002` 做 NtSuspend 压测（不烧 Token）。

| 场景 | 结果 |
|------|------|
| 基线 /health ×20 | 20/20，p50=1ms |
| 挂起 1/4 worker | **15/15** 成功，ok_p50=1ms |
| 挂起 3/4 worker | **19/20** 成功，ok_p50=1ms（1 次命中冻进程超时） |
| 挂起全部 4 worker | **0/3**，全部 2s 超时（对照成立） |
| 恢复后并发 ×30 | **30/30** |
| 收尾 | healthy，仍 4 spawn workers |

结论：多 worker 有效——部分 worker 卡死时 /health 仍可由其余 worker 秒回；全挂才会全体超时。

脚本：`scripts/stress_workers_health.ps1`
