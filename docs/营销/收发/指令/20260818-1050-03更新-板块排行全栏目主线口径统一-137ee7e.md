## 背景
老板反馈：全市场主线应一致，但「科创主线/北证主线/北证全市场/MACD首红」的板块排行都与「沪深主线」不一致（有的榜首显示成「今日主线 通信技术」，跟顶部主线卡片 AI服务器算力 打架；有的全是非主线）。
根因：① 主线对齐只对沪深/全市场生效，科创/北证未按主线（含别名，如 通信技术→通信光模块CPO）匹配；② 前端把「榜单第1名」一律渲染成「⭐ 今日主线」，未区分「复盘主线」与「本市场榜单第1」；③ MACD首红 后端不返回板块排行。
修复：
1. bj_screener.py `_sync_rank_mainlines` 升级：支持主线别名匹配（SECTOR_BOARD_ALIASES，板块名包含别名如 CPO概念→通信光模块CPO），同一主线只保留 1 个代表板块；命中主线的板块置顶（第1=king 今日主线、其余=key 重点关注），未命中保持 backup（mainline=False）。调用范围扩展到 bj/bj_all（_reattach_ths + run_scan 两处）。
2. macd_view 补 board_rank（复用 all 扫描的板块榜）。
3. 前端（bjscreener.js v80→v81 + 手机版 m/gd.html）：只有 mainline=true 才显示「主线✓ / ⭐今日主线 / 重点关注」；非主线榜首显示「市场强势」；命中别名的板块加「主线：通信光模块CPO」小标；isAll 判断加入 macd。
本地已实测（桌面+手机）：hs=AI服务器算力⭐主线；kc=通信技术⭐主线（标 主线：通信光模块CPO）；bj=半导体⭐主线；bj_all=通信设备⭐主线（标 主线：通信光模块CPO）+半导体重点关注；macd 板块榜正常显示；无 JS 报错。
