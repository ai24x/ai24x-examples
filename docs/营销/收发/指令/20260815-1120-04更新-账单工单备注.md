## 本次变更（雷总已验收本地）
1. **账单页（对照 DeepSeek transactions）**：新增 `/v1/billing/transactions` 全类型流水（充值/消耗/赠送/返利/过期）+ 每笔交易后余额 + 收支汇总卡 + 时间范围筛选 + 每日趋势图 + 模型榜 + Key 榜 + 7 列流水表（时间/类型/模型/金额/Tokens 带入出子行/余额/备注）+ 类型筛选 + 分页 + 导出 CSV。

4. **协助浮窗让位 `#support`**：`#support` 路由给控制台工单面板，浮窗只响应 `#help`。
5. **版本号**：locales/api/console/support-widget 全站统一 `v=20260815d`。
