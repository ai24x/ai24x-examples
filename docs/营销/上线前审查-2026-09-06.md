## 1. 重大漏洞 / 逻辑问题（按优先级）

### CRITICAL

| ID | 问题 | 位置 | 影响 |
|----|------|------|------|
| **S1** | BYOK 用户可控 `base_url` 无内网/元数据拦截 | `p/open/api/byok.py` ~1729–1850 | **SSRF**：打内网/本机；密钥可能被带到攻击者 URL |

### HIGH

| ID | 问题 | 位置 | 影响 |
|----|------|------|------|
| **S2** | `【DIAG】` 全量 dump 上游 body + 写盘 | `api/model_router.py` ~2918–2931 | 提示词/PII/密钥进日志与 `codex-request-body.json` |
| **S3** | SSO Cookie `httponly=False` | `api/oauth_social.py` ~162–168 | 任意子域 XSS 可偷 JWT |
| **S4** | `ADMIN_REQUIRE_SMS` 默认 `False` | `api/config.py` ~119 | 泄漏一把 Admin Key ≈ 充值/冻结/履约全开 |
| **S5** | 先校验余额 → 上游调用 → 再扣款 | `api/services.py` 等 | 并发可透支，平台付上游亏钱 |
| **S6** | 限流仅进程内 | `security_util` / `main` | 多 worker ≈ N 倍白嫖能力 |
| **S7** | 部署风险：本地 `APP_ENV=dev`、默认 `SECRET_KEY` | `.env` / config | 非 prod 可能跳过 webhook 验签；JWT/BYOK 加密弱 |

### MEDIUM（产品/SEO）

| ID | 问题 | 影响 |
|----|------|------|
| **S8** | Markets `/stocks/{sym}.html` 404 | SEO 扩量卡死 |
| **S9** | 全量 `chat_requests` 存 prompt | 库被拖 = 提示词泄漏面 |
| **S10** | BYOK 成功不扣平台钱包 | 若产品意图含网关费则收入为 0（需产品确认） |

### 已较稳固

- 履约原子 claim + 账本幂等；prod 禁 mock pay  
- PayPal/Creem/Dodo webhook 生产路径有验签  
- API Key HMAC；BYOK AES-GCM；CORS prod 拒 `*`  
- SSO / EdgeOne / 双支付桥已上线
