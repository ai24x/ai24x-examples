## 监控项说明

### 1. GSC（Google Search Console）
- **收录页数：** 站点被 Google 索引的页面数量
- **曝光次数：** 搜索结果中出现的次数（不含同一个人多次搜索）
- **点击次数：** 从搜索结果点击进入的次数
- **CTR：** 点击次数 / 曝光次数
- **检查频率：** 每日 1 次（数据有 2-3 天延迟属正常）
- **数据源：** GSC API 或手动导出

### 2. markets SEO 页面 200
- **定义：** markets.ai24x.com/stocks/{symbol}/ 页面返回 HTTP 200 的数量
- **检查方法：** 批量 curl 或监控脚本
- **目标：** 所有已上线页面均返回 200
- **频率：** 每日 1 次（部署后必检）

### 3. Dodo 首单
- **定义：** DodoRelay 平台上的首笔充值/订单
- **状态：** 等待 Dodo 平台对接完成
- **监控：** 有/无，记录日期和金额

### 4. X 表现
- **发帖频率：** ≤1 条/天，≥12h 间隔
- **关键指标：** impressions（曝光）、engagement（互动）、link clicks（链接点击）
- **数据源：** X Analytics 或手动记录
- **分析维度：** 哪类内容表现好（教育型 vs 产品型 vs 股票分析型）
