## UTM 规范
`utm_source=google_ads`（渠道）· `utm_medium=cpc` · `utm_campaign={批次}` · `utm_term={关键词}` · `utm_content={广告变体}`

## 归因链路
广告点击 → 落地页（带 UTM）→ 注册 → PayPal 充值 → 按批次/词组归因到报表
- 开投前必须验证 UTM 参数完整落地并能在后端查询
- 每次上线前核对生产价表与 `pricing.html` 一致
