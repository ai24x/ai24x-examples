## B. 醒来联测清单（约 20 分钟）

1. **价表**：价格页 / 控制台只见 3 包（入门、开发、Scale）；月卡不可买。  
2. **CNY 展示**：入门约 ¥14.4、开发约 ¥144（汇率 7.2 时），不是 ¥0.14。  
3. **PayPal live 小额**：下单 → 回调/webhook → 余额到账 **一次**；再点「确认到账」应 `duplicate`，余额不翻倍。  
4. **流式扣费**：用 Key 打流式 chat，看流水 `amount_usd` 非 0，控制台美元余额同步减少。  
5. **mock**：生产控制台不应出现「模拟到账」；即使覆盖文件误开也应 403。  
6. **预检**：余额很少时设很大 `max_tokens` + pro，应 402/额度不足，而不是先跑完再扣穿。  
7. **vip-picks**：改后台倍率后硬刷新，前台估售价跟着变。  
8. **邀请页**：文案含「token 入账 / 可抵扣 / 不支持提现」。  
9. **登录爆破**：连续错密约 8 次应 429「尝试次数过多」。
