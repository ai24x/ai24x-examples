> 数据口径：我方报价取自生产接口 /v1/billing/plans、/v1/models（2026-08-05 实测，与本地一致）；竞品官方价来自各厂商官网/文档，聚合平台来自 ai24x.com/competitor-ranking.html（08-02/03 三轮调研）。价格随时会变，对外页面以 console 页面为准。

## 0. 结论速览（TL;DR）

1. 别跟「亏损引流盘」拼价格：LAYSO/TokenLab 的官方 30-70% off 不可持续，我们的护城河是「信任 + 中/美模型一把 key + 预充额度不过期 + 免绑卡免订阅 + 7×24 可用性」，定价基准应锚定 OpenRouter（+5.5%）而不是亏损盘。
2. 套餐单价倒挂要修：现 Scale $0.495/M > Builder $0.40/M > Advanced $0.35/M，最大包单价最贵，会被精算型开发者抓包。建议「升额度不降价」或「降 Scale 到 $95」二选一，并把每百万单价透明化。
3. 模型价 5 档要调：Terra/Claude-Sonnet/GPT-5.4 目前靠上游 50% off 促销成本定价（卖价低于官方混合价），促销一到期必亏，必须加「促销到期守卫」；GLM 比官方贵约 94%，建议换上游源后下调；flash $0.35 锚点保留作钩子。
4. 额度有效期建议改为不过期（现 12 个月）：OpenRouter 预充不过期，我们 12 个月到期反而是短板；「额度不过期、仅 VIP 资格过期」是强信任信号，实现成本也低。
5. 落地机制：已具备 token_plans_override.json（套餐）+ model_warehouse_override.json（单模型 mult）两个快速调价入口，再加一个「每周竞品比价 + 毛利守卫」脚本（副脑03/04 侧），就能实现「快速浮动可控」的长期策略。

## 4. 核心问题诊断（7 条）

1. 套餐单价倒挂：Scale $0.495/M > Builder $0.40/M > Advanced $0.35/M，最大包反而最贵（靠 VIP 资格撑），精算型用户会流失。
2. 促销成本依赖：Terra/Sonnet/GPT-5.4 的 cost 是 OpenRouter 50% off 促销价；促销结束且未调价时，输出重场景直接亏本（Terra 按 1:3 算毛利 -81%）。
3. 1:1 混合假设失真：推理模型实际输出占比高，按 1:1 定 mult 会系统性低估成本。
4. GLM 卖价偏高：3.50 vs 官方 GLM-4.6 混合 1.80，贵 94%；除非上游是更高档 GLM 变体，否则对价格敏感开发者没吸引力。
5. 额度 12 个月过期：OpenRouter 预充不过期，我们到期作废是竞争短板，也是差评/退款纠纷来源。
6. 单一口价粒度太粗：billing_mult 是整数（0.35 步进），低价模型（0.35~1.75 区间）无法精细调价，也限制了低价位段的毛利优化。
7. 价格透明度不足：套餐页没展示「每百万单价」，无法帮用户算账；「比官方贵/便宜多少」也没给证据，转化靠猜。

## 5. 优化方案

### 5.1 套餐层（P0，可只改 override + 页面文案）
目标：单价单调、大包更划算、每百万透明、Scale 的 VIP 价值可感知。

| 档位 | 现状 | 方案 A（升额度，推荐） | 方案 B（降价） |
|---|---|---|---|
| Starter | $2 / 1M | 保持 $2 / 1M（体验价，限购 1 次） | 同左 |
| VIP Pass | $15 / 30 天 | 保持；文案注明「可叠在 Builder/Advanced 上」 | 同左 |
| Builder | $20 / 50M | $20 / 55M（$0.364/M） | $18 / 50M（$0.36/M） |
| Advanced | $49 / 140M | $49 / 150M（$0.327/M） | $45 / 140M（$0.321/M） |
| Scale | $99 / 200M + VIP365 | $99 / 250M + VIP365（$0.396/M，含 VIP 后仍低于 Builder） | $95 / 200M + VIP365（$0.475/M） |

- 推荐 A：价格不变（少动支付/对账），额度上浮制造「加量不加价」，并让 Scale 含 VIP 后单价低于 Builder，逻辑自洽。
- Scale 卡面写法：「$99 = 12 个月 VIP 点名权（单买价 $180）+ 250M 额度（$0.396/M）」，把 VIP 价值显性化。
- 额度有效期：建议改为「额度不过期、仅 VIP 资格过期」（validity_days 配置化）。若保守，先改 24 个月。
- 页面：pricing.html 增加「每百万单价」列；首屏加一句「额度永久有效 · 免绑卡 · 免订阅」。

### 5.2 模型层（P1）
保留（不动）：flash 0.35、ds-pro 1.05、kimi 13.65、haiku 4.55、opus 22.75、gemini-pro 10.5、qwen-max 4.55、gpt5 8.75、gpt4o 9.45、gpt5-mini 1.75、minimax 1.4、kimi-code 3.5。
调整建议：
- vip-glm：核对上游是否 GLM-4.6；若是，换硅基/直连低价源后 mult 10 降到 7（约 $2.45，仍保 1:3 毛利 ≥25%）；若是更高档 GLM，保留 3.50 但文案注明变体。
- vip-gpt56-terra / vip-claude-sonnet / vip-gpt54：促销到期守卫。新增配置 promo_until（如 2026-09-30），到期自动按官方价重算 mult（Terra 例：cost 2/12 → 1:1 混合 7 → mult 30 → $10.5/M）；到期前保持现价做「窗口期特惠」宣传。
- vip-gpt56-luna：保持 0.70；官方降价后我们仍低于官方混合价，可当「国际入门钩子」。
- 可选优化：允许 billing_mult 一位小数（0.35 步进改 0.05 步进），让低价模型可精细定价。属代码级小改（int() 保留一位小数），放 P2。

### 5.3 定价引擎守卫（P1，代码/脚本）
- 毛利守卫：对每个模型按 1:3 混合成本算毛利，<15% 时预警（走现有飞书预警通道），<10% 自动触发「提价待确认」工单。
- 比价巡检：副脑03 竞品榜单增加「官方价 → 我方卖价」差值列；每周一次，偏差 >80% 或毛利 <15% 的模型自动入候选调整清单。
- 调价入口：套餐走 token_plans_override.json，单模型走 model_warehouse_override.json，改完 pm2 restart core 即生效，全程可回滚（备份 override 文件）。

### 5.4 免费层与冷启动（P1）
- 免费层保持「每日限额 + 每 key/IP 限流」，不强制手机号（国际用户无国内号，指纹/T13 只做后端风控阈值，不做前端拦截）。
- 上线期促销建议（可选）：首单 Starter 送 50% 额度（$2 得 1.5M），对标 Pateway「首单 20% off」但不伤价格锚点；国际投流 landing 强调「$2 起、额度不过期」。

### 5.5 支付通道（Airwallex 审核通过后，P1）
- PayPal + Airwallex 双国际通道；Airwallex 费率低可补贴「首单立减」或维持现价放大毛利。
- 支付宝/微信仅面向国内站（东南亚/港台用户若走国际站，引导 PayPal/Airwallex）。

## 6. 需要你决策的点

1. 套餐方案 A（升额度，价格不动）还是 B（降价）？默认建议 A。
2. 额度有效期：改「不过期」还是保守「24 个月」？默认建议不过期（信任信号 + 减少售后）。
3. GLM 是否接受「换上游源 + 降到 $2.45」？需副脑04 先查硅基 GLM-4.6 可用性与实测速度。
