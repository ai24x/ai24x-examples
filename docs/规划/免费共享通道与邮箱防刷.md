# 免费共享通道与邮箱防刷口径（2026-07-30）

## 1. 邮箱恶意注册刷量？

**现阶段风险可控**：注册仅 **一次性小礼包（5k）**，已关闭 FREE 月赠；刷号套利空间有限。邀请双方各得另有 IP/人日帽。

建议保持轻量防护（已有或易加）：

| 措施 | 优先级 |
|------|--------|
| 发信冷却 + 同 IP/邮箱小时上限 | 已有类似能力则保持 |
| **注册赠送额度小（5k）且一次性；月赠关闭** | **已落地** |
| 邀请即时奖频控 | 已有 |
| 同邮箱仅一个账号 | 已有唯一约束 |
| 验证码必过才建号 | 已有 |
| Cloudflare Turnstile / 图形验证 | **有刷量再加** |
| 一次性邮箱域名黑名单 | **已落地**（`api/email_abuse_guard.py`；发信+注册双拦） |
| 邮箱发信 IP/邮箱小时帽 | **已落地**（同文件；进程内） |

**结论**：小额礼包 + OTP 阶段**不必重做防刷**；若出现异常注册曲线再上验证码墙。详见 `docs/规划/赠送与拉新策略-2026-07-30.md`。
