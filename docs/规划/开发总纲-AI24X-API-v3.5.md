# AI24X API · 开发总纲（v3.5 · 执行对齐版）

> **版本**：v3.5.3 · 2026-07-27 · 定价：国内外统一国际口径  
> **策略**：产品与售价对齐国际；国内仅测试场（不主攻国内开发者市场）  
> **协议**：`X-API-Key` + `prompt`；Phase 2 再做 OpenAI 兼容（`Bearer` + `messages`）  
> **岗位/节点/路由总纲**：`docs/规划/主脑副脑岗位与国际Token供给-1.0.md`

现行入口：本文件。旧版见 `docs/历史/`。

## 一、一句话定位

**AI24X — 中国高性价比模型的全球 API 入口（对标 OpenRouter 中国模型线：更好用，价格贴近或略高，整体性价比打得过）。**

## 二、市场与定价（2026-07-26 拍板 · 07-27 补充）

| 项 | 口径 |
|----|------|
| **主力市场** | 国际开发者（USD · PayPal/Stripe） |
| **国内** | **仅测试/联调**；不主攻国内付费开发者 |
| **售价** | **国内外统一国际价表**（USD 锚定；CNY 按汇率展示） |
| **结算** | **国内站**：微信/支付宝 · **CNY**；**国际站**：PayPal 等 · **USD** |
| **峰谷** | DeepSeek 高峰×2 **不对用户加价**；路由切固定价上游 |
| **区域** | 欧盟默认 Qwen 国际；非欧盟默认 DeepSeek；ToS 写明模型处理地 |
| **节点** | 国际入口 **先 1× 新加坡（04）**；暂不加美/欧主机 |
| **对标** | OpenRouter 中国模型线 **+10%～25% 便利溢价** |

| 阶段 | 支付 | 文档 | 说明 |
|------|------|------|------|
| **Phase 1** | 微信/支付宝 + mock | 中文 | 测通链路 |
| **Phase 2** | + PayPal Live（04） | 英文为主 | 新加坡网关 + 多上游 + OpenAI 兼容 |

## 三、品牌与 SKU

| 对外档 | 计费侧 | 默认路由（目标） | 限制 |
|--------|--------|------------------|------|
| Free | `FREE` | 欧盟 Qwen 国际；非欧盟 DS Flash；高峰偏固定价 | 月赠；**日请求 100** |
| Flash | 加油包余额 | 同上 flash | `model=flash` |
| Pro | `VIP` | 欧盟 Qwen-Plus；非欧盟 DS Pro | `model=pro` |
| Ultra | VIP + 高端 | 智谱海外等 | `model=ultra` |

```bash
curl http://127.0.0.1:8000/v1/chat/run \
  -H "Content-Type: application/json" \
  -H "X-API-Key: sk-..." \
  -d "{\"prompt\":\"你好\",\"model\":\"flash\"}"
```

## 四、副脑分工（摘要）

| 席位 | 角色 | 口径 |
|------|------|------|
| 主脑 | 指挥官+开发 | 编码、拍板、门禁指令 |
| 01 | 国际获客 | VPN/SEO；**非**生产服、**非**预发 |
| 02 | 国内获客 | 行情官种子/社媒 |
| 03 | 国内生产店长 | `a.ai24x.com` |
| 04 | 国际生产店长 | `www`+`api`+PayPal Live |

发版：**本机合格 → Gitee → 生产门禁**（无独立预发机）。
