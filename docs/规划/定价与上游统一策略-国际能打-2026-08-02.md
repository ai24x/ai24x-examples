## 0. 一句话战略

**主战场卖「中国强模极致性价比（flash/pro）」——单价贴近上游成本的薄利透明档；VIP 名模点名卖「省事与可选」，不跟 OR/LAYSO 拼国际旗舰低价。**  
上游：**硅基流动打中国模成本底 + DeepSeek 直连稳底 + OR/TokenLab 作国际旗舰备用**；LAYSO 仅小额试单。

## 1. 目标约束（必须同时满足）

| # | 目标 | 量化底线（建议） |
|---|------|------------------|
| 1 | 够付运维 + 投流 | 付费用户毛利（收入−上游 token 成本）**≥ 35%**；投流 CAC 回收 ≤ 首充后 60 天 |
| 2 | 极致性价比（能打） | **flash 有效售价**落在官方/OR 的 **1.5～2.5×**（中国模）；对外可说「省事 + 略贵一点」或「专精中国模更省」 |
| 3 | 投流能比价 | 定价页 / 名模页有**可比口径**（$/M 或「约等于官方 ×N」），避免再被算成「贵 100 倍」 |
| 4 | 国内也能打 | 同一套国际锚价 × 汇率 → CNY；体验靠入门包/日帽，不另开倾销表 |
| 5 | 长期可扩 | 换上游只动路由与成本，**不绑死单一供应商**；名模可关可降权 |

另需考虑（04 原文未写全）：

- **PayPal / 通道费率**（约 3～5%）计入毛利  
- **失败重试、高峰 failover** 的隐性成本  
- **免费共享 / 注册礼** 的成本帽（已有日帽则守住）  
- **话术与真实价一致**（决策曾写「比 OR 高 10～25%」，必须回到这个量级或改话术）  
- **合规 / ToS**：TokenLab 转售条款、硅基商用条款书面确认后再加重仓  
- **品牌档 vs 点名**：flash≠对外宣传「DeepSeek 官方价」，但**有效价必须像中国模聚合**

## 2. 产品双轨（对外叙事）

### 轨 A — 极致性价比（投流主推 · 占量 80%+）

- 模型：`flash` / `pro` / `auto`（背后中国模路由）  
- 卖点：一个 Key、PayPal、OpenAI 兼容、省事；**单价能打**  
- **不主推**「比 GPT 官方还便宜」——比的是 **中国强模聚合**

### 轨 B — VIP 点名（利润与差异化 · 占量少数）

- 模型：Kimi / MiMo / MiniMax / GLM / Qwen + GPT / Claude / Gemini  
- 卖点：会员可点名、统一账单；国际旗舰 **不承诺最低价**  
- 定价：官方或批发成本 × **1.8～3.0**（覆盖手续费与运维），贵于 LAYSO 补贴价可接受

## 3. 定价重构（核心：改锚，不是只改 mult）

### 3.1 废除「Builder = $40/M 永久锚」作对外估价

现网 VIP 页 `~$40 × mult` 与投流竞品不可比，**必须改锚**。

建议采用 **「成本加成 + 套餐展示」**：

| 档位 | 目标有效售价（用户真实 token） | 成本参考 | 目标毛利 |
|------|-------------------------------|----------|----------|
| flash（L1） | **$0.35～0.55 / M**（约官方 2～2.5× in 侧，或按 blended 定） | DS Flash ≈ $0.14/$0.28 | ≥ 40% |
| pro（L2） | **$1.0～1.5 / M** | DS Pro ≈ $0.435/$0.87 | ≥ 40% |
| ultra（L3） | **$2～3 / M** 或并入 pro | 路由更高配中国模 | ≥ 35% |
| 中国名模点名 | 硅基/OR **批发 × 2.0～2.5** | 见 04 表 | ≥ 35% |
| 国际旗舰点名 | 批发或官方 × **2.0～2.5** | TokenLab/OR | ≥ 30%（波动大） |

> 具体数字落地时用「blended in/out 假设」或「按 1:1 in/out 展示」二选一写死在定价页脚注，避免再吵口径。

### 3.2 套餐怎么改（仍卖「包」，但折算要对得上）

| 套餐 | 角色 | 建议方向（示例，待精算） |
|------|------|--------------------------|
| **Starter** | 投流钩子 / 限购 1 次 | 保持小额（$1～$3），额度按 **新锚** 给够「能跑通 hello + 小试」（如 5～20 万 flash 等效），**禁止**再出现 $100/M 观感 |
| **Builder** | 主充值包 | 按新 flash 锚反推额度：例如目标 ~$0.45/M → $20 应对应约 **4000～4500 万** 钱包 token（若仍用「1 钱包 token = 1 flash token」），或改「美元余额」——见 3.3 |
| **Pro Pass** | 订阅能打 | 保留 VIP 权益；日赠按 **新成本** 重算（宁少送、别按旧 $40 锚送穿毛利） |
| **Scale** | 大客户 | 预充优惠 5～15% + VIP，不靠暗示「无限」 |

### 3.3 两种技术路径（二选一，推荐先走甲）

**甲（改动小，推荐 Phase 1）**  
- 仍用钱包 token + mult  
- **大幅提高**同美元购得的 `credit_tokens`，并 **下调** VIP `billing_mult` 使名模有效价落到上表  
- VIP 页估价改为：`ref_usd_per_m` = 新 flash 锚（如 0.45）× mult  

**乙（更干净，Phase 2）**  
- 钱包改 **USD 余额**，按模型实时单价扣费（更像 OR）  
- 工程量大，等甲验证投流转化后再上

明细与官网见：`docs/联调/上游候选评估-接入建议-20260802.md`。

| 优先级 | 渠道 | 官网 / API | 用途 | 动作 |

## 6. 利润与投流护栏（上线前算一张表）

对每个付费 SKU 算：

`净毛利 ≈ 用户付费 × (1 − 支付费率) − 上游 token 成本 − 分摊免费额度`

硬规则：

1. flash 路径毛利 **不得长期 < 30%**（促销周除外，需有结束日）  
2. Google 测试预算周：**只推 Starter→Builder 转化**，用「有效 $/M」物料，不用「贵 100 倍」旧锚截图  
3. VIP 国际旗舰若批发价抖动：自动提高 mult 或暂时下架，**禁止亏本引流**

## 7. 分阶段落地（避免一次改炸）

### Phase 0（本周 · 不改价）

- 对内统一口径：承认旧锚不可投流比价  
- 硅基：盘点 VIP 目录哪些可切硅基、预估月省多少  
- TokenLab：要 API 文档 + ToS 摘要；LAYSO：≤$20 试单  

### Phase 1（改价甲 · 建议 1～2 周内）

- 定 flash/pro 目标有效价区间（上表）  
- 改 `credit_tokens` + `billing_mult` + VIP 页 `ref_usd_per_m`  
- 定价页脚注写清「有效价口径」  
- 副脑04：回归冒烟 + 一张「改价前后 $/M 对照表」  

### Phase 2（上游）

- 中国名模默认硅基；OR 降级  
- TokenLab 灰度国际旗舰  
- 投流第二波：用新价物料  

### Phase 3（可选）

- USD 余额扣费（乙）  
- `/v1/responses`、更多客户端案例
