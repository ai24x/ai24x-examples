## 二、分级直连通信（去中心化，解决堵塞+单点）

| 层级 | 通道 | 用途 |
|---|---|---|
| **项目官 ↔ 直属副脑** | SSH 直连（双向） | 日常派发/拉回执，不经总司令 |
| 项目官 ↔ 总司令 | 文件通道 | 协调/审批/跨项目 |
| 副脑 ↔ 总司令 | 飞书/SSH | 生产审批/异常/兜底 |
| 副脑 ↔ 雷总 | 飞书私信 | 总司令失联兜底 |

### 项目官 ↔ 副脑 直连闭环
- 项目官 → 副脑：SSH 派任务（`ssh Administrator@<IP> "openclaw agent --agent main --message-file ..."`）
- 副脑 → 项目官：回执写副脑本地 `C:\Users\Administrator\ops\收发\<项目>\回复\`，项目官 SSH 拉取

### 直属副脑组（去中心化）
| 项目官 | 直属副脑 |
|---|---|
| 平台官 | 04（国际生产）、03（国内生产） |
| 行情官 | 03（行情主生产）、02（运营） |
| 游戏官 | 01（游戏生产+构建）、02（竞品监控） |

### 兜底逻辑
- 总司令网关挂 → 项目官↔副脑 SSH 直连照常干活，仅审批/跨项目暂停
- 总司令整机失联 → 副脑飞书私信雷总，项目官本机继续编码
