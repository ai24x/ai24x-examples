## 1. 这是不是「对外售价」？

**是。** 该页是硅基流动 **对自己客户的 API 按量公开牌价**（生产选型用价表），不是各模型厂「官方成本内部价」。

性质更接近：

| 角色 | 说明 |
|------|------|
| 硅基 | 推理聚合 / 托管：一 Key 多模型，按 **硅基牌价** 向你收费 |
| 各厂官方 API | DeepSeek / 通义 / 智谱等 **官方直连价**（另一套） |

因此：**不是「官方价的固定折扣表」**，也 **不一定** 比官方便宜；要逐模型对比。

---

## 2. 和各自官方价比：优惠还是对齐？

**结论（务实口径）：**

1. **多数情况 = 硅基自己的零售价**，与官方「大致对齐或略有加减」，**没有**「全线官方价再打 X 折」的统一承诺。  
2. **部分小模型 / 活动模型标「免费」** —— 这是硅基引流与共享池价值，官方未必提供同等免费 API。  
3. **同名大模型（尤其 DeepSeek 旗舰）**：官方直连往往更便宜；硅基贵在「一站式、国内线路、多模型」。  
4. **Pro 线路**（页上 `Pro/...`）常与普通线路同价或分区价，偏稳定性/专线，不代表更低价。

### 对照示例（2026-07-30 量级，勿当合同价）

DeepSeek 官方常见口径（项目内既有记录 / 公开挂牌量级）：

| 模型 | 官方量级（USD / 1M） | 硅基中文页（CNY / 1M） | 粗换算 ≈USD（÷7.2） | 关系 |
|------|----------------------|------------------------|---------------------|------|
| DeepSeek-V4-Flash | 约 $0.14 / $0.28（入/出） | ¥1.00 / ¥2.00 | ≈ $0.14 / $0.28 | **大致对齐** |
| DeepSeek-V4-Pro | 约 $0.435 / $0.87（入/出，会浮动） | ¥12.00 / ¥24.00 | ≈ $1.67 / $3.33 | **常高于官方直连** |

含义：

- 做 **付费主路径 flash/pro**：优先 **DeepSeek 官方或 OR 挂牌最低通道**，不必默认硅基更便宜。  
- 做 **免费共享 / L0 / 小模型**：硅基「免费档 + 国内稳」往往更合适——比的是 **可用性与零成本**，不是旗舰价。

OpenRouter 等聚合侧也会挂 SiliconFlow 作为上游之一，挂牌价同样是「转售价」，可与中文页交叉验证。
