## 九、Git 工作流红线

- **双推送**：`git push gitee && git push origin`（缺一不可）
- **等待确认**：commit 后必须等你亲自确认测试通过，才推代码
- **打 tag**：每次用户确认后打 `verified-YYYYMMDD` 标签，防线上事故
- **默认分支**：只用 `master` 发布，不做多分支

## 十、项目关键坑（踩过 & 记住）

1. **东财 SSL 问题**：Windows schannel SSL 重协商断开 → 已加 `verify=False`
2. **BK≠THS**：同名板块不同编制，默认选 BK 并标注来源
3. **缓存文件名**：Windows 文件名含 `:` 会自动变 NTFS ADS，禁用
4. **图表 time**：必须传 `YYYY-MM-DD` 字符串，不可传对象
5. **PM2 v6 bug**：`startOrRestart` 报错 → 改用逐个 `pm2 start`
6. **serve 命令**：不用 `pm2 start serve`（.cmd 解析报错），需直调 serve main.js
