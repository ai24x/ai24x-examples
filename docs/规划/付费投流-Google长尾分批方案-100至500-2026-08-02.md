## 3. 预算档位与三批迭代

| 档位 | 总预算 | 建议拆批 | 日预算约 | 何时用 |
|------|--------|----------|----------|--------|
| **试水** | **$100** | 3×~$33 | ~$7 | 门禁齐后默认开跑 |
| **验证** | **$300** | 3×~$100 | ~$21 | $100 有注册+≥1 付费信号后再升 |
| **加码** | **$500** | 3×~$165 | ~$36 | 已有赢家长尾词再扩 |

**每档内部结构（主投长尾）：**

| 词组 | 占比 | 含义 |
|------|------|------|
| **A 中国名模 API** | **~40%** | china llm / kimi / glm / deepseek / qwen + api |
| **B 接入栈痛点** | **~35–40%** | openclaw / lobechat / open webui / cursor + china / openai compatible |
| **C 支付/可达长尾** | **~15–20%** | paypal + china model / usd billing（叙事主语仍是 China models） |
| 热门替代大词 | **≤10% 或 $0** | 仅侦察；不主砸 `openai api alternative` 等 |

**三批节奏（每一档预算都适用）：**

1. **第 1 批**：长尾主投 + 少量侦察；拿真实 CPC / 搜索词报告  
2. **第 2 批**：否定废词、加码有注册长尾、砍高花费零转化  
3. **第 3 批**：只留赢家 + 1～2 条扩展长尾；出复盘与「停/续/加码」建议  

地域建议：US / CA / UK / AU / SG / DE。

## 6. 成功线与决策

| 档位结束看 | 倾向 |
|------------|------|
| 注册少、CPC 虚高、0 付费 | **停或缩**，改词/改落地，不升 $300 |

不以「首充 2x 回本」判 $100 成败；看 **真实 CPC + 注册/付费信号 + 30 日 LTV 潜力**。
