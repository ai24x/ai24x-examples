## 1. 付费池 / 共享池不够用 → 怎么扩

**拍板：关键路径先保证 2 家异厂；其余按真实告警慢慢接入。不做「绝对够用备满」。**

| 池 | 开业底线（已具备方向） | 后期再加 |
|----|------------------------|----------|
| 共享免费 | 硅基主力 + OR Auto 备；failover / rotate | OR Free、第二硅基模型、BYOK |
| 付费 | OR 或 DS 主路径 + L0 兜底；层内容灾 | **VIP 点名中国名模**（OR 优先）+ 国际旗舰；有量再直连 Qwen/GLM |

「不够用」四类对策：限流→rotate/加同级备；账单撞顶→加钱换厂；单家挂→异厂备；质量不够→引导付费，不堆免费好模。

触发再扩：日请求上来、连续 429/5xx、单家账单异常——再点开目录项，不提前堆十家。

## 2. 硅基图片 / 视频 / 音频 · 现在要不要接

**结论：MVP / 国际主打阶段不做。记为 P2+ 可选。**

| 理由 | 说明 |
|------|------|
| 产品焦点 | 当前卖 **Chat Completions 统一 API + Token 计费**；多模态是另一套计费、存储、审核、超时与产品页 |
| 国际主客 | 海外开发者要图/视频时，优先走 **OpenAI / Replicate / fal / OR 多模态**，不靠硅基中文站心智 |
| 硅基多模态价值 | 更适合 **国内线 / 行情官周边 / 以后中文站增值**，不是国际 Token 差异化核心 |
| 成本与运维 | 视频/音频账单波动大、失败重试与内容合规重；一人公司先稳文本漏斗 |

**何时重开**：文本付费流水稳定 + 明确 SKU（如「生图加油包」）+ 上游条款与结算清晰。优先评估路径仍是 **OR 多模态**（国际叙事一致），硅基多模态作国内备选。

## 3. 主打国外开发者 · 凭什么选我们 · 怎么体现优势

**不要假装「比 OpenAI 更全 / 比 OpenRouter 更大」。要打「中国模型国际通道 + 更省事的信用与路由」。**

### 3.1 真实可卖的优势（对外可写）

| 卖点 | 用户感知 | 落地要求 |
|------|----------|----------|
| **中国强模一站式** | DeepSeek / Qwen / MiMo 等，一个 Key、统一账单 | 对外别名 `flash/pro/ultra`，不暴露上游品牌乱跳 |
| **比直连多家更省事** | 少注册、少发票、少换 Key | 控制台、用量、PayPal、英文文档 |
| **性价比专精** | 同档中国模型，标价贴近或略高 OR 10%～25%，换稳定路由与客服口径 | 对齐定价决策；禁止自杀价 |
| **免费可试、付费可升** | shared 日帽 → 升 VIP；余额尽有升级 CTA | 共享与付费池隔离 |
| **新加坡入口** | 延迟/支付/站点国际向 | 诚实写延迟预期（上游若在国内，不承诺「等于美东」） |

### 3.2 不要硬吹（易翻车）

- 「全球最全模型目录」（输给 OR / OpenAI）
- 「绝对最低价」（毛利与稳定性双杀）
- 「与本地同延迟」（中国上游经 SG 出口须诚实）
- 「官方代理 / 白标大厂」（条款与品牌风险）

### 3.3 体现优势的最短产品清单（P0/P1）

| 级 | 动作 |
|----|------|
| P0 | 英文落地页 + 一页 Quickstart（curl / OpenAI SDK 兼容） |
| P0 | 状态页 / 余额与用量透明；PayPal 履约稳 |
| P1 | 「China models / Value route」专页：flash=省、pro=强，对比「为何不直连五家」 |
| P1 | 区域与延迟说明（SG 网关 + 上游区域诚实表） |
| P2 | 多模态、美西节点、欧盟合规专线 |

## 4. 后期给国内买家开 GPT / 国际旗舰 · 可否 · 风险

**技术上：主机在新加坡 ≠ 可以随意转售 OpenAI 等给中国用户。产品上：可以做「国际旗舰 SKU」，但必须条款 + 主体 + 支付分轨。**

### 4.1 可以怎么做（方向）

- 通过 **OpenRouter / 正规聚合** 或 **自有海外主体直签** 拿国际模型，在 **新加坡 API** 上对用户计费转售（卖平台 credit，不宣称官方代理）。
- 国内买家若用 **境外支付（PayPal 等）+ 访问新加坡 endpoint**，产品形态接近「出海开发者同一套」；另开 SKU，**不与中国模型国际价混表**（已有定价决策预留）。
- **不要**默认把「国内微信/支付宝买 GPT」当成一期必做——支付主体、发票、退款、内容合规全变一摊。

### 4.2 主要风险（与「在不在新加坡」无关的部分更多）

| 风险 | 说明 | 缓解 |
|------|------|------|
| **上游 ToS / 转售** | OpenAI 等对转售、地区、终端用户有限制；经 OR 须遵守 OR + 上游双重条款 | 只走允许转售/聚合的路径；对外不写「官方 GPT」 |
| **地区与账号政策** | 部分厂商对中国大陆使用/支付有限制；「国内买家」身份与支付方式敏感 | 用户协议写清服务提供地=SG；KYC/支付方式与站点分轨 |
| **内容与合规** | 国内用户用国际模生成内容，仍可能触及国内传播/行业监管（看场景） | 先 ToC 开发者 API；不做面向公众的内容产品壳 |
| **支付与税务** | 境内人民币买境外算力：通道、退税、对账复杂 | 国内站继续中国模型+CNY；国际旗舰走 USD/PayPal |
| **出口管制 / 制裁名单** | 少数模型/算力有管辖限制 | 跟上游与聚合商政策；不做灰色「翻墙专供」营销 |
| **延迟与体验** | SG 主机只解决你们网关；模型仍在各云区 | 文档诚实；关键客户再加美西 |

### 4.3 拍板建议

| 阶段 | 口径 |
|------|------|
| **现在** | 国际主打中国强模 + OR；国内站体验/联调，不主打开 GPT |
| **有稳定国际流水后** | 经 OR（或直签）上 `gpt-*` 等为 **VIP/Ultra 或独立 International SKU** |
| **对国内买家** | 允许「同一新加坡 API + 境外支付」自助使用；**暂缓**「微信买 GPT」专轨，除非法务/支付主体就绪 |
| **营销** | 禁止「国内便宜用 GPT / 突破限制」话术；只讲统一 API 与套餐 |
