## 三、通信框架（统一收发根目录，每项目一条通道）

```
E:\AI24X\ai24x-website\ai24x01\收发\
├── 平台\（平台官）  指令\ + 回复\ + AGENTS.md
├── 行情\（行情官）  指令\ + 回复\ + AGENTS.md
└── 游戏\（游戏官）  指令\ + 回复\ + AGENTS.md
```

- 每通道配套：AGENTS.md 协议 + 收发目录 + 总司令统一 cron 轮询
- 现 `p\game\收发\` 归一到 `收发\游戏\`；`docs\营销\收发\`（司令主通道）迁入 `收发\平台\`
- 老板前缀：无前缀=总司令；`平台官:`/`行情官:`/`游戏官:`=直连对应项目

## 四、副脑调度规则（收口总司令）

- 副脑 01/02/03/04 = 总司令统一调度的资源池
- 项目官需要副脑资源 → 向总司令申请（写通道指令）→ 总司令派发 + 收回执
- 授权例外：只读查询/轻量操作可直调，回执统一回流总司令归档

## 五、审批流（单一出口）

- 涉及钱/生产/密钥/资质/支付 → 项目官报总司令 → 总司令把关 → 转雷总审批
- 项目官不直接找雷总（跨层越级，除非总司令失联的降级场景）

## 六、敏感信息分级通道

| 级别 | 内容 | 通道 |
|---|---|---|
| 🟢 普通 | 协同/汇报/进度 | 飞书群 |
| 🟡 普通敏感 | 账号密码/注册信息 | 飞书私信雷总（不进群不留痕） |

**铁律**：🟠🔴 永不进群、永不私信明文，只走 SSH/加密文件。
