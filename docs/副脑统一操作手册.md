## ⚠️ 常见错误处理

### 错误1：推送被拒绝
```bash
# 先拉取远程更改
git pull origin master --allow-unrelated-histories

# 解决冲突后提交
git add .
git commit -m "解决冲突"
git push
```

### 错误2：认证失败
```bash
# 重新配置远程仓库URL
git remote set-url origin https://ai24x:8d6d649284a6ee802f3360388053fa0b@gitee.com/ai24x/ai24x-website.git
```

### 错误3：目录结构不一致
```bash
# 检查当前目录结构
tree -L 2

# 按照标准结构创建目录
mkdir -p api web db config scripts docs
```
