## ⚠️ nginx no-cache 误插入事故（open console.html 404）+ 精准修复（08-28 晚）
- **事故**：雷总反馈 open.ai24x.com/console.html 404。根因：nginx no-cache 补丁脚本用 .NET String.Replace()（替换**所有**匹配）→ 把 token-admin/console no-cache 规则插进了 **7 个 server block**（nginx.conf 有 7 个 location /）。open/api/markets 是纯反代 block，location = /console.html 精确匹配后无 proxy_pass → 404（open 服务本身 18080 本地 200 正常）。
- **修复**：ops/_fix_nginx_nocache_www_only_20260828.ps1——从备份 nginx.conf.bak-20260828 恢复 → 按 server_name  www.ai24x.com; 定位 https www block → 仅在该 block 的 location / 前注入 2 条 no-cache 规则 → 校验仅 1 处 → nginx -t + reload。验证：open console 200 ✅、www console/token-admin 200 + no-cache + MISS ✅、api console 200（恢复代理）✅、markets console 404（原状无回归）✅。
- **教训（重要）**：① 修改 nginx.conf 前数清 server block，注入必须**按 server_name 定位**，禁用 Replace 全局替换；② 改 nginx 后必须逐个域名验证（open/api/markets/www）；③ 纯反代 block（无 root）里加 location 规则会截断代理导致 404。
- **脚本**：ops/_fix_nginx_nocache_www_only_20260828.ps1（ops/_ 前缀 gitignored，仅本地/04 保留）。
