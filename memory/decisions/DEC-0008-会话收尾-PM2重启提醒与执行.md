# DEC-0008：会话收尾 — PM2 重启提醒与执行

**状态**：已采纳（用户要求「永久记忆」）

## 决策

当本次改动**必须经 PM2 重启才能生效**时（典型：修改 `api/`、`p/a/api/server/` 下 Python 代码，或修改 `.env` / PM2 启动参数）：

1. **在对话收尾明确写一句**：需要重启哪些进程（例如 `core-8000`、`a-api-18031`），建议命令 `pm2 restart <name> --update-env` 或 `pm2 restart all --update-env`。
2. **在本地/当前会话可执行时**：由助手**直接执行**上述重启，无需用户再单独说「重启」。

## 反例（不必写重启）

- 仅改 `admin_config` 等**运行时读库**的配置且代码路径已支持热读。
- 纯文档、纯前端静态资源且当前部署方式不依赖本机 PM2 进程重载（按实际栈判断）。

## 备注

本地 `ecosystem.local.js` 刻意未启用 uvicorn `--reload`（Windows 体验）；因此**代码级变更仍依赖重启**，本决策不改变该工程选择。
