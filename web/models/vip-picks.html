点名模

下方中国名模适合点名调用；国际旗舰为附属。倍率越高，余额消耗越快。优先用 flash（$0.35/百万起）。

控制台

怎么用

  1. 注册并创建 API Key
  2. 在价格页或控制台购买套餐（点名模需套餐含 VIP）
  3. 请求里填写模型名：优先用推荐档；也可填下方名模名称

推荐档（优先）

日常先填 flash（约 $0.35/百万）或 pro；点名模/高倍率模型会更快消耗预充额度。预估仅供参考。
