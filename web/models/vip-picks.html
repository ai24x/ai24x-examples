整份清单都是 VIP 能力：上方推荐档优先——好记、同用量通常更省、高峰更稳；下方名模点名适合认准某一款时再用。倍率越高，余额消耗越快。

价格 控制台 接入

怎么用

  1. 注册并创建 API Key
  2. 在价格页或控制台购买套餐（名模点名需套餐含 VIP 天数）
  3. 请求里填写模型名：优先用推荐档；也可填下方名模点名

推荐档（优先）

默认用这里：好记、同用量通常更省、高峰更稳。填写 flash、pro 即可；新手先从 flash 开始。预估消耗仅供参考。
