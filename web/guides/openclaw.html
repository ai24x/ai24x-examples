OpenClaw → AI24X

Use AI24X as the model/credit layer for OpenClaw so agents can call extreme-value China LLMs with one key.

1) Create a key

Sign up → Console → create API key → keep a small credit balance (PayPal USD or CNY rails).

2) Configure OpenClaw

Point the OpenAI-compatible / HTTP provider settings to AI24X:

AI24X_BASE=https://api.ai24x.com/v1 AI24X_API_KEY=YOUR_API_KEY # Prefer public tiers in apps: AI24X_MODEL=flash # or: pro

Field names may differ by OpenClaw version—use your AI24X base URL, API key, and model flash or pro.

3) Smoke test

curl -X POST "https://api.ai24x.com/v1/chat/run" \ -H "Content-Type: application/json" \ -H "X-API-Key: YOUR_API_KEY" \ -d "{\"prompt\":\"ping\",\"model\":\"flash\",\"max_tokens\":64}"
