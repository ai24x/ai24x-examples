Migration in 4 steps (≈10 minutes)

1) Create an account and a key

2) Point your client to AI24X

Everything that speaks the OpenAI protocol works — just change the base URL and the key. For example with the OpenAI SDK:

from openai import OpenAI client = OpenAI( base_url="https://api.ai24x.com/v1", # was https://openrouter.ai/api/v1 api_key="sk-ai24x-..." # your AI24X key )

3) Map model names

# OpenAI-compatible model names are accepted and mapped automatically. # Short aliases also work: "flash" | "pro" | "vip-kimi" | "vip-mimo" ... # Unknown names fall back to flash (no hard failures).

4) Verify with one request

curl -sS -X POST "https://api.ai24x.com/v1/chat/completions" \ -H "Authorization: Bearer $AI24X_API_KEY" \ -H "Content-Type: application/json" \ -d '{"model":"flash","messages":[{"role":"user","content":"Hello"}]}'

Expect HTTP 200 with an OpenAI-style response. 401 = wrong key · 402 = top up credits · 400 with model error = use a mapped model name.
