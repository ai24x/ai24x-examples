Privacy Policy

Last updated: 2026-08-07

AI24X (“we”) provides API access and related developer tools. This page explains what we collect and how we use it.

Data we collect

  • Account data: email (and optional phone), password hash, session tokens
  • Billing: plan purchases, payment references (WeChat / Alipay / PayPal), wallet balances
  • Usage: API request metadata needed for metering and abuse prevention

How we use data

  • Provide and secure the service
  • Process payments and credit token balances
  • Prevent fraud and enforce rate limits

Processors

Payment processors (e.g. WeChat Pay, Alipay, PayPal, Creem) receive only what is required to complete a transaction. Upstream model providers receive prompts you submit via the API.
