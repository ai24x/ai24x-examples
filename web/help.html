FAQ

What model should I send?

Everyday: flash (about $0.35/M) or pro / ultra / auto. Members can also name global models. New users: start with flash.

International payment

Pricing → Console → PayPal (USD). China (CNY): WeChat Pay / Alipay in Console.

401 / unauthorized

Check that your API key is correct, active, and your account is available.

Out of balance? Or need prepaid credits?

When prepaid credits run out, we auto-continue on the free daily pool (~100k tokens/day). Or set model=shared. pro/ultra and named models need VIP access and consume prepaid credits.

429 / rate limited

Slow down or upgrade plan.

Referrals

Share your invite code or link—see the Referrals page.

405 / Responses error?

POST /v1/responses is supported for text chat. If you still see 405, the Base URL likely includes /chat/completions—stop at /v1. For tools / agent tool-calling, turn Responses off and use chat/completions (Completions supports tools).

Why is my usage/balance running out so fast?

Each reply re-reads the full conversation history as context, so longer chats cost more per turn.

Getting "We're currently experiencing high demand…" / temporary errors?

This is a generic message clients show during temporary server-side fluctuations—retrying shortly usually works.

还是不行？

优先用控制台「转人工」提交工单并查看进度；紧急账单问题可用注册邮箱说明问题与大致时间。
