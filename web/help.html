FAQ

How do I search a stock, ETF or index?

Type a ticker such as AAPL, SPY or ^GSPC into the search box and press Search. Quotes, K-lines and indicators load automatically.

What indicators are available?

Daily, weekly and monthly K-lines with MA, MACD, RSI and volume.

What does the AI commentary tell me?

A plain-language technical snapshot of a symbol: trend, momentum, volume and watch points. It is educational, not investment advice.

How do I subscribe to Markets Pro?

Pro is $24.9/month or $199/year (33% off), paid with PayPal. One account works for both AI24X Markets and the developer API.

Why is the data delayed by 15 minutes?

We use free delayed market feeds. Sources are credited on every page; content is for educational purposes only.

Do I need a separate account for Markets?

No — sign in with the same AI24X account. Log in from the Markets app and manage billing from your Account.

Searching a symbol returns nothing?

Check the ticker spelling and use the exchange format (e.g. ^GSPC for the S&P 500). Some symbols on free feeds may be temporarily unavailable.

Delisted or renamed symbols

Delisted companies may no longer be available. Try the new ticker after a rename.

Why do daily, weekly and monthly look different?

Different timeframes show different scales, so markers and indicators naturally differ. Don't compare them directly.

Why do numbers differ from other apps?

Different platforms use different feeds and compilation methods. Please rely on the data shown on this site.

Can I trade based on the AI commentary?

No. Commentary, indicators and charts are educational references only. Markets involve risk; make your own decisions.

How do I manage or cancel my subscription?

Sign in to your Account (same sign-in as Markets) to manage your subscription. Cancel anytime; access continues until the paid period ends.

Developer API FAQ

What model should I send?

Everyday: flash (about $0.35/M) or pro / ultra / auto. Members can also name global models. New users: start with flash.

International payment

Pricing → Account → PayPal (USD). China (CNY): WeChat Pay / Alipay in Account.

401 / unauthorized

Check that your API key is correct, active, and your account is available.

Out of balance? Or need prepaid credits?

When prepaid credits run out, we auto-continue on the free daily pool (~100k tokens/day). Or set model=shared. pro/ultra and named models need VIP access and consume prepaid credits.

429 / rate limited

Slow down or upgrade plan.

Referrals

Share your invite code or link—see the Referrals page.

405 / Responses error?

POST /v1/responses is supported for text chat. If you still see 405, the Base URL likely includes /chat/completions—stop at /v1. For tools / agent tool-calling, use chat/completions.

Why is my usage/balance running out so fast?

Each reply re-reads the full conversation history as context, so longer chats cost more per turn.

Getting "We're currently experiencing high demand…" / temporary errors?

This is a generic message clients show during temporary server-side fluctuations—retrying shortly usually works.

Do prepaid credits expire?

No. Prepaid credits are valid indefinitely.

Topped up but balance not showing?

Make sure you're signed into the account used for payment. If it still doesn't match, open a ticket from the chat bubble with the payment order number and we'll investigate.

Can I get a refund for unused credits?

Yes. Unused balance is refundable—start a refund from Account → Billing. Invoiced or already-consumed amounts are not refundable.

How do I get an invoice?

Account → Billing lets you request an e-invoice by top-up amount or by consumption amount; you can also void and re-issue from the invoice history.

My API key leaked—what should I do?

Delete the leaked key in Account → API Keys right away (it stops working immediately), then create a new key and update your app. Never embed keys in web or client code, and don't share them.

How do I check usage per key?

Account → Usage lets you filter by API key and export data, so each key's consumption is clear.

Request sent but no response / only blank lines?

Streaming keeps the connection alive while waiting for the first token—please wait. If nothing arrives after ~10 minutes, the upstream is busy: retry later or switch to a more stable model like flash.

Still stuck?

Prefer Instant help → Human support for a tracked ticket. For urgent billing, email from your registered address with approx. time.
