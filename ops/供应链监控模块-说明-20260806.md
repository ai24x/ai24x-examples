# 供应链监控模块 · 说明（2026-08-06）

## 用途
后台「供应链监控」面板：逐模型监控 售价/成本/毛利（双口径），与 OR/TL/Requesty 实拉价对比，
自动发现三类风险：① 倒挂（售价 < 成本）② 低毛利 ③ 我方成本高于市场最低价 1.2 倍（可切通道降本）。
预警接入巡检推送：倒挂 = P0（error），低毛利/高成本 = P1（warn）。

## 口径
- GM入 = (售价入 - 成本入) / 售价入；GM出 = (售价出 - 成本出) / 售价出
- GM混合 = 1 - (成本入+成本出) / (售价入+售价出)（1:1）
- GM1:4  = 1 - (成本入+4×成本出) / (售价入+4×售价出)（输入1输出4 加权，贴近实际流量）
- 判定：任一 GM < 0 → alarm「倒挂」；GM混合 < 红线(默认 0) → alarm；GM混合 < 20% 或单端 < 10% → warn；
  成本 > 市场最低 × 1.2 → warn「成本高于市场最低 xx%」

## 阈值（env，可覆盖）
- PRICE_GM_WARN=20、PRICE_GM_RED=0、PRICE_COST_MARKUP=1.2
- 拉价超时：单家 15s，并行 3 家，总 30s 内返回；失败保留旧缓存（fallback_old）

## 数据源
- 我方售价/成本：`model_warehouse.py` catalog_merged()（含 override）
- 供货商价：OR/TL/Requesty `/v1/models` 实拉（TL models 接口不带价，比价用 tokenlab_detail 已核价目；
  初始基准来自副脑04 实拉缓存 `ops/quality-price-raw-20260806.json`）
- 官方直连参考：OR 价 ≈ 官方价（差异点在比价文档中标注）
