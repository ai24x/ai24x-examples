# 定价优化说明：点名模溢价调整 · 2026-08-06

> 背景：国外开发者点名中国名模（DeepSeek/MiMo/GLM/Kimi）比例高；此前点名价与品牌层 flash/pro 同价，未体现点名溢价且毛利偏低。
> 目标：点名模适度溢价（毛利 30%->55-60%），品牌层 flash/pro 不动（毛利已贴底线），同时守住「售价不超过官方直连 4x」红线。

## 一、调整方案（model_warehouse.py，5 款）

| 点名模 | 旧价 $/1M | 新价 $/1M | 混合毛利变化 | vs 官方直连 |
|---|---|---|---|---|
| DeepSeek V4 Flash | 0.35 / 0.35 | **0.35 / 0.70**（in×1/out×2） | 40% → 60% | 2.5x / 2.5x |
| DeepSeek V4 Pro | 1.05 | **1.40**（×4） | 38% → 55% | 3.2x / 1.6x |
| MiMo Pro | 1.05 | **1.40**（×4） | 38% → 55% | 3.2x / 1.6x |
| GLM-5.2 | 2.10 / 4.55 | **2.80 / 4.90**（in×8/out×14） | 30% → 40% | 2.5x / 1.4x |
| Kimi K3 | 5.60 / 18.20 | **6.30 / 20.30**（in×18/out×58） | 24% → 32% | 2.1x / 1.35x |

- DS Flash 文案同步改为「点名专属 · 全程同模型不降级」（不再用"高性价比"，避免与溢价矛盾）
- 品牌层 auto/flash/pro/ultra 价格不动（flash $0.35 / pro $1.05，输出毛利已 17-20%，无降价空间）
- Claude/GPT-5 薄利款（23-26%）不动（引流/品牌定位）

## 二、决策依据

- 点名 DS 与品牌层 flash/pro 同模型，涨价后价格敏感用户会转 flash/pro（毛利 40% 不亏），等于往最省钱入口引导
- MiMo/GLM/Kimi 品牌层无替代，用户"点名=我要这款"，溢价不流失
- 护栏：所有新价通过 `_assert_vip_margin_ok`（售价 >= 混合成本 ×1.5）
- 红线：全部 ≤ 官方直连 4x（DeepSeek 官方国际支付方便，超 4x 用户会流失）
