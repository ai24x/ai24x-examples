# 原型孵化与选拔流水线（游戏官 定稿 2026-08-13，v2 市场验证优先）

> 一句话：**先调研已被市场验证的玩法类型 → 原创化微创新做 5-10 个最简原型 → 副脑01 公网统一试玩页 → 10-20 人实测投票 → 排名选 1-3 个 → 微信端（测试号并行）→ 按排名上架 → 跑通复制下一个。**
> v2 核心变化：选题不再靠拍脑袋原创，改为「已验证类型 × 本地化/新包装」，降低研发投入与试错成本。

## 零、市场验证优先 + 合规红线（2026-08-13 雷总定，v2 加入）
1. **优先级**：已被市场验证的玩法类型（畅销榜/人气榜/IAA 榜有同类跑通）> 微创新 > 纯原创。原创只作为补充，不押注。
2. **合规红线（务必遵守）**：
   - 玩法/机制/规则本身不受著作权保护，可以借鉴复刻；
   - **禁止抄袭具体表达**：代码、美术素材、UI 布局、名称、商标、角色形象、音乐音效、文案——全部必须原创或合法授权；
   - 「换皮」= 玩法借鉴 + 100% 原创表达，这是行业通行做法，也是我们唯一允许的「复刻」方式；
   - 每次选题过「侵权自检」：表达是否全原创（代码自写/素材自绘/音乐自制或授权）、名称是否撞车。
3. **调研机制**：副脑02 每周出「市场已验证类型榜」（榜单来源：微信小游戏人气榜/畅玩榜、IAA 休闲榜、抖音小游戏榜、海外超休闲榜），输出类型/钩子/变现点/竞品示例/可借鉴玩法五要素，供选题池轮换。

## 一、为什么（依据）
1. 爆款率极低，但「已验证类型」的玩法已经过市场投票，命中率显著高于原创。
2. 注册/认证/备案（300 元/款 + 备案工时）只对胜出的 1-3 个投入。
3. 用真实试玩数据代替自嗨，喂给决策门（≥70% 玩满 3 局、≥50% 愿分享）。
4. 微信端开发不需要正式注册（测试号即可），与选拔并行推进。

## 二、流水线（阶段 → 动作 → 产出）

| 8 复制 | 跑通一款 → 从类型池复制下一个 | 矩阵滚起来 |

## 三、三条防翻车约束（务必遵守）
1. **数量服从质量**：原型 = 最简可玩闭环（验证「玩法钩子 + 裂变钩子」），不是成品；做不完 10 个做 6 个，宁缺毋滥。
2. **试玩 UX**：每人试玩 ≤5-8 个（再多疲劳、数据变噪声）；10 个以上分批或 15-20 人；统一试玩页。
3. **数据量化统一**：埋点（page_visit/game_start/game_end/play_rounds/share_intent/停留）+ 统一 1 分钟问卷 + 投票，同口径排名。

## 六、投入纪律
- 注册/认证/备案仅对胜出 1-3 个投放（300 元/款/年）
- 每个原型上线前过「好玩检查」：自己玩 3 局想不想再来？不想 → 砍或大改再上
- 每个原型过「侵权自检」：表达 100% 原创（代码/素材/音乐/文案/名称），否则不出原型
