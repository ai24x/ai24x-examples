## 选题原则
- 玩法借鉴经典/已验证类型池 A-J 的机制，**表达 100% 原创**（自写代码/自绘 CSS 图形/自命名/自写文案）
- 每局 30s-3min、单指操作、无教程文字即可懂 → 手机可玩（后期复刻微信端的前提）
- 单文件 HTML+CSS+JS（内嵌），无外部依赖，断网也能玩

## 技术规范（每款统一）
- 单 HTML 文件，`<meta name="viewport" content="width=device-width, initial-scale=1, user-scalable=no">`
- 触摸事件 touchstart + 鼠标 click 双兼容（pointerdown 统一）
- 禁 body 滚动/双击缩放（touch-action: manipulation; overscroll-behavior: none）
- canvas 或 DOM 渲染均可，视游戏类型选
- 自带简易开始界面 + 结束结算 + 重开按钮
- 列表页 / 统一入口：index.html
