   - 结算：微信流量主按月对公结算；穿山甲按月/周 + 提现门槛（≥100 元）。第一阶段只接微信流量主，跑通数据后再扩聚合。
3. **点位设计（定稿）**：P0-1 三点位（续命 15s / 双倍积分 / 每日挑战重试）定稿，每局限次（续命 1、双倍 1、重试 2）；插屏每 3 局 1 次低频。
   - **人均激励视频目标（定稿）**：≥3 次/日（对应 5 条验收标准第 4 条；休闲 IAA 行业均值 2-5 次/日，取 3 为及格线）。
4. **合规与准入（定稿）**：确认免版号判定成立 = 纯 IAA + 非实时对战 + 网络公司主体（乐清市速度网络有限公司）+ 软著/自审/备案三件套。流量主准入 = 小游戏累计独立访客 ≥500（UV）。
