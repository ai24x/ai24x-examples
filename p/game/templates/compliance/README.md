# templates/compliance — 合规文档包（每款游戏一套，先模板后定制）

> 原则：纯 IAA（无内购、非实时对战）免版号；网络公司主体；低调合规、快跑不踩线。
> 蓝本：渔悦 docs/合规经营方案.md（p/game/fisher/docs/）已跑通口径，直接套用改产品名。

## 模板清单（按需生成）

| 文件 | 用途 | 备注 |
|---|---|---|
| user_agreement.md | 用户协议 | 明示广告、积分不可兑换现金 |
| privacy_policy.md | 隐私政策 | 个人信息保护法/数据安全法、未成年人信息 |
| self_review.md | 游戏自审自查报告 | 提审必备，平台模板 |
| ad_guide.md | 广告合规自查 | 激励视频不得诱导误点、广告位明确标识 |
| compliance_checklist.md | 上线前合规清单 | 逐项勾选 |

## 红线（所有游戏通用）

- 不碰：真实货币充值、虚拟币提现/兑换、赌博/盲盒、UGC 自由输入、虚拟资产交易。
- 积分话术：叫「星币」，协议写明「仅虚拟荣誉、不可兑换现金」。
- 未成年人：接入微信健康系统/实名校验，防沉迷提示。
- 文案：不宣传「网游/手游」字眼；不承诺收益/提现。
