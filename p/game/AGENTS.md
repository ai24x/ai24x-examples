## 🔌 与总司令（主脑）的专项通信协议（2026-08-13 雷总定）

本会话需要总司令/副脑/雷总配合时，**走文件通道**（总司令 cron 每 10 分钟轮询），不要依赖飞书直接联系。

### 发需求给总司令（需要什么就写这里）
1. 需求写成文件：`p\game\收发\指令\YYYYMMDD-HHMM-需求名.md`
2. 文件内容模板：
   ```
   # 需求类型：①主脑直接办 / ②需副脑办(注明副脑01/02/03/04) / ③需雷总审批
   # 需求描述：（具体、可执行）
   # 验收标准：（明确）
   # 期望时间：（可选）
   ```
3. 写完即止，总司令自动处理

### 收总司令结果
- 总司令处理结果写入 `p\game\收发\回复\<指令文件名>-out.md`
- 本会话需要时读取该目录即可

### 规则（务必遵守）
- 能自己搞定的（写代码、跑本地命令、本机测试）**不用发总司令**，直接干
- 只有涉及 **副脑（01/02/03/04 生产/获客/运维）**、**跨机器操作**、或**需要雷总审批** 的，才写指令发总司令
- 总司令会：能自己办的自己办 → 办不了的派对应副脑 → 需要审批的转雷总
