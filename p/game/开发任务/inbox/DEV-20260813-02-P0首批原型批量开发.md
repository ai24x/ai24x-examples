## 2. B 离谱合成（key: weird-synth）
- 玩法：盘面随机掉落物品，两个同类合成为高级物品；合成路线含「离谱彩蛋」（蛋+蛋=鸡，鸡+鸡=恐龙，恐龙+恐龙=哥斯拉…）
- 最简闭环：单屏合成盘 + 5-6 层合成路线 + 合成动画 + 收集图鉴（新物品弹「新图鉴！」）+ 分数 + 结束页
- 钩子：收集欲（图鉴点亮）+ 惊喜感（离谱合成结果）
- 埋点：game_start/game_end（含合成数、图鉴解锁数）/share_intent
- 激励视频占位：双倍掉落 / 加速合成（按钮占位即可）

## 3. C 默契大考验（key: bond-test）
- 玩法：出 5 题（先吃包子还是油条/生气秒回还是冷战…），玩家先答自己，再猜好友答案 → 结算默契度 %
- 最简闭环：题库 ≥10 题 + 自答 + 猜好友 + 默契度结算卡（大字号 % + 评语）
- 钩子：默契度结算卡 = 天然分享物（H5 版先生成文字卡片，可复制/截图分享）
- 埋点：完成率/默契度值/share_intent
- 注意：H5 版好友数据用「随机假好友答案」占位，微信版再接真实数据

## 4. D 你不对劲（key: sus-meter）
- 玩法：10 道脑洞/三观题（如果必须选一个：永远不能说话 or 永远不能吃辣？），答完出「你不对劲指数」+ 结果标签
- 最简闭环：题库 ≥10 题 + 结果页（指数 % + 标签评语，如「不对劲指数 87%，建议离你远点」）+ 分享卡
- 钩子：羞辱式分享（结果标签天然想发群里）
- 埋点：完成率/结果分布/share_intent

## 5. F 解压操作类（key: pull-pins）
- 玩法：木板插满钉子/箭头，按正确顺序/方向拔除，动作解压 + 连击；选最简一种（拔钉子或拧螺丝）
- 最简闭环：1 个关卡流程（木板 + 可拔钉子）+ 解压动画（掉落/弹开）+ 音效（WebAudio 合成）+ 连击计数 + 结束页
- 钩子：解压手感 + 连击数炫耀
- 埋点：game_end（连击/用时）/share_intent
- 激励视频占位：下一关提示 / 双倍连击分
