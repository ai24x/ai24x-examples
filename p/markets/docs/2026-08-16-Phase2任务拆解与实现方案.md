## 二、架构决策

- **身份**：复用核心层账号（/api/me 已代验 /v1/user/info），markets 不建独立账户体系
- **数据**：markets 本地 SQLite（`api\server\data\markets.db`）存 订阅订单 / watchlist / 用户订阅状态；AI 点评缓存用文件缓存（沿用 Phase 1 模式）
- **模型**：AI 点评走核心层 `CORE_BASE + /v1/chat/completions`（内部 key，不暴露给前端）
- **支付**：复用核心层 PayPal 凭据；markets 创建订单时带 `custom_id=markets:{user_id}:{months}` 标记，webhook 按 custom_id 激活

## 三、数据模型（SQLite）

```sql
CREATE TABLE IF NOT EXISTS subscriptions (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL,            -- 核心层用户 id
  plan TEXT NOT NULL,               -- monthly | yearly
  status TEXT NOT NULL DEFAULT 'active',  -- active | expired | cancelled
  started_at TEXT NOT NULL,
  expires_at TEXT NOT NULL,
  source TEXT DEFAULT 'paypal',
  created_at TEXT DEFAULT (datetime('now'))
);
CREATE INDEX IF NOT EXISTS idx_sub_user ON subscriptions(user_id);

CREATE TABLE IF NOT EXISTS orders (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  paypal_order_id TEXT UNIQUE,
  custom_id TEXT NOT NULL,
  amount_usd REAL NOT NULL,
  plan TEXT NOT NULL,
  status TEXT NOT NULL DEFAULT 'created',  -- created | approved | paid | failed
  created_at TEXT DEFAULT (datetime('now')),
  paid_at TEXT
);

CREATE TABLE IF NOT EXISTS watchlist (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id TEXT NOT NULL,
  symbol TEXT NOT NULL,
  created_at TEXT DEFAULT (datetime('now')),
  UNIQUE(user_id, symbol)
);
```

## 四、API 设计

### 1. AI 点评 `POST /api/ai/brief`
- 入参：`{symbol, period="day"}`
- 鉴权：Bearer（免费用户限日 3 次，Pro 不限）
- 处理：拿 signals 数据 → 组装统计（最新价/涨跌幅/MA 关系/MACD 状态/RSI/位置/量能）→ 提示词模板 → 调核心层模型 → 合规黑名单过滤 → 写日缓存
- 出参：`{code:0, data:{symbol, brief, generated_at, cached}}`
- 合规：输出禁词（trade/signal/advisor/tips/picks/broker/buy/sell/买入/卖出/推荐/目标价）；只描述事实，不给建议

### 2. 订阅 `POST /api/subscribe/checkout`
- 入参：`{plan="monthly"|"yearly"}`（Bearer）
- 处理：创建 PayPal order（$14.9/$119）→ 返回 `{approve_url, order_id}`
- `GET /api/subscribe/status`：返回当前用户订阅状态 + 到期日（供前端/后端校验）

### 3. PayPal webhook `POST /api/paypal/webhook`
- 验签（复用 pay_paypal.py 模式）→ 取 custom_id 解析 `markets:{user_id}:{months}` → 激活/续订订阅 → 写订单 paid

### 4. watchlist `GET/POST/DELETE /api/watchlist`
- 免费 3 个 / Pro 50 个（按订阅状态判断）
