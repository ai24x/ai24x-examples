FAQ

What model should I send?

Bring your own keys (BYOK) or start instantly with managed access. Auto-routing, failover, request cache, cost dashboard. Service fee only — no token markups.

International payment

Pricing → Console → PayPal (USD). China (CNY): WeChat Pay / Alipay in Console.

401 / unauthorized

Check that your API key is correct, active, and your account is available.

Out of balance? Or need prepaid credits?

When prepaid credits run out, we auto-continue on the free daily pool (~100k tokens/day). Or set model=shared. pro/ultra and named models need VIP access and consume prepaid credits.

429 / rate limited

Slow down or upgrade plan.

Referrals

Share your invite code or link—see the Referrals page.

405 / Responses error?

POST /v1/responses is supported for text chat. If you still see 405, the Base URL likely includes /chat/completions—stop at /v1. For tools / agent tool-calling, turn Responses off and use chat/completions (Completions supports tools).

Why is my usage/balance running out so fast?

Each reply re-reads the full conversation history as context, so longer chats cost more per turn.

Getting "We're currently experiencing high demand…" / temporary errors?

This is a generic message clients show during temporary server-side fluctuations—retrying shortly usually works.

Do prepaid credits expire?

No. Prepaid credits are valid indefinitely.

Topped up but balance not showing?

Make sure you're signed into the account used for payment. If it still doesn't match, open a ticket from the chat bubble with the payment order number and we'll investigate.

Can I get a refund for unused credits?

Yes. Unused balance is refundable—start a refund from Console → Billing. Invoiced or already-consumed amounts are not refundable.

How do I get an invoice?

Console → Billing lets you request an e-invoice by purchase amount or by consumption amount; you can also void and re-issue from the invoice history.

My API key leaked—what should I do?

Delete the leaked key in Console → API Keys right away (it stops working immediately), then create a new key and update your app. Never embed keys in web or client code, and don't share them.

How do I check usage per key?

Console → Usage lets you filter by API key and export data, so each key's consumption is clear.

Request sent but no response / only blank lines?

Streaming keeps the connection alive while waiting for the first token—please wait. If nothing arrives after ~10 minutes, the model provider is busy: retry later or switch to a more stable model like flash.
