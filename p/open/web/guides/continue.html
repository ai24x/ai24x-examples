Continue → AI24X

Continue is an open-source coding assistant for VS Code and JetBrains. Point it at AI24X with the OpenAI provider—flash/pro and named models through one endpoint, with your own key (BYOK) or managed access.

1) Prerequisites

Sign up → Console → create an API key → keep a small credit balance. Install the Continue extension.

2) config.yaml (recommended)

Edit ~/.continue/config.yaml (or the config opened from Continue settings):

name: AI24X version: 1.0.0 schema: v1 models: - name: AI24X Flash provider: openai model: flash apiBase: https://api.ai24x.com/v1 apiKey: YOUR_AI24X_API_KEY roles: - chat - edit - apply - name: AI24X Pro provider: openai model: pro apiBase: https://api.ai24x.com/v1 apiKey: YOUR_AI24X_API_KEY roles: - chat - edit

3) config.json (legacy)

{ "models": [ { "title": "AI24X Flash", "provider": "openai", "model": "flash", "apiBase": "https://api.ai24x.com/v1", "apiKey": "YOUR_AI24X_API_KEY" } ] }

4) Pitfalls

  • apiBase must include /v1.
  • 401 = bad, truncated, or rotated key—paste the full key, or create a new one in Console.
  • Start with flash; VIP named ids need an active membership.
  • If a build defaults to Responses: text chat can use /v1/responses; for tools / agent tool-calling set useResponsesApi: false and use chat/completions.
