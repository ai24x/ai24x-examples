## p/ — AI24X 子项目池（可持续追加）

`p/` 用来承载 **独立迭代** 的新项目（优先国内业务验证），遵循“一个项目一个目录”的可复制结构；未来新增项目直接在 `p/` 下追加即可。

### 当前项目

- `p/a/`：**AI 行情官｜灯塔版（1.01）**（第一个子项目，域名 `a.ai24x.com`）
  - `p/a/web/`：前端演示页（当前 `demo.html`）
  - `p/a/api/server/`：后端 API（FastAPI，SQLite 起步）
  - `p/a/docs/`：规划、算法口径、合规/风控基线

- `p/fisher/`：**山海渔**（备用子项目｜微信小程序休闲垂钓 + 经营养成；见 `p/fisher/README.md`，完整策划 `p/fisher/docs/产品规划-山海渔-完整版-v1.0.md`，工程口径 `p/fisher/docs/架构与落地汇总.md`）

### 推荐的统一结构（新增项目照抄）

```
p/<project-key>/
  api/         # 后端服务（可选）
  web/         # 前端页面（可选）
  docs/        # 规划/口径/验收
  scripts/     # 本地脚本/工具（可选）
  vendor/      # 本地化静态依赖（可选）
  README.md    # 本项目入口说明（必备）
```

### 命名约定（建议）

- `<project-key>`：短、稳定、可用于子域名/路径（例如 `a`、`tools`、`lab`）。
- 对外域名：优先使用独立子域名（例如 `a.ai24x.com`），与主站 `www.ai24x.com` 解耦部署与风控。
