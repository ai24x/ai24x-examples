## 推荐的统一结构（新增项目照抄）

```
p/<project-key>/
  api/         # 后端服务（可选）
  web/         # 前端页面（可选）
  docs/        # 规划/口径/验收
  scripts/     # 本地脚本/工具（可选）
  vendor/      # 本地化静态依赖（可选）
  收发/        # 项目官通信信箱（可选，指令/回复/司令来信/司令回信）
  README.md    # 本项目入口说明（必备）
```

## 命名约定（建议）

- `<project-key>`：短、稳定、可用于子域名/路径（例如 `a1`、`game`、`lab`）。
- 对外域名：优先使用独立子域名（例如 `a.ai24x.com`），与主站 `www.ai24x.com` 解耦部署与风控。
