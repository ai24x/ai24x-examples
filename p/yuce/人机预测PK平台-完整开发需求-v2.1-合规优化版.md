## 一、项目核心定位

对标海外事件预测市场的**清算与命题严谨性**，以 **AI 独立研判为产品骨架，人类群体投票为差异化互动与传播层**。

**一句话定位：** 积分参与的人机同题研判 + 国产备案大模型独立输出 → 前台人机 PK 内容互动 → 后台加权商用概率 API。无博彩、无现金合约、无投资顾问属性。

**创意定位（对外口径）：** 属「组合创新」（事件研判 × 大众投票 × 多模型 PK × 国内去现金壳），国内外有近邻竞品（Kalshi / Polymarket / Manifold / Metaculus；国内雪球类猜涨跌为监管参照），**同形态合规平台稀缺，但不是无人区神话**。

### 四重红线（一条不可破）

1. ❌ 彻底移除现金合约、资金兑付、金融衍生品交易等违法模块  
2. ❌ 积分不可充值购买、不可提现、不可转账、不可变现  
3. ❌ AI 禁止创建虚拟账号混入真人投票池，两套概率物理隔离  
4. ❌ 从业者认证仅展示「从业标签」，不与预测加权联动（规避「专家建议=投资建议」）

### v2.1 新增合规底线

5. ❌ **永不开放**：政治/选举、敏感社会事件、个股涨跌、体育赛果、名人是非、未公开信息相关命题  
6. ❌ MVP/公测期 **禁止用户创建事件**；命题仅运营双人审核上线  
7. ❌ 前台禁止「盘口 / 赔率 / 下注 / 猜涨跌 / 赢钱」等表述与类交易 UI  
8. ❌ B 端概率数据 **禁止** 对接配资、自动下单、炒作投机类客户（合同 + KYC，不仅免责声明）

> ⚠️ 禁用游戏赛事预测。娱乐类仅保留票房。  
> ⚠️ **MVP 不五线齐开**（见 §九）。

### 候选盈利板块（成熟期运营权重参考：约 70%）

|---|------|--------|----------|----------|
| 1 | **大宗商品现货月度研判** | 我的钢铁网、卓创资讯、农业农村部等（授权/手录） | 下月现货均价是否上涨/突破指定价格 | 月度 |
| 2 | **A 股财报硬指标研判** | 沪深交易所财报公告 | 仅净利润增速、营收、产能、算力出租率等硬指标；**严禁股价涨跌** | 季报年报 |

### 候选民生流量板块（成熟期约 30%）

| # | 板块 | 数据源 | 结算频率 |
|---|------|--------|----------|
| 3 | 70 城二手房房价 & 成交套数 | 国家统计局、各地住建局公开口径 | 月度 |
| 4 | 宏观经济指标（CPI、PMI、社零） | 国家统计局 | 月度 |
| 5 | 院线月度票房 | 猫眼专业版、灯塔专业版（授权/手录） | 月度 |

### 品类白名单 / 黑名单（v2.1）

**可上（白名单原则）：** 有固定官方发布日、可公开核验、二元阈值可客观判定的产业/宏观/票房硬指标。

**禁止（黑名单，代码+运营双拦）：**

- 政治、政策揣测、舆论战、群体性事件  
- 任意个股/指数涨跌、融资融券、期货开仓建议  
- 体育/电竞赛果、博彩关联娱乐  
- 「该不该买房/买股」决策题、具体小区投资建议  
- 依赖非公开信息才能判断的题  

**财报专项：** 只挂已公告报告期 + 官方指标定义；避免临近窗口的诱导性标题。  
**房价专项：** 只用统计局等官方口径指数/套数，不做个案成交诱导。

## 三、底层核心架构：两套概率完全物理隔离

> **核心逻辑：** 禁止合并混淆。前台 PK 互动 + 后台商用售卖，各自独立运转。

### 第一层：前台展示层（用户可见，人机独立 PK）

#### 3.1 人类投票体系

- **风控分层（v2.1）：**  
  - 浏览赛事 / 看人机对比：**可免登录**  
  - 提交投票：**手机号实名**；设备指纹作为辅助因子（Android 硬件指纹；iOS 用设备标识 + 行为分，**不得宣称风控等级等同**）  
- 单事件单账号（+ 设备策略）终身仅可投票 **1 次**，禁止重复投票；**截止前默认不允许改票**（保清算公信；若产品要改票须单独法务评估）  
- **理由门槛分级（v2.1）：**  
  - 基础票：短理由即可（建议 ≥10 字），保证冷启动转化  
  - 优质理由（20～200 字）：可获展示加权 / 额外段位分，**绝不改变票权（一人一票）**  
- **人类概率：** 有效「是」票 ÷ 全部有效票；刷票账号不计入  
- **用户排名：** 按月正确率 → 青铜 / 白银 / 黄金 / 行业大神（展示名可再润色，避免「赌神」感）  
- **从业者标签：** 仅展示行业来源；不加权、不加成排名；文案禁止「专家荐」；理由区禁引流至站外荐股/带单  

#### 3.2 AI 独立分析师体系

**核心原则：**

- ✅ 仅使用**国内完成网信办备案**的大模型；**本产品部署与主站国际模型路由物理隔离**，禁止误接境外模型  
- ✅ AI 仅做独立分析角色，禁止虚拟账号混入真人池  
- ✅ AI 研判与投票数据完全隔离  

**AI 分级部署：**

| 阶段 | 模型数量 | 模型选择 | 说明 |
|------|----------|----------|------|
| **一期 MVP** | 3 家 | DeepSeek Flash（主力）+ Kimi + Qwen Flash | 先跑通对比与清算 |
| **二期扩充** | 6 家 | 新增智谱、豆包 Lite、百川等 | 会员量与收入覆盖算力后再扩 |

**运行规则：**

- 每日固定 1 轮定时拉取精简资讯、执行 AI 研判  
- 禁止用户点开页面无限触发批量 AI  
- 冷门事件 3 天刷新一次  
- 单款 AI 输出：是/否、0～100% 概率、简短依据；页面标注模型名（深度合成标识）  
- 免费看精简短句，付费解锁深度解读（字数上限）  
- 并列展示各 AI + AI 阵营均线 vs 人类整体；标签：「人机一致」「人机对立」「AI 内部分歧」  
- 月度最强 AI 榜  
- 高端模型深度解读仅会员按需调用  

#### 3.3 冷启动展示规则（v2.1）

- 人类有效票 **&lt; N**（建议 N=50～100，可配置）时：前台主视觉以 **多模型分歧 / AI 擂台** 为主，人类柱标注「样本不足」或折叠  
- 达到 N 后点亮人类概率，避免早期噪声柱误导传播与 B 端观感  
- 允许运营「种子内容」账号，但必须标注且 **永不计入人类概率池**（与 AI 不混池对称）

### 第二层：后台商用融合概率（仅 B 端 API 可见）

> 前端用户完全不可见，不参与任何 PK 排名结算。

#### 融合权重配置表

| 板块 | 融合公式 | 投票 &lt; 500 人时 |
|------|----------|-------------------|
| 大宗商品、财报 | AI × **85%** + 人类 × 15% | AI 95% + 人类 5% |
| 二手房、宏观经济 | AI × 70% + 人类 × 30% | AI 90% + 人类 10% |
| 电影票房 | AI × 55% + 人类 × 45% | AI 80% + 人类 20% |

#### 对外输出

- 每日融合概率、时序曲线、历史脱敏集  
- **方法论摘要**（权重、样本阈值、修订规则）— B 端信任必需（v2.1）  
- **校准指标**（见 §五补充）：Brier、校准曲线，成熟后输出  

→ B 端核心售卖资产

## 四、事件全生命周期自动清算引擎

> 全程默认可机审；争议走仲裁，杜绝私下篡改。

### 事件创建必填（缺一不可）

1. 投票开启日期  
2. 投票截止日期（须早于官方数据发布日 **≥ 3 天**）  
3. 官方数据源公开链接 + 官方固定发布日期  
4. 二元结果量化判定阈值  

### 上线闸门（v2.1）

- 运营双人审核（命题人 ≠ 终审人）  
- 黑名单敏感词扫描  
- 结算源可公开核验  

### 清算执行步骤

1. 官方发布日自动拉取权威真实数据  
2. 程序判定事件成立与否  
3. 同步：用户积分/段位结算、人类与各 AI 独立对错、数据永久封存  
4. 官方延期 → 结算日自动顺延  
5. 操作日志留存 **≥ 3 年**  

### 结算争议与数据修订（v2.1 新增）

| 场景 | 处理 |
|------|------|
| 官方数据事后修订（如统计局修订） | 以「首次用于结算的快照」为准并公示；或按白皮书约定「修订窗口内可重算一次」——**上线前二选一并写死** |
| 阈值/口径歧义 | 进入仲裁队列：双人复核 → 公示结论 → 必要时整场作废并退回本场消耗的投票额度；**禁止静默改历史榜** |
| 用户发起异议 | 限结算后 T 日内提交；记录工单与证据链 |

每场结算后自动生成 **「人机谁赢 / 哪家模型对 / 一句话复盘」分享卡**（一期就要，传播核心）。

## 五、用户激励体系（纯免费获取，零充值入口）

### 双账本（v2.1 强烈建议）

| 账本 | 用途 | 禁止 |
|------|------|------|
| **段位分** | 正确率、段位、月榜 | 不可商城兑换、不可提现 |
| **活动积分** | 签到、任务、商城虚拟权益 | 不可提现、不可转账 |

避免「扣积分投票 + 猜对奖积分」在观感上接近有奖竞猜；法务白皮书须专项论证本设计。

### 获取途径（无任何充值按钮）

1. 每日登录签到（连续递增可配置）  
2. 研判正确按难度发放 **段位分**（及可选少量活动积分）  
3. 新手任务、资质认证一次性奖励  

### 投票消耗（去赌感）

- **默认：** 免费用户每日基础票额度（不扣积分）  
- **超额：** 才消耗活动积分或要求会员  
- 付费会员提高日额度 / 不限次数（仍一人一票、不改正确率）  

### 积分消耗（若保留商城）

1. 超额投票或道具  
2. 虚拟权益：免积分投票券、理由置顶卡、往期复盘、会员体验碎片  

### 绝对禁止（代码封锁）

- 积分提现、转账、私下交易、折现、红包抵扣  
- **「积分 + 现金补差」兑实物：三期默认不做**；若强上须另案法务，不允许纯现金买实物走电商化擦边  

### 文案与 UI「去赌感」清单（v2.1）

| 禁用/慎用 | 推荐 |
|-----------|------|
| 盘口、赔率、下注、押注、猜涨跌、赢积分、奖惩、赌神 | 研判、投票、准确率、段位、复盘、人机对照 |
| 红绿闪动涨跌、深度图、K 线式概率跳动 | 静态对比条 + 分歧标签 |
| 「会员更准」 | 「会员解锁解读与工具，PK 票权公平」 |

## 六、三大商业化变现体系

### 开发优先级（延续 v2.0）

```
付费会员（C）→ B 端 API → 积分商城（可选，收敛虚拟权益）
```

### 变现 1：C 端分级付费会员

> 付费仅解锁功能权限，绝不提升投票权重、不修改 AI 判断、不增加预测正确率。

| 等级 | 核心权益 | 定价 |
|------|----------|------|
| **免费** | 基础投票（日额度）、精简 AI、基础榜 | 0 |
| **白银** | 更高投票额度、完整短解读、成绩单导出、去基础广告、每日理由置顶 1 次 | 月/季/年 |
| **黄金** | 白银 + 行业小工具、新事件提前预览、投票记录云备份、月度 PDF 简报三选一 | 月/季/年 |
| **钻石** | 黄金 + 全品类简报、个人 vs AI 准确率/校准报告、内测、专属客服、免广告 | 月/季/年 |

### 变现 2：B 端机构数据 API

**售卖：** 加权概率时序、脱敏历史集、行业日报；成熟后附 Brier/校准。

**收费：** 按量 / 年包 / 数据集 + 更新费。

**强制附加（v2.1）：**

- 返回体永久带免责与方法论字段  
- **销售 KYC + 禁售名单**（配资、炒作、自动交易对接）  
- 合同写明：仅产业调研参考，不构成采购/投资/交易依据  

### 变现 3：积分商城（三期可选，收敛）

- 仅虚拟道具  
- 实物 + 现金补差：**默认不上**

## 七、AI Token 算力成本控制 + 熔断机制

### 常规控本

1. DeepSeek Flash 承担约 70% 基础算力  
2. Prompt 模板化、输出限长；深度版仅会员触发、≤150 字级  
3. 素材仅 3～5 条摘要，不落盘存新闻原文  
4. 常规事件日 1 轮；冷门 3 天；票房可只开 2 款模型  
5. 后台监控：分模型日成本、日预算、一键开关  

### 熔断（v2.1：随一期上线）

```
月度：当月 AI 成本 > 当月总收入 × 120%
  → 暂停冷门与票房 AI；仅保留核心垂直 DeepSeek Flash
  → 告警管理员，人工解除

日报：当日成本 > 日预算 × 80% → 预警

熔断日志 ≥ 3 年
```

## 八、数据抓取 & AI 内容合规

### 8.1 数据源

- **政府公开数据：** 低频、间隔 ≥60s、守 robots、错峰  
- **商业平台：** 前期手录公开极简数；成熟期采购官方 API；禁破解反爬与复刻转售  
- **新闻摘要：** 搜索摘要 API，用完销毁缓存，不存全文  

### 8.2 AI 生成

- 标注模型名称  
- 禁止用抓取数据训练自有模型；仅单次研判  
- 前台只展示结论与精简逻辑  

### 8.3 爬虫规范

- 可识别 UA + 官方域名标识；禁伪装代理绕过  
- 抓取与 AI 调用日志 ≥ 3 年  

### 8.4 全站免责（底部常驻）

> 平台所有用户投票观点、AI 分析、概率数据仅为产业信息调研与知识互动参考，不构成任何投资、房产交易、原料采购决策建议。本平台无金融交易、博彩兑付相关功能。

### 8.5 上线前合规交付物（v2.1）

1. 《合规白皮书》（非博彩 / 非证券期货 / 非投顾；对照有奖竞猜与深度合成等口径）  
2. 文案 UI 去赌感清单验收表  
3. 品类黑白名单与命题审核 SOP  
4. 结算争议与数据修订规则（对外可公示摘要）

## 九、整体开发阶段划分（v2.1）

### 一期 MVP（约 8～12 周）：**单垂直深挖 + C 端 + 熔断**

**垂直建议（二选一组合，推荐）：**

- **B 向：** 宏观经济指标 **或** 大宗商品（一条即可）  
- **C 向：** 院线票房（传播与结算故事）  

一期必做：

1. 账号风控分层（浏览免登 / 投票实名）+ 双账本基础  
2. **仅 2 个垂直**框架 + 手录/合规数据入口（爬虫可后置）  
3. 3 家 AI 接入 + 日批调度  
4. 自动清算 + 延期容错 + **争议工单最小集**  
5. 付费会员四档  
6. 真人投票 + 段位榜 + **冷启动展示规则**  
7. **AI 成本监控 + 熔断**  
8. **结算分享卡**  
9. 合规文案/免责/模型标注落地  

### 二期（约 8～10 周）：B 端 + 扩模型 + 度量

1. B 端 API + KYC/禁售流程 + 方法论字段  
2. AI 扩至 6 家（按收入）  
3. 人机双榜、成绩单导出  
4. Brier / 校准曲线（对内先、对 B 后）  
5. 按需扩第 3～5 垂直  
6. 脱敏历史集打包  

### 三期（约 6～8 周）：增值收敛

1. 虚拟权益商城（无现金补差实物）  
2. 数据交易所对接（可选）  
3. 运营看板完善
