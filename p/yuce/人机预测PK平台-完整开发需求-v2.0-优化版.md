## 一、项目核心定位

对标海外 Kalshi 事件预测市场，**以 AI 预测为产品骨架，人类群体智慧为差异化调味料**。

**四重红线（Cursor 逐条校验，一条不可破）：**

1. ❌ 彻底移除现金合约、资金兑付、金融衍生品交易等违法模块
2. ❌ 积分不可充值购买、不可提现、不可转账、不可变现
3. ❌ AI 禁止创建虚拟账号混入真人投票池，两套概率物理隔离
4. ❌ 从业者认证仅展示"从业标签"，不与预测加权联动（规避"专家建议=投资建议"合规风险）

**一句话定位：** 积分投票 + 国产合规大模型独立研判 → 前台人机 PK 娱乐互动 → 后台加权商用概率 API 售卖。无博彩、无金融违规属性。

## 三、底层核心架构：两套概率完全物理隔离

> **核心逻辑：** 禁止合并混淆。前台 PK 娱乐 + 后台商用售卖，各自独立运转。

### 第一层：前台展示层（用户可见，人机独立 PK）

#### 3.1 人类投票体系

- **准入规则：** 手机号实名注册 + 设备硬件指纹绑定（Android 硬件指纹；iOS 因系统限制采用设备标识+注册时间戳绑定，风控等级等同）
- 单事件单设备终身仅可投票 **1 次**，禁止重复投票、改票
- 投票强制要求：选择【是/否】后，必须填写 **20~200 字**研判理由，空理由无法提交
- **人类概率计算公式：** 人类概率 = 有效选择「是」票数 ÷ 全部有效投票数；无效刷票账号不计入统计
- **用户排名结算：** 每位用户独立统计每场对错，按月生成预测正确率，划分 **青铜 / 白银 / 黄金 / 行业大神** 四档段位榜单
- **从业者认证（v2.0 优化）：** 采购、券商研究员、房产中介可上传资质获取"从业标签"，标签仅在前台展示用（标识"该用户来自 XX 行业"），**不与预测加权联动**，不计入任何排名加成。彻底拆除"持证专家预测=投资建议"的合规隐患

#### 3.2 AI 独立分析师体系

**核心原则：**

- ✅ 仅使用**国内完成网信办备案**的大模型（DeepSeek、Kimi、Qwen、智谱等）；**禁止接入 GPT、Claude 等境外模型**
- ✅ AI 仅做独立分析角色，禁止创建虚拟账号混入真人投票池
- ✅ AI 研判数据与投票数据**完全隔离**，互不污染

**AI 分级部署方案（v2.0 关键优化）：**

| 阶段 | 模型数量 | 模型选择 | 说明 |
|------|----------|----------|------|
| **一期 MVP** | 3 家 | DeepSeek Flash（主力）+ Kimi K2.6 + Qwen Flash | 先跑通核心链路，3 家对比足以体现 AI 内部分歧 |
| **二期扩充** | 6 家 | 新增智谱、豆包 Lite、百川等 | 会员量过 5000 后再扩，用会员收入覆盖新增算力 |

**运行规则：**

- 每日固定 **1 轮** 定时拉取精简资讯素材、执行 AI 研判
- 禁止用户点开页面实时重复调用 AI（杜绝单用户无限制触发 AI 算力）
- 冷门低热度事件 **3 天刷新一次** AI 数据
- 单款 AI 固定输出三项独立数据：判定结果（是/否）、0~100% 独立概率、简短研判依据
- 免费用户仅看精简短句，付费会员解锁长文深度解读
- 前台并列展示各 AI 的独立结果，额外算出 AI 阵营平均概率，与人类整体概率横向对比
- 自动打上标签：「人机一致」「人机对立」「AI 内部分歧」
- 每月统计各款模型正确率，决出**月度最强 AI 榜单**
- **Kimi K3 仅高端会员查看深度解读时按需调用**，日常批量运算不参与

### 第二层：后台商用融合概率（仅 B 端 API 可见）

> **前端用户完全不可见，不参与任何 PK 排名结算。** 仅后端单独封装加权计算函数。

#### 融合权重配置表（v2.0 优化）

| 板块 | 融合公式 | 投票 < 500 人时 |
|------|----------|-----------------|
| 大宗商品、财报 | AI 平均概率 × **85%** + 人类概率 × 15% | AI 95% + 人类 5% |
| 二手房、宏观经济 | AI 平均概率 × 70% + 人类概率 × 30% | AI 90% + 人类 10% |
| 电影票房 | AI 平均概率 × 55% + 人类概率 × 45% | AI 80% + 人类 20% |

#### 对外输出内容

- 每日融合概率数值
- 概率逐日时序曲线
- 历史脱敏事件数据集

→ **B 端核心售卖资产**

> 💡 **设计逻辑：** 人类投票是"调味料"和"传播载体"，不是平等的预测输入。大幅提升 AI 权重既保证 B 端数据质量，又不牺牲人机 PK 的话题传播力。少量人类票数（< 500 人）时 AI 权重进一步提升，防止散户噪音干扰。

## 四、事件全生命周期自动清算引擎

> 全程无人为干预，杜绝篡改。

### 事件创建必填 4 项参数（缺一不可）

1. 投票开启日期
2. 投票截止日期（必须早于官方数据发布日 **≥ 3 天**，到期永久关闭投票）
3. 官方数据源公开链接 + 官方固定发布日期
4. 二元结果量化判定阈值

### 清算执行步骤

1. 官方发布日自动拉取权威真实数据
2. 程序自动判定事件最终成立与否
3. 同步执行三项动作：
   - ① 用户积分自动奖惩结算
   - ② 人类 + 各款 AI 分别独立判定本场对错
   - ③ 本条事件所有投票、AI 数据永久封存归档
4. **官方数据延期发布 → 结算日期自动顺延**（v2.0 新增容错机制）
5. 所有操作日志留存 **≥ 3 年**，可供监管核查

1. 每日登录签到，连续签到积分递增
2. 任意预测投票猜对，按事件难度发放对应积分：

   | 难度等级 | 板块 | 积分 |
   |----------|------|------|
   | ★★★ | 财报 / 大宗商品 | 最高 |
   | ★★ | 宏观经济 / 二手房 | 中等 |
   | ★ | 电影票房 | 最低 |

3. 新手任务、行业资质认证一次性奖励积分

### 积分消耗两大用途

1. 参与投票扣除固定积分；免费普通用户每日投票积分有上限，付费会员无投票积分上限
2. 积分商城兑换平台虚拟权益：免积分投票券、理由临时置顶卡、往期 AI 复盘资料、少量会员体验天数碎片

### 🚫 绝对禁止功能（代码层面直接封锁接口）

- 积分提现
- 积分转账、玩家私下交易
- 积分折现兑换现金
- 红包抵扣

## 六、三大商业化变现体系（⚡ v2.0 调整开发顺序）

### 开发优先级重排

```
原版：B 端 API → 付费会员 → 积分商城
v2.0：付费会员 → B 端 API → 积分商城
```

**原因：** B 端销售周期通常 3~6 个月且需要历史案例数据支撑才能说服客户下单；C 端会员当月上线当月即可产生现金流 → 用 C 端收入养团队、积累案例数据，同步推进 B 端商务。

### 变现 1：C 端分级付费会员订阅（第一优先级开发）

> 付费仅解锁**功能权限**，绝不提升投票权重、不修改 AI 判断、不增加预测正确率。**PK 绝对公平。**

| 等级 | 核心权益 | 定价 |
|------|----------|------|
| **免费** | 基础投票、精简 AI 结论浏览、基础排行榜；每日投票积分受限、看不到 AI 完整深度解读 | 0 |
| **白银** | 不限投票次数、AI 完整简短解读、个人预测成绩单导出、去除基础广告、每日 1 次理由置顶 | 月/季/年卡 |
| **黄金** | 白银全部权益 + 专属行业测算工具、新事件提前 1 天预览、云端永久备份所有投票记录、月度行业 PDF 简报三选一、积分商城 8 折 | 月/季/年卡 |
| **钻石** | 黄金全部权益 + 全品类月度简报、个人 AI 对比准确率分析报告、新功能内测资格、专属客服、全局免广告 | 月/季/年卡 |

支持月/季/年卡，年卡折扣更大。

### 变现 2：B 端机构数据 API 售卖（第二优先级）

**售卖内容：** 后台加权商用概率时序数据、历史脱敏数据集、定制行业数据日报推送

**收费模式：**

- ① 按量单次调用计费
- ② 年度分级授权包（小微版 / 标准版 / 企业定制版）
- ③ 历史数据集一次性售卖 + 年度更新服务费

**强制附加：** 所有 API 返回数据附带免责声明——数据仅产业调研参考，不构成采购、投资、交易决策依据；**禁止对接配资、金融投机类客户**。

### 变现 3：积分商城衍生增值变现（三期可选开发）

- 仅虚拟道具兑换
- 可选上线「积分 + 小额现金补差」兑换定制行业手册、纪念周边
- **不允许纯现金单独购买实物**，避免电商化违规

## 七、AI Token 算力成本控制 + 熔断机制（⚡ v2.0 新增核心模块）

### 常规控本方案

1. **DeepSeek Flash** 极低单价承担全站 **70%** 基础 AI 算力
2. **Prompt 极致精简**，固定模板，限制输出字数：
   - 精简版（日常批量运算）：仅输出是/否、百分比概率、最多 3 条短句依据
   - 深度版（仅高端会员点开详情触发二次调用）：限定 150 字以内
3. **素材精简：** 每次仅抓取 3~5 条资讯摘要，禁止爬取网页全文，减少输入 Token
4. **调用频次管控：**
   - 常规事件每日 1 轮 AI 运算
   - 冷门事件 3 天一轮
   - 票房板块仅启用 2 款 AI 运算，其余关闭
5. **后台算力监控模块：**
   - 统计每款模型日消耗 Token 与成本
   - 设置单日算力预算阈值
   - 支持后台一键开关任意模型
6. **成本分摊逻辑：**
   - 基础算力由 B 端数据收入覆盖
   - 会员专属深度解读增量算力由会员收入覆盖
   - 免费用户几乎无额外算力成本

### 🔥 AI 算力成本熔断机制（v2.0 新增，必须开发落地）

```
月度熔断规则：
  当月 AI 总调用成本 > 当月总收入 × 120%
  → 触发紧急熔断：
      ├── 所有冷门事件 AI 调用暂停
      ├── 票房板块 AI 调用全部暂停
      ├── 仅保留大宗商品 + 财报板块的 DeepSeek Flash 基本运算
      └── 后台弹告警通知管理员，人工审核后手动解除或调整预算阈值

日报警规则：
  当日 AI 调用成本 > 日预算阈值 × 80%
  → 发送日预警报告，提前提醒管理员关注趋势

熔断日志留存 ≥ 3 年，可供审计追溯
```

## 八、数据抓取 & AI 内容生成 全合规法律约束

> Cursor 必须逐条校验规避风险。以下为硬性红线。

### 8.1 数据源分级抓取权限与风险管控

**① 政府公开数据（统计局、交易所、住建局）：**

- 允许低频率合规爬虫
- 单站点请求间隔 ≥ 60 秒，凌晨错峰抓取
- 优先校验 robots.txt 协议，禁止抓取屏蔽目录

**② 商业付费数据平台（卓创、我的钢铁、猫眼）：**

- 前期低成本方案：取消自动爬虫，运营每日手动录入首页免费极简公开数据
- 成熟期零风险方案：采购平台官方商用授权 API 调取数据
- 禁止：破解反爬、批量爬取付费数据、复刻对方数据售卖业务（构成不正当竞争侵权）

**③ 行业新闻素材：**

- 使用正规搜索引擎摘要 API 临时调取简短摘要
- AI 使用完毕立即销毁临时缓存，不在服务器长期存储新闻原文（规避著作权侵权）
- 禁止抓取整篇文章落地保存

### 8.2 AI 生成内容合规要求

1. 所有 AI 输出文案页面必须标注对应生成模型名称（符合深度合成内容管理规定）
2. 禁止使用外部抓取数据训练、微调自有 AI 模型，仅做单次实时研判使用
3. 页面不直接大面积转载 AI 原文内容，仅展示结论与精简逻辑（杜绝抄袭侵权）

### 8.3 爬虫强制开发规范

- 带正规可识别 UA、平台官方域名标识
- 禁止代理 IP、伪装身份绕过反爬
- 抓取日志、AI 调用日志留存 3 年以上，可供监管核查

### 8.4 全站通用免责硬性要求

全站底部永久固定免责声明：

> 平台所有用户投票观点、AI 分析、预测概率仅为产业信息调研参考，不构成任何投资、房产交易、原料采购决策建议。本平台无金融交易、博彩兑付相关功能。
