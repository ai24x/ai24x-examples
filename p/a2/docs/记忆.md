# AI24X 子项目02（股票查询助手）· 项目记忆

## 一句话目标
做一个“内部圈子免费体验”的股票查询页：登录 → 搜索标的 → 看K线/均线/信号；次数/VIP/邀请/数据代理后端化。

## 目录与入口
- `web/demo.html`：前端静态页入口（用 `scripts/serve.cmd` 本地启动更稳）
- `web/demo-standalone.html`：日常双击测试入口（直连公开源，不依赖后端）
- `api/server/`：后端 FastAPI（MVP：鉴权/配额/邀请/数据代理）
- `docs/AI24X股票查询助手规划1.01.md`：规划主文档

## 启动（本地）
- 前端：运行 `scripts/serve.cmd` → 打开 `http://127.0.0.1:8765/demo.html`
- 后端：`cd api/server` → `py -m venv .venv` → `pip install -r requirements.txt` → `uvicorn app.main:app --host 127.0.0.1 --port 8787 --reload`

## 关键约定（别忘）
- 前端不直连外部数据源：统一走 `/api/*`（后端代理）
- 多端适配：`web/demo.html` 已有基础响应式（480/640），但“iPad完美适配”验收条款需在规划补齐
- 前端风格：内置 3 套主题（深色/浅色/深蓝），从用户角度优先可读性与风险话术克制

## 最近变更
- 前端：隐藏“导出信号 JSON/CSV”按钮（逻辑保留，容器加 `hidden`）
- 前端：修正集合竞价/开盘前 qt 快照可能污染日线（09:30 前典型竞价态跳过合并）
- 板块支持：接入东方财富板块指数（`90.BKxxxx`）K 线，允许按中文名 / BK 码查询，并加入同花顺 88/886 六位码到东财 BK 的映射
  - `886078`（同花顺概念码）当前映射到东财 `90.BK0963`（商业航天 BK），但两者为**不同编制指数**，点位/量额不可逐字段对比
  - `881271`（同花顺行业码）映射到东财 `90.BK1238`（IT服务 BK）
- 前端：修复板块无 qt 时行情栏不更新、以及十字光标提示与 K 柱数据错位的问题（版本 v1.82 左右）

## 重要结论（板块/指数口径）
- 同一个“概念/板块名”在不同平台（同花顺 vs 东财 BK）不一定是同一条指数，K 线形态可能很像，但 OHLC/量额/点位会不同。
- 复权（fqt）不足以解释同花顺 2335 vs 东财 2645 这种整套 OHLC 量级差异：主要原因是**指数编制不同**。
