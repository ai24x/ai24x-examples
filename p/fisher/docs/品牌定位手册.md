# 渔悦 · 品牌定位手册 v3.0

> "如果活着不是为了快乐，那么长命百岁还有什么意义？"

---

## 一、核心理念

```
快乐至上 · JOY FIRST

不是"钓鱼游戏"，是"快乐生活方式"。
不是"虚拟经营"，是"你的第二人生渔场"。
不是"打发时间"，是"每一竿都是对平庸生活的反抗"。
```

## 二、品牌Slogan

| 场景 | Slogan |
|------|--------|
| 主Slogan | **一竿山海，快乐至上** |
| 副Slogan | 把生活，活成一场永不收竿的快乐 |
| 品牌标语 | 渔悦 · JOY FIRST |
| 开机文案 | 如果活着不是为了快乐，那么长命百岁还有什么意义？ |
| 分享文案 | 我在渔悦，钓的不是鱼，是快乐。 |

## 三、品牌调性

```
高端的、松弛的、有哲学感的

✅ 像Rimowa的质感，不是LV的浮夸
✅ 像Patagonia的户外精神，不是快速消费
✅ 像《老人与海》的孤独感，不是菜市场的热闹
✅ 像京都禅院的留白，不是夜店的霓虹

关键词：极简 · 留白 · 松弛 · 质感 · 自由 · 快乐
```

## 四、视觉方向

```
色彩：不是廉价的蓝绿，而是
  深海蓝 #1a2a3a  沙金色 #c4a35a  珍珠白 #f8f6f0
  暮光紫 #6b5b7b  松石绿 #5a8a7a

字体：优雅衬线体 + 极简无衬线
图标：线性图标，少即是多
留白：大量留白，呼吸感
摄影：大面积水面/天空/剪影，少露人脸
```

## 五、品牌故事

```
每个人都有一片海。
有人用来谋生，有人用来逃离。
而你，用来快乐。

渔悦不教你钓鱼。
只负责让你记起——
上一次纯粹快乐是什么时候。

打开渔悦。
抛一竿。
等。
你等的不是鱼。
是快乐自己上钩。

一竿山海，快乐至上。
```

## 六、对外定性（合规用）

- 产品类型：垂钓生活方式社区
- 核心功能：渔获记录 · 渔场管理 · 钓友社交
- 不定义：网络游戏、虚拟货币交易平台
