# 渔悦 · 合规经营方案

> 场景：一家网络公司，快速发展期，需低调平稳
> 原则：快跑不踩线，能做不声张

---

## 一、资质分类（决定生死的第一道坎）

### 当前产品定位策略

```
❌ 不要说：游戏 / 网游 / 手游
✅ 要说是：垂钓工具 / 社区应用 / 渔获管理SaaS

核心原则：
  不做版号申报 → 必须避开"网络游戏"定义
  不做支付牌照 → 必须避开"虚拟货币交易"
```

### 产品定性对照表

| 如果被定义为 | 需要什么 | 获批周期 | 风险 |
|-------------|---------|---------|------|
| 网络游戏 | 版号(ISBN号) | 1-2年 | 🔴 极高 |
| 付费应用 | ICP备案 | 1-2周 | 🟢 低 |
| 社区工具 | ICP备案 | 1-2周 | 🟢 低 |
| SaaS服务 | ICP备案 | 1-2周 | 🟢 低 |

**结论：我们是一款"垂钓社区与渔获管理工具"。**

---

## 二、功能设计合规清单

### 🔴 绝对不能做的

```
✗ 真实货币充值兑换虚拟币
✗ 虚拟币提现/兑换现金
✗ 赌博/抽奖/盲盒（未被批准的）
✗ UGC内容（用户发帖/评论）— 需要人工审核团队
✗ 实时对战/PVP（被认定为网络游戏特征）
✗ 虚拟资产RMT（真实货币交易）
```

### 🟡 谨慎做的

```
△ 虚拟币系统 → 改名"积分""金币"，强调"不可兑换现金"
△ 排行榜 → 不加现金奖励，仅虚拟荣誉
△ 社交功能 → 只用预置文案（预设句子选择），不开放自由输入
△ 付费功能 → 先上广告，后上会员/解锁钓场
```

### 🟢 放心做的

```
✓ 钓鱼模拟（纯工具属性）
✓ 渔获图鉴/百科
✓ 单机玩法 + 异步社交（好友渔获展示）
✓ 道具商店（虚拟币购买虚拟道具）
✓ 广告变现（穿山甲/优量汇）
✓ 会员订阅（功能解锁）
```

## 三、分阶段上线策略

### 阶段0：软启动（当前→1个月）

```
目标：跑通技术，验证留存，不引起关注
范围：微信小程序审核版（不加支付，不加社交）
用户：内部测试 + 100人内邀请制
域名：子域名低调部署

关键动作：
  ✅ 已完成：服务端闭环架构
  ⬜ 待做：小程序前端移植
  ⬜ 待做：加入"工具属性"功能（渔获记录/天气/潮汐）
  ⬜ 待做：备案域名 + HTTPS
```

### 阶段1：公测推广（1-3个月）

```
目标：获取1万DAU，验证商业模式
范围：小程序全量 + H5分享页
变现：信息流广告（不打扰核心玩法）

合规锚点：
  - 强调"渔获管理工具"
  - 所有交易用"积分"
  - 积分不可兑换现金
  - 用户协议明确写入

风险控制：
  - 不宣传"游戏"
  - 不做充值排名
  - 社交功能用预置文案
```

### 阶段2：商业化（3-6个月）

```
目标：月流水10万+，申请ICP许可证
范围：App（工具类上架）+ 小程序 + H5
变现：会员订阅 + 广告 + 道具

此时可做：
  - 会员解锁高级钓场
  - 渔场经营增值服务
  - 企业合作（渔具品牌赞助）

此时仍不可做：
  - 真实货币兑换虚拟币
  - 虚拟币提现
```

### 阶段3：资本化（6-12个月）

```
目标：拿到版号，正式转型"网络游戏"
前置条件：
  - 公司主体有游戏运营资质
  - 注册资本≥1000万
  - 有版号申请通道

拿到版号后：
  - 全面放开所有游戏功能
  - 真实充值系统
  - 赛事/竞拍
```

## 四、技术合规措施

### 1. 数据安全

```
✅ 数据库在国内服务器
✅ 用户数据加密存储
✅ 日志保留180天（网安法要求）
✅ 提供用户数据删除接口
⬜ 接入实名认证（规模上来后）
```

### 2. 内容安全

```
✅ 鱼种名称/描述全部预审（无敏感词）
✅ 社交功能：预置句子选择，不开放自由输入
✅ 投诉/举报入口
⬜ 接腾讯云/阿里云内容安全API（规模上来后）
```

### 3. 支付合规

```
阶段0-1: 无真实支付（仅虚拟币）
阶段2: 走微信支付→公司对公账户
  - 商品名：垂钓工具会员 / 渔获管理增值服务
  - 绝不出现"金币充值""游戏币"
```

## 五、紧急情况应对

| 情况 | 应对 |
|------|------|
| 被应用商店下架 | 修改描述为"工具"，提交复议 |
| 被认定为网络游戏 | 立即下架支付功能，改为免费工具 |
| 用户投诉虚拟币 | 用户协议明确"积分不可兑换现金" |
| 数据安全审查 | 提供完整的日志系统和用户数据删除流程 |
