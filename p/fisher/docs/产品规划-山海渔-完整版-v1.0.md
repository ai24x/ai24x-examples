## 三、工程架构（优化后摘要）

- **客户端**：微信**原生**（WXML / WXSS / JS）。  
- **真源**：自建 **`fisher-api`** + **PostgreSQL**；经济、冷却、渔获、交易均在服务端校验与落库。  
- **域名（推荐）**：`fisher.ai24x.com`（门面/H5）、`fisher-api.ai24x.com`（API）、`fisher-admin.ai24x.com`（管理）；TLS 推荐一张 **`*.ai24x.com`**。  
- **微信云开发**：可选，不作长期唯一真源。  
- **12～24 个月 H5/App**：先 **API 契约稳定**；再决定是否引入 Taro 等跨端框架。  
- **与主站统一身份**：**默认不做**（见 DEC-0009）；若未来要「全站一号」再对齐 `DEC-0007` 模式，游戏数据仍在 Fisher。

## 四、游戏核心定位与产品逻辑

### 4.1 游戏简介

《山海渔》是集 **休闲垂钓、渔市动态经商、资产长线养成、真人钓友实景社交** 于一体的轻量化微信小程序（首期），主打低门槛、碎片化、治愈慢节奏。玩家从新手钓手起步，通过垂钓获鱼、囤货套利、升级装备、解锁高阶钓场、购置载具，逐步成长；节奏偏解压与经营成就感，避免重度氪金与内卷叙事。

### 4.2 目标用户

25～55 岁男性为主、现实钓鱼爱好者、模拟经营玩家、轻度解压玩家、海外休闲垂钓爱好者（长期）。

### 4.3 核心玩法闭环

垂钓渔获 → 仓库囤货 → 动态渔市买卖获利 → 装备 / 钓场 / 载具升级 → 高阶海域探索 → 长线资产积累 → 高留存养成。

### 4.4 核心差异化（表述建议）

- **钓鱼 + 渔市经商** 双核心（细分赛道）。  
- **实景打卡类社交**（需按微信平台内容规范设计审核与成本）。  
- **轻量化交互 + 治愈氛围**；适配碎片时间。  
- **赛季 + 转生 + 离线收益** 等解决后期疲软（数值需单独调表）。  
- 竞品话术避免绝对化；以「差异化」替代「市面绝无」类不可证伪表述。

## 五、开发工具与痛点方案（更新版）

### 5.1 工具组合

- **代码 / 动效 / BUG**：Cursor + 微信开发者工具。  
- **后端真源**：自建 `fisher-api`（与「仅云开发」方案相比，更适配 H5/App 与自建管理端）。  
- **美术**：AI 批量出图（如豆包等），统一提示词前缀。

### 5.2 痛点对策（保留原意 + 工程补充）

| 痛点 | 方案 |
|------|------|
| 小动画 | CSS 轻动效为主；波纹等用 **`transform: scale()`**，避免部分基础库对单独 `scale` 动画兼容问题。 |
| 无美术 | 固定画风前缀 + 批量出透明 PNG；控制包体与尺寸。 |
| 不会写代码 | AI 分模块生成；**经济逻辑只放服务端**，客户端薄。 |
| 怕崩盘 | 小步迭代：钓鱼核心 → 渔市 → 养成 → 社交 → 变现。 |

### 5.3 Cursor 协作话术（可直接复用）

- 「我是微信小程序原生项目，用 WXML+WXSS+JS，帮我写【功能：钓鱼 / 渔市 / 仓库】完整代码，要求轻量化、治愈风格、带基础动效，注释清晰。」  
- 「帮我写微信小程序 WXSS 动效，实现【抛竿波纹 / 浮漂晃动 / 咬钩提醒】，用 transform，适配手机。」  
- 「这段小程序报错 / 样式错乱，完整修复并保留功能。」

## 八、核心系统设计

### 8.1 垂钓系统

- **操作**：点击抛竿 → 等待咬钩 → 点击拉杆 → 获得渔获（单手可玩）。  
- **冷却**：普通钓场 8 秒/竿，高级钓场 5 秒/竿（**由服务端校验**，防改包）。  
- **反馈**：浮漂微动、咬钩震动、闪光、上鱼动画。  
- **鱼种**：15 种基础鱼种；分淡水（金币）、近海（积分）、稀有变异（积分）；具体见第十章数值表。

### 8.2 渔市经营系统

- **货币**：金币（基础）、积分（高阶）；兑换比例 **100 金币 = 1 积分**（需防套利，配合动态行情与回收口设计）。  
- **动态行情**：每小时鱼价 ±5% 随机波动（可服务端定时任务写快照）。  
- **交易**：单条出售、批量出售、仓库扩容。

### 8.3 养成系统

- **鱼竿**：新手竹竿（白，免费）→ 精工手竿（绿）→ 碳素钓竿（蓝）；数值见第十章。  
- **钓场解锁**：见第十章。  
- **载具线**：小木船 → 运动快艇 → 豪华游艇 → 远洋游轮 → 海上私人庄园（长线，分期开放）。

### 8.4 社交系统

- 基础：世界聊天、排行榜、好友互赠（分期、合规优先）。  
- 核心：实景图片打卡、同城钓友、点赞评论、打卡 buff（须 **审核 + 举报 + 关键词** 与成本评估）。

### 8.5 合规风控

- 无现金提现、无违规抽奖赌博表述与机制。  
- UGC 图片人工初审 + 关键词屏蔽。  
- 控制产出与货币回收，防止通胀。

## 十、轻量化动效（WXSS 推荐写法）

全局按钮回弹、淡入、浮漂、咬钩闪烁、金币上浮等保持原案；**水面波纹**建议用 `transform: scale()` 实现扩散，避免仅用 `scale:` 属性在部分环境下不生效。

示例（波纹核心思路）：

```css
.wave-ring {
  animation: waveRing 1s ease-out forwards;
}
@keyframes waveRing {
  0%   { opacity: 1; transform: scale(0.2); }
  100% { opacity: 0; transform: scale(1.5); }
}
```

## 十二、微信小程序工程说明（避免复制损坏片段）

早期文档中的 WXML 示例存在截断与标签未闭合问题，**不可直接粘贴**。正确做法是：在开发者工具新建小程序后，按标准 `app.json` / `pages/index/*` 结构创建文件，将业务逻辑改为 **`wx.request` 调用 `fisher-api`**，本地仅用 `wx.storage` 做缓存而非经济真源。

最小 `app.json` 示例：

```json
{
  "pages": ["pages/index/index"],
  "window": {
    "backgroundTextStyle": "light",
    "navigationBarTitleText": "山海渔",
    "navigationBarBackgroundColor": "#f0f7f4",
    "navigationBarTextStyle": "black"
  },
  "style": "v2",
  "sitemapLocation": "sitemap.json"
}
```

引流版仅将 `navigationBarTitleText` 与首页 Slogan 改为引流文案即可（其余复用同工程）。
