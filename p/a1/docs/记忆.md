# AI24X 子项目 · AI行情官 a1 · 项目记忆

> **2026-07-16**：完整现行记忆见仓库根目录 `memory/projects/a1.md` 与 `memory/daily/2026-07-16.md`。下文端口/入口以现行为准（本地 web **18001** / api **18011**）。

## 一句话目标
做一个可运营的 A股行情标注工具：登录 → 搜索标的 → 看K线/均线/信号；次数/VIP/邀请/数据代理后端化。对外叙事收敛为「数据可视化」。

## 目录与入口
- `web/demo.html`：行情主产品
- `web/index.html`：注册登录入口
- `web/account.html`：配额/VIP/邀请
- `api/server/`：FastAPI（鉴权/配额/邀请/支付/信号/数据代理）
- 同花顺公式：`docs/formulas/1~8-*.txt`

## 启动（本地，现行）
- 前端：PM2 `a1-web-18001` → `http://127.0.0.1:18001/`
- 后端：PM2 `a1-api-18011` → `http://127.0.0.1:18011/`

## 关键约定（别忘）
- 前端不直连外部数据源：统一走 `/api/*`（后端代理）
- 板块：BK优先；THS与BK同名概念**不是同一指数**，点位/量额不可对比
- 信号缓存版本 v4；部署注意清 `__pycache__`
- 推送须用户确认后双推 gitee + origin

## 最近变更（摘要至 2026-07）
- 搜索 BK优先/THS第二；本地信号兜底；分享短链 content-first；SEO index；合规去算法化文案
- 推广：同花顺指标广场 + QQ群 + 客户经理三聚焦

## 重要结论（板块/指数口径）
- 同一个“概念/板块名”在不同平台（同花顺 vs 东财 BK）不一定是同一条指数，K 线形态可能很像，但 OHLC/量额/点位会不同。
- 复权（fqt）不足以解释整套 OHLC 量级差异：主要原因是**指数编制不同**。
