# 客服风控与话术红线 SOP 1.0

> 目的：统一客服/代理对外口径，守住合规红线，规范投诉与风控处置，全程留档。
> 配套：《产品合规红线清单》《种子群与高净值客户运营SOP》、三份合作协议。

---

## 一、响应时效与渠道

- 渠道：公众号/客服微信/群内 @/后台工单，统一入口，避免散落。
- 时效：工作日 9:00-21:00 内，普通咨询 2 小时内响应，投诉 4 小时内响应并登记；非工作时间次日优先处理。
- 值班：主理人 + 1 名客服，群内 @ 与私聊都有人接。

## 二、标准话术要点（可讲）

- 产品定位：行情数据可视化工具，帮用户看数据，不给买卖建议。
- 免费/收费差异：额度、数据源优先级、高峰稳定性、技术支持。
- 退款口径：虚拟数字服务开通后原则上不支持退款；因平台原因长期不可用，登记后按规则协商处理。
- 数据口径：数据来自第三方公开渠道，可能存在延迟或误差，仅供参考。

## 三、红线话术（禁用，违者警告→清退）

- 收益类：「稳赚」「必涨」「翻倍」「保证收益」「跟我买」。
- 建议类：「现在可以买/卖」「目标价」「马上要涨」「别追高」。
- 代客类：「帮你操作」「代你理财」「资金交给我」。
- 拉人头类：「拉 3 个人返你多少」「层级提成」「发展下线」。
- 预测类：「明天一定涨」「这波行情能到 X 点」。

## 四、风控事件处置

| 事件 | 处置 | 记录 |
| --- | --- | --- |
| 批量注册/养号 | 冻结账号、人工复核 | 记录 IP/设备/邀请关系 |
| 自买自返/刷量 | 冲减返点、冻结相关订单 | 保留订单与支付流水 |
| 违规宣传（代理） | 警告→暂停返点→解除合作 | 截图证据存档 |
| 订单异常（大额/高频） | 触发人工审核后再放行 | 审核结论存档 |
| 投诉/监管问询 | 先停相关功能，保留全部记录，联系律师后回应 | 全程留痕，不自行删改 |

## 五、投诉处理五步

1. 登记：时间、渠道、诉求、证据。
2. 安抚：先听完整，不辩解，承诺时限。
3. 核实：查订单/日志/录音。
4. 答复：按规则给出方案（退款/补偿权益/解释说明）。
5. 回访：24 小时后回访确认满意，归档。

## 六、交接与留档

- 每次会话结束后 1 小时内填客服记录表（客户、问题、结论）。
- 每周汇总高频问题 → 更新 FAQ → 反哺产品优化。
- 所有与钱、承诺、投诉相关的沟通，微信/群聊截图存档，保留至少 2 年。
