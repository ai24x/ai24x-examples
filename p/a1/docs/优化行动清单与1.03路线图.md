## 一、已完成（1.02 基线，勿回退）

- 安全：密码≥8位、OTP 错5次作废、登录/发码限流、prod 关闭 /docs、JWT 强随机 + 双密钥平滑过渡。
- 登录：`AI24X_ADMIN_KEY` + 白名单手机短信 OTP（腾讯云直发）。
- 脱钩：不再依赖 Token 接口平台，`identity_api_base` 已清空。
- 合规：伙伴计划 `partner_payout_mode=rewards`；用户协议/隐私政策上线；三份合作协议与合规红线清单落地。
- 定价：体验 8.8 / 月卡 888 / 年卡 8888 / 成长 5000 / 合作伙伴 10000（本地 DB 已生效）。
- 增长：金银铜自动晋级 + 城市合伙人签约试点 + 阶梯返点 15/20/25%。

## 三、P1（1.03 目标，需要少量投入）

- **Redis 限流**：当前进程内限流在多进程/重启后会失效，改用 Redis 做登录/发码/接口限流，全局生效。
- **数据源容灾演练**：K 线主源 + 新浪备用 + TuShare 双源切换，做一次模拟主源故障演练。
- **监控告警**：服务存活、磁盘、日志 ERROR、订单异常（大额/高频）接入钉钉/微信群机器人。
- **数据源授权确认**：核对 TuShare/新浪行情数据再分发条款，保留授权证据（页面已标来源）。
- **等保二级自评**：对照《网络安全等级保护基本要求》做一次差距自查，形成记录。

## 四、P2（有实力后办理，见红线清单第二节）

- ICP 经营许可证 → 等保测评备案 → 金融信息服务备案/登记 → 算法备案/生成式AI备案（按需）。
- 日志集中与审计、Redis 上云、数据库高可用。

## 五、持续运营红线（每季度自查）

- 产品功能是否触碰「荐股软件」四条功能（具体品种建议/买卖时机/涨跌预测/模型分析意见）。
- 话术与物料是否出现收益承诺、拉人头、代客理财。
- 客服/代理是否执行话术红线与留档。
- 协议、隐私政策、免责声明版本是否与当前产品一致。
