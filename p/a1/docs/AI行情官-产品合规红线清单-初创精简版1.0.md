# AI行情官 产品合规红线清单（初创精简版 1.0）

> 定位一句话：行情数据可视化工具。只展示、不推荐、不预测、不代客、不承诺。
> 配套文件：《用户协议》web/terms.html、《隐私政策》web/privacy.html、docs/协议/ 下三份合作协议。

---

## 一、不可触碰的红线（碰了无法补办，可能涉刑/巨额处罚）

1. **不出具针对具体证券品种的投资意见**
   不得提供：具体品种选择建议、买卖时机建议、价格走势预测、依据公式/模型给出的具体品种分析意见。
   （依据：证监会《关于加强对利用"荐股软件"从事证券投资咨询业务监管的暂行规定》2012年40号公告）
2. **不以发展人员/层级计酬，不收入门费**
   推广返佣只能挂钩「实际支付成功订单」，严禁拉人头、多级返利、变相传销。
3. **不承诺收益、不保证盈亏、不虚假宣传**
   所有页面与话术不得出现"稳赚""翻倍""内部消息""百分百"等表述。
4. **不代客理财、不代客操盘、不代收客户资金**
   资金只走平台正规支付渠道，不碰客户账户与资金管理。
5. **不虚构市场事件/新闻**
   行情数据须注明来源，不得编造利好利空消息（《金融信息服务管理规定》第八条）。

## 二、可以"先精简、后补办"的资质

| 事项 | 说明 | 建议时点 |
| --- | --- | --- |
| ICP 经营许可证 | 在线收费属经营性互联网信息服务 | 有盈利后办理 |
| 网络安全等级保护（二级起） | 行情数据处理平台建议测评备案 | 有实力后办理 |
| 金融信息服务备案/登记 | 视属地网信办要求 | 商用后主动沟通 |
| 算法备案/生成式AI备案 | 仅当 AI 功能公开向公众提供生成式内容时触发 | 上 AI 建议类功能前必须先办 |

## 三、现在就要做（零/低成本，立即执行）

1. 页面与协议底部标注**数据来源**（如"行情数据来自第三方公开渠道，可能存在延迟"）。
2. 保留**客服/投诉入口**，能收能回，记录留档。
3. 用户协议、隐私政策、合作协议、免责声明**全部留档保存**（含各版本截图），形成证据链。
4. **话术红线培训**：客服、推广、代理统一禁用荐股/收益话术，违规一次警告、两次清退。
5. 每次发版保留**功能截图与版本说明**，证明产品定位始终是数据工具。

## 四、触发"先停再评估"的情形

- 计划上线 AI 生成"该不该买/能涨到多少/何时买卖"等建议 → **先停**，律师评估 + 资质到位后再上。
- 计划开放现金返佣给非签约城市合伙人 → **先停**，评估返佣合规性。
- 收到监管问询/投诉 → **立即停止相关功能**，保留记录，联系律师，不要自行删改证据。
