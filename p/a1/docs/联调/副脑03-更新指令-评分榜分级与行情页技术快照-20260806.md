## 一、本包内容

| 模块 | 内容 |
|------|------|
| 配置 | `config.py`：新增 `wl_score_max_free`（普通注册会员评分榜统计上限，默认 20）、`wl_score_max_vip`（VIP，默认 100），可用 `AI24X_WL_SCORE_MAX_FREE/VIP` 环境变量或后台系统参数覆盖 |
| 数据库 | `db.py`：新增 `watchlist_score_caps()`（读 admin_config，留空回退 .env 默认） |
| 后端接口 | `main.py`：`/api/watchlist/scores` 返回分级信息（is_vip / score_max / vip_cap / watchlist_total / truncated），超出上限只统计前 N 只；新增 `/api/quote/snapshot`（单票技术指标快照：综合分/关键信号/风险 + 大盘环境，与评分榜同口径，按自然日同票去重不重复扣次） |
| 后台 | `admin_ui.py`：系统参数新增「评分榜统计上限·普通会员 / VIP」两个可填项，保存即生效 |
| 自选评分榜 | `web/watchscore.html`：多票时改为固定表头滚动表格 + 强弱分组（强势≥70 / 中性45-69 / 弱势<45，弱势默认折叠可展开）+ 筛选按钮 + 搜索 + 表头排序；显示统计上限提示（超出时提示开通 VIP 可统计更多，链接直达会员页） |
| 行情页 | `web/demo.html`：单票查询成功后，行情栏下方新增「技术指标快照」卡片（综合分大数字 + 偏强/中性/偏弱状态 + 技术信号标签 + 风险提示 + 大盘环境行 + 合规免责），5 分钟内存缓存，未登录不显示 |

## 二、执行（PowerShell · 整段复制给 OpenClaw）

```powershell
$ErrorActionPreference = 'Stop'
$PSNativeCommandUseErrorActionPreference = $false   # git 失败不直接中断（PS7.3+ Stop 会抛错），改由 $? 判断
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8   # 防 git 中文输出乱码，Select-String 才能匹配
$repo = 'C:\ai24x01'

Write-Host '=== 1/3 拉码 ===' -ForegroundColor Cyan
Set-Location $repo
git checkout master
git pull origin master
if (-not $?) { Write-Host '!! 拉码失败（origin master），先别继续，回报 git pull 输出' -ForegroundColor Red; exit 1 }
git log -1 --oneline
if (-not (git log -1 --oneline | Select-String '技术快照')) { Write-Host '!! 未拉到目标提交（应含「技术快照」），先别继续，回报 git log -1' -ForegroundColor Red; exit 1 }

Write-Host '=== 2/3 重启后端（db.py + main.py + config.py 改动，必须重启 AI24X-a1-api）===' -ForegroundColor Cyan
if (Get-Service AI24X-a1-api -ErrorAction SilentlyContinue) { Restart-Service AI24X-a1-api } else { Write-Host '!! 未找到 AI24X-a1-api 服务' -ForegroundColor Red; exit 1 }
Start-Sleep -Seconds 4

Write-Host '=== 3/3 验收 ===' -ForegroundColor Cyan
try { $r = Invoke-WebRequest 'http://127.0.0.1:8001/health' -UseBasicParsing -TimeoutSec 5; Write-Host "health(8001)=$($r.StatusCode) $($r.Content)" } catch { Write-Host "health(8001) FAIL $($_.Exception.Message)" -ForegroundColor Red }
try { $r = Invoke-WebRequest 'http://127.0.0.1:18011/health' -UseBasicParsing -TimeoutSec 5; Write-Host "health(18011)=$($r.StatusCode) $($r.Content)" } catch { Write-Host "health(18011) FAIL $($_.Exception.Message)" -ForegroundColor Red }
try { $r = Invoke-WebRequest 'https://a.ai24x.com/demo.html' -UseBasicParsing -TimeoutSec 10; $has = $r.Content.Contains('id="quote-snap"'); Write-Host "demo页面=$($r.StatusCode) 技术快照元素=$has（True=已生效；浏览器 Ctrl+F5 刷新）" } catch { Write-Host "demo页面 FAIL $($_.Exception.Message)" -ForegroundColor Red }
try { $r = Invoke-WebRequest 'https://a.ai24x.com/watchscore.html' -UseBasicParsing -TimeoutSec 10; $has = $r.Content.Contains('wl-group-row'); Write-Host "评分榜页面=$($r.StatusCode) 分组元素=$has（True=已生效）" } catch { Write-Host "评分榜页面 FAIL $($_.Exception.Message)" -ForegroundColor Red }
Write-Host '=== 完成。回执要求：git log -1、health、demo/评分榜页面 has 结果 ===' -ForegroundColor Green
```

## 三、上线后人工动作

- 无新增必配环境变量；后台「系统参数」可随时调整评分榜统计上限（普通会员 / VIP），留空即用默认 20 / 100。
- 行情页技术快照仅登录用户可见；扣次与行情日线同配额池，按自然日同票去重，不重复扣次。
- 若后台仍显示旧套餐默认值：重启后进入后台系统参数页 Ctrl+F5 刷新一次。
