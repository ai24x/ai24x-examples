# 副脑03 更新指令 · 用户中心「自选股」与「自选评分榜」（含行情页收藏服务端同步）

> 发令：2026-08-06
> 进程管理：NSSM / Windows 服务（禁止 pm2）
> 前置：主脑本机已验通并推 Gitee（origin 与 gitee 两远端均已到目标提交，提交信息含「自选评分榜」），拉码后 `git log -1` 应匹配「自选评分榜」

## 一、本包内容

| 模块 | 内容 |
|------|------|
| 数据库 | `db.py`：新增 `watchlist` 表（user_id+secid 复合主键，PG/SQLite 通用，`CREATE TABLE IF NOT EXISTS` 幂等）+ `watchlist_add/remove/list` 三函数 |
| 技术评分 | `scoring.py`（新文件）：技术面量化评分 0-100（MACD量能柱25 / 均线底部金叉20 / 量能确认15 / 异动回踩15 / 位置安全边际10 / 趋势环境10，基准+5封顶100），含 ST/退市、连续下杀、多次跌停、破位下行、高位滞涨、量能低迷等风险标记 |
| 后端接口 | `main.py`：`GET/POST /api/watchlist`、`POST /api/watchlist/remove`、`GET /api/watchlist/scores`（逐票拉日线120根→评分→降序；按自然日同票去重扣次；4 个接口均加防刷限流） |
| 用户中心 | `web/account.html`：新增「自选股」Tab（会员 / 自选股 / 伙伴计划），支持搜索建议添加、列表移除、「生成评分榜」表格（评分/信号标签/风险提示），默认仍进「会员」 |
| 行情页 | `web/demo.html`：收藏/自选从 localStorage 升级为登录后服务端同步（页面加载合并、增删即时同步，未登录仍走本地） |

## 二、执行（PowerShell · 整段复制给 OpenClaw）

```powershell
$ErrorActionPreference = 'Stop'
$repo = 'C:\ai24x01'

Write-Host '=== 1/3 拉码 ===' -ForegroundColor Cyan
Set-Location $repo
git checkout master
git pull gitee master
if (-not $?) { git pull origin master }
git log -1 --oneline
if (-not (git log -1 --oneline | Select-String '自选评分榜')) { Write-Host '!! 未拉到目标提交（应含「自选评分榜」），先别继续，回报 git log -1' -ForegroundColor Red; exit 1 }

if (Get-Service AI24X-a1-api -ErrorAction SilentlyContinue) { Restart-Service AI24X-a1-api } else { Write-Host '!! 未找到 AI24X-a1-api 服务' -ForegroundColor Red; exit 1 }
Start-Sleep -Seconds 4

Write-Host '=== 3/3 验收 ===' -ForegroundColor Cyan
try { $r = Invoke-WebRequest 'http://127.0.0.1:8001/health' -UseBasicParsing -TimeoutSec 5; Write-Host "health(8001)=$($r.StatusCode) $($r.Content)" } catch { Write-Host "health(8001) FAIL $($_.Exception.Message)" -ForegroundColor Red }

Write-Host '=== 完成。回执要求：git log -1、health、account/demo 页面 has 结果 ===' -ForegroundColor Green
```
