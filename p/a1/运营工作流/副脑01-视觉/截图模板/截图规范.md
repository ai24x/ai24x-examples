# 截图规范（副脑01 执行）

## 统一要求

| 项目 | 规范 |
|------|------|
| 分辨率 | 1200×800px |
| 主题 | 深色主题（黑底/深灰底） |
| 水印 | 右下角半透明 "AI行情官 · 灯塔版" |
| 格式 | PNG |
| 文件命名 | YYYY-MM-DD-标的-类型.png |
| 归档 | `副脑01-视觉/今日配图/YYYY-MM-DD/` |

## 截图内容

每张K线截图必须包含：
1. **K线主体**（日K/周K，视需求而定）
2. **信号标注**（B/D/小底/底/顶/追，用文字标注在对应位置）
3. **均线**（MA14蓝色、MA28红色、MA57黄色）
4. **信号图例**（右下角或右上角，列出当前信号类型）
5. **水印**（半透明）

## K线截图类型

| 类型 | 用途 | 说明 |
|------|------|------|
| 日线信号 | 日常信号帖 | 180天K线+信号标注 |
| 周线信号 | 周度分析帖 | 2年K线+信号标注 |
| 多周期对比 | 深度方法帖 | 日线+周线上下排列 |

## 每日启动指令

每天副脑01收到主脑 `今日视觉需求.md` 后：
1. 打开 a.ai24x.com → 搜索标的
2. 截图K线（深色主题）
3. 标注信号位置（文字标注）
4. 添加水印
5. 按日期归档到 `今日配图/`
