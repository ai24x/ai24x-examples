## 五、锁定 2 大板块

### 5.1 PCB（印制电路板）—— 资金主攻 + 技术最强，概率最高

**为什么是它（逻辑）**：
- 事件催化：DeepSeek API 涨价 → AI 算力资本开支上行 → 服务器/交换机/加速卡对高多层板、HDI、载板需求提升（AI 服务器 PCB 用量为传统服务器数倍），**AI 硬件载体最直接受益**；
- 资金主攻：行业 5 日主力净流入电子 **+582.7 亿（全市场第1）**、印制电路板 **+252.4 亿**、PCB 概念今日 **+64.6 亿（第2）**——持续性最好；
- 业绩确认：概念端"2026中报预增"5日净流入第三，PCB 龙头普遍有业绩兑现能力。

**为什么是它（数据确认）**：
- 板块成分股评分均值 **64.7**、健康率 **5/6**，为科技板块最强；
- 位置 32~38% 低位、MACD 刚翻红 1~2 天、站上 MA20、均线金叉——**典型的"底部右侧刚启动"结构，而非高位接力**；
- 龙头梯队：深南电路 69.4 / 生益科技 69.4 / 景旺电子涨停 62.0 / 鹏鼎控股 63.8 / 沪电股份 63.4 / 胜宏科技 60.0。

**操作参考**：
- 关注龙头回踩 MA10/MA20 不破的低吸机会（板块位置低，可分批建仓）；
- 已持有者沿 5 日线持有，破 MA20 减仓；
- 板块内优先"MACD 翻红 + 站上 MA20"且未大涨的补涨品种，回避 5 日涨幅过大的追高。

### 5.2 煤炭 —— 确定性主线（中报预增 + 高股息 + 今日领涨）

**为什么是它（逻辑）**：
- 今日行业涨幅第 1（+4.88%），龙头兖矿能源 +9.98%、潞安环能 +10.03% 涨停——**资金当日主攻实证**；
- 2026 中报预增确定性：煤价维持高位 + 成本优化，业绩确定性强，概念端"2026中报预增"5日净流入 +657.8 亿印证资金偏好；
- 高股息防御属性：大盘空转多初期，攻守兼备的资金会配置"业绩确定 + 分红高"的顺周期。

**为什么是它（数据确认）**：
- 板块评分均值 **65.6**（9 板块中最高）、健康率 4/6；
- 龙头明细：兖矿能源 86.4 / 潞安环能 86.4 / 山煤国际 72.2 / 中煤能源 60.0——**领涨龙头评分普遍 70+**；
- 山煤国际放量 2.48、MACD 翻红第 24 天（趋势 + 爆发共振）。

**操作参考**：
- 今日集体大涨后**不追高**，等回踩 MA5/MA10 缩量企稳再介入；
- 龙头选择：兖矿/潞安（弹性）＋ 山煤/中煤（趋势）；
- 注意多数个股当日风险标签含"量价背离"——大涨后 1~2 日防分歧。

### 5.3 有色（稀土/铜铝）—— 同逻辑延伸，列入观察

- 北方稀土 66.2（均线金叉×3，趋势最强）、紫金矿业 62.8（但位置 88% 偏高、长上影滞涨）、云铝/神火 47% 中位健康；
- 5 日主力净流入 +181.8 亿，趋势健康但**位置普遍高于 PCB/煤炭**；
- **定位**：若 PCB 短线涨幅过大，资金可能轮动至有色（尤其稀土），可作为主线二线备选，不作为首选。
