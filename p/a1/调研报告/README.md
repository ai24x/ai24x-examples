# AI行情官 · A股调研报告库

集中存放 A股调研/研究报告，分门别类，便于查阅与分享。

## 分类说明
| 目录 | 用途 |
|---|---|
| `01-事件驱动研究` | 突发政策/公告/涨价/技术变革等事件刺激下的受益标的研判（如 DeepSeek API 涨价） |
| `02-行业研究` | 行业景气度、产业链、供需格局、政策面分析 |
| `03-个股深度研究` | 单只股票的深度基本面 + 技术面分析 |
| `04-技术面与量价` | 形态、指标、量价关系、资金面专项分析 |
| `05-复盘与交易日志` | 每日/每周复盘、交易计划与执行总结 |
| `99-模板` | 报告模板与可复用工具 |

## 命名与归档规范
1. 每篇报告一个独立文件夹：`YYYY-MM-DD-主题`（例如 `2026-08-06-DeepSeek涨价受益标的`）；
2. 主报告文件名：`主题_YYYY-MM-DD.md`；
3. 配图与报告同级存放，报告中用**相对路径**引用（如 `![图](./chart_xxx.png)`），保证整包可迁移分享；
4. 原始行情数据放 `数据/`，图表脚本等可复用工具放 `工具/`；
5. 新报告按题材归入对应分类目录，拿不准的先放 `01-事件驱动研究`，之后可移动。

## 分享方式（推荐用"分享版"）
- **微信/邮件快速分享**：用 `分享版\*.html`（单文件、图片已内嵌 base64、任何浏览器双击即看，约 0.5MB）；
- **正式场合**：用 `分享版\*.pdf`（A4 排版、可打印、可转发，约 0.7MB）；
- **编辑/二次加工**：直接改 md，改完运行报告文件夹 `工具\make_share.py` 一键重新生成 HTML 与 PDF；
- 整体打包：直接压缩报告文件夹（md + 图片 + 数据 + 分享版）也可；
- 本库内所有报告均已声明"不构成投资建议"。

## 报告工具（每篇报告文件夹内 `工具/`）
| 脚本 | 用途 |
|---|---|
| `make_share.py` | md → 单文件分享版 HTML（自动内嵌 K线图与 `分享卡_*.png`），再用 Edge 无头转 PDF |
| `make_share_card.js` | 浏览器自动化生成 AI行情官「信号分享卡」（K线信号+技术快照评分；评分/信号需登录态） |
| `chart_gen.py` | 用 `数据/*.json` 生成日K线图（simhei 字体防乱码） |
| `ocr_check.py` | RapidOCR 校验图表中文渲染 |

> 分享卡登录态：运行 `make_share_card.js` 前，将登录 token 放入环境变量 `AI24X_TOKEN` 或写入 `工具/token.txt`（token 为页面 localStorage 键 `ai24x_a_token` 的值，登录 a.ai24x.com 后可从浏览器 DevTools 复制）。游客模式每日次数有限且不含评分。
