OpenClaw技能开发：从零创建自定义AI技能

阅读时间：30分钟 作者：AI24X团队 发布日期：2026-03-21 分类：OpenClaw 难度：中级

什么是OpenClaw技能？

OpenClaw技能是扩展AI助手功能的核心模块。每个技能都是一个独立的插件，可以为AI助手添加新的能力，如搜索网页、读取文件、计算数学等。

技能开发基础

技能文件结构

一个标准的OpenClaw技能包含以下文件：

my-skill/
├── SKILL.md          # 技能说明文档
├── index.js          # 技能主逻辑
├── config.json       # 技能配置
├── package.json      # 依赖管理
└── README.md         # 使用说明

创建新技能

使用OpenClaw CLI创建新技能：

# 创建新技能目录
mkdir my-weather-skill
cd my-weather-skill

# 初始化技能
openclaw skill init --name="weather-skill" --description="天气查询技能"

技能开发实战

1. 创建天气查询技能

创建 index.js 文件：

// 天气查询技能
module.exports = {
    name: 'weather',
    description: '查询城市天气',
    
    // 技能配置
    config: {
        apiKey: process.env.WEATHER_API_KEY,
        baseUrl: 'https://api.weather.com'
    },
    
    // 技能执行函数
    execute: async function(params, context) {
        const { city } = params;
        
        if (!city) {
            return { error: '请提供城市名称' };
        }
        
        try {
            // 调用天气API
            const response = await fetch(`${this.config.baseUrl}/weather?city=${city}&key=${this.config.apiKey}`);
            const data = await response.json();
            
            return {
                city: data.city,
                temperature: data.temp,
                condition: data.condition,
                humidity: data.humidity,
                windSpeed: data.wind_speed
            };
        } catch (error) {
            return { error: '天气查询失败: ' + error.message };
        }
    },
    
    // 技能参数定义
    parameters: {
        city: {
            type: 'string',
            description: '城市名称',
            required: true
        }
    }
};

2. 配置技能

创建 config.json 文件：

{
    "name": "weather-skill",
    "version": "1.0.0",
    "description": "OpenClaw天气查询技能",
    "author": "AI24X团队",
    "license": "MIT",
    "dependencies": {
        "node-fetch": "^3.0.0"
    },
    "openclaw": {
        "minVersion": "1.0.0",
        "category": "utility",
        "tags": ["weather", "api", "utility"]
    }
}

3. 编写技能文档

创建 SKILL.md 文件：

# 天气查询技能

## 功能描述
查询指定城市的天气信息，包括温度、湿度、天气状况等。

## 使用方法
```javascript
// 在OpenClaw中使用
const weather = await openclaw.skills.weather.execute({ city: '北京' });
```

## 参数说明
- `city` (必填): 城市名称，如"北京"、"上海"

## 返回结果
```json
{
    "city": "北京",
    "temperature": 22,
    "condition": "晴朗",
    "humidity": 65,
    "windSpeed": 12
}
```

## 环境变量
- `WEATHER_API_KEY`: 天气API密钥

技能测试与调试

本地测试

npm install

npm test

# 调试技能
openclaw skill debug ./my-weather-skill

集成测试

const weatherSkill = require('./index.js');

async function testSkill() {
    const result = await weatherSkill.execute({ city: '北京' }, {});

技能发布

1. 打包技能

# 创建技能包
openclaw skill pack my-weather-skill

# 输出: my-weather-skill.opks (OpenClaw技能包)

2. 发布到技能市场

# 登录OpenClaw开发者账户
openclaw login

# 发布技能
openclaw skill publish my-weather-skill.opks

# 设置技能可见性
openclaw skill set-visibility my-weather-skill public

3. 安装使用

# 用户安装技能
openclaw skill install weather-skill

# 在OpenClaw中使用
openclaw ask "北京天气怎么样"

最佳实践

1. 错误处理

始终包含完善的错误处理：

execute: async function(params, context) {
    try {
        // 业务逻辑
    } catch (error) {
        console.error('技能执行错误:', error);
        return {
            error: '技能执行失败',
            details: process.env.NODE_ENV === 'development' ? error.message : undefined
        };
    }
}

2. 参数验证

// 验证必填参数
if (!params.city) {
    return { error: '城市参数不能为空' };
}

// 验证参数类型
if (typeof params.city !== 'string') {
    return { error: '城市参数必须是字符串' };
}

3. 性能优化

  • 使用缓存减少API调用
  • 批量处理相似请求
  • 设置合理的超时时间
  • 监控技能性能指标

常见问题

Q: 技能如何获取用户上下文？

A: 通过 context 参数获取：

execute: async function(params, context) {
    const userId = context.userId;
    const sessionId = context.sessionId;
    // 使用上下文信息
}

Q: 技能可以调用其他技能吗？

A: 可以，通过技能组合实现复杂功能：

// 在技能中调用其他技能
const searchResult = await context.skills.webSearch.execute({ query: '天气API' });
const translation = await context.skills.translator.execute({ text: searchResult, targetLang: 'zh' });

Q: 如何更新已发布的技能？

A: 更新版本号后重新发布：

# 更新package.json中的版本号
"version": "1.0.1"

# 重新打包发布
openclaw skill pack my-weather-skill
openclaw skill publish my-weather-skill.opks --update
